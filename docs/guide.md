# 笔记模板与使用说明

## 怎么添加笔记

1. 在 `docs/gongzhuan`、`docs/xingce` 或 `docs/shenlun` 下新建 Markdown 文件，例如 `my-note.md`。
2. 复制下面的模板，写入学习内容。
3. 在 `docs/.vitepress/config.mts` 对应板块的 `sidebar` 中添加文章链接，例如 `{ text: '我的笔记', link: '/xingce/my-note' }`。
4. 运行 `npm run docs:dev`，在浏览器中查看。保存后页面会自动更新。

## 知识笔记模板

````md
# 专题名称

## 学习信息
- 日期：
- 来源：

## 核心知识
用自己的话解释本节重点。

## 方法与例子
写明适用条件，并补充一个例子。

## 易错点
记录容易混淆的内容与区分方法。

## 复习清单
- [ ] 能独立复述知识点
- [ ] 能说明方法的适用条件
- [ ] 已完成相关练习
````

## 错题复盘模板

```md
## 题目名称
- 日期 / 来源：
- 所属专题：
- 我的答案 / 参考答案：
- 当时的思路：
- 错误原因：
- 正确思路与依据：
- 下次遇到同类题如何判断：
- 二次自测日期 / 结果：
```

## 维护习惯

- 文件名建议使用小写英文和连字符，文章标题可以使用中文。
- 一篇笔记聚焦一个主题，内容变长后拆分为独立文章。
- 标注资料出处；涉及有时效的内容时，同时记录资料日期。
- 搜索框支持按笔记正文查找内容，手机端可以从菜单展开板块导航。
