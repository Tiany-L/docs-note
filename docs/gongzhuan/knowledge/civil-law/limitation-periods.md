# 民法典、诉讼时效

## 知识点速记

> 来源：2027 公专 P44 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 普通时效三年 | 一般民事案件诉讼时效期间为 3 年；自权利人<strong>知道或应当知道</strong>权利受到侵害之日起算；不是从侵害行为发生之日起算。 |
| 最长保护二十年 | 自权利受到侵害之日起超过 20 年，法院不予保护；<strong>20 年从受侵害之日起算</strong>，与权利人是否知道无关；3 年是主观起算，20 年是客观上限。 |
| 应当知道的认定 | 单位发放工资条之日，即为「应当知道」被扣工资之日，从收到工资条起算；当事人自称「5 月 5 日才知道」不予采信；判断标准是<strong>客观上何时可得知悉</strong>。 |
| 知道义务人起算 | 被蒙头殴打，1 月 1 日已知道受损，但直到 5 月 5 日看监控才知侵权人是谁；起算点自<strong>知道义务人</strong>之日起算，不是从受损之日起算。 |
| 性侵成年起算 | 未成年人遭受性侵害的损害赔偿请求权，诉讼时效自受害人<strong>年满 18 周岁</strong>之日起算；幼年不懂、不能起诉，不影响其成年后主张。 |
| 三费不受时效限制 | 请求支付抚养费、赡养费、扶养费，<strong>不受 3 年和 20 年限制</strong>；抚养是长辈对晚辈、赡养是晚辈对长辈、扶养是平辈之间；立法考量是保护弱势群体的生存权。 |
| 时效立法目的 | 法律不保护在权利上睡大觉的人；设定 3 年、20 年是督促权利人及时主张，防止权利无限期悬空、一代代传着起诉。 |
| 中断归零重算三年 | 3 年内发生中断事由，已经过的期间全部作废，从零重新起算 3 年；如临近届满时打电话主张债权，时效重新起算。 |
| 中断无次数限制 | 每遇一次中断事由即重新起算 3 年，可反复中断；<strong>没有次数上限</strong>，隔一段主张一次，时效就一再刷新。 |
| 中断四种法定事由 | 权利人向义务人提出履行请求；义务人同意履行；权利人提起诉讼或申请仲裁；与提起诉讼、申请仲裁具有同等效力的其他情形（如申请支付令、申请破产）。 |
| 超时效后不再中断 | 时效届满后再出现中断事由，<strong>不发生中断</strong>；中断必须发生在时效期间内，届满后义务人同意履行也不重新起算。 |
| 中止是客观障碍 | 中止是暂停键，不是权利人不愿主张，而是客观上无法行使；须先遭遇法定障碍才暂停，障碍消除后接着走。 |
| 中止两个条件 | 一须符合五种法定事由之一；二该事由必须发生在时效期间<strong>最后 6 个月内</strong>；发生在最后 6 个月之前的，不产生中止。 |
| 中止五种法定事由 | 不可抗力（地震、泥石流、洪水）；无民事行为能力人或限制民事行为能力人无法定代理人，或法定代理人死亡、丧失代理权、丧失民事行为能力；继承开始后未确定继承人或遗产管理人；权利人被义务人或其他人控制；夫妻等家庭成员间因特殊关系不能行使（如离婚冷静期）。 |
| 中止后补六个月 | 中止前已经过的期间仍然有效，<strong>不归零</strong>；自中止事由消除之日起再计算 6 个月，6 个月内起诉仍有效；旧法是剩多久补多久，现行统一补 6 个月。 |
| 中止与中断对比 | 中断是重拨键：归零重算 3 年、无次数限制；中止是暂停键：已过期间有效、事由消除后只补 6 个月；<strong>中断看有没有主张权利，中止看有没有客观障碍</strong>。 |

## 待核对事项

::: danger
**以下为来源文件保留的疑点，复习时需结合原课或正式规定核对。**

- 38:30：「无明知性为能力或先知命之性没能力的人」——疑为「无民事行为能力人或限制民事行为能力人」，该中止事由的主体表述需核。
- 44:00：「终止是由消除知识起一律再计算六个月」——疑为「中止事由消除之日起计算六个月」；讲者同时提到此处有法条更改（旧法剩余多久补多久、现统一六个月），新旧衔接口径需核。
- 20:00：「赛养费」及多处「抚养」「扶养」混读——三费应为抚养费、赡养费、扶养费，语音识别混同，具体名称需核。
:::
