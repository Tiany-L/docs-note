# 民法典、基本原则与自然人

## 知识点速记

> 来源：2027 公专 P41 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 民法典条文规模 | 2020 年 5 月 23 日十三届全国人大三次会议通过；全文 <strong>1260 条</strong>，总则 206 条、分则 1054 条；考试约 3—4 分，总则约 2 分。 |
| 民法调整对象 | 调整平等主体的自然人、法人、非法人组织之间的<strong>人身关系</strong>和财产关系；主体地位平等是前提。 |
| 平等主体的判断 | 买卖、租赁等双方自愿成交属平等主体；<strong>治安、行政案件</strong>中行政机关地位高于相对人，不归民法调整。 |
| 自愿与公平原则 | 自愿：由当事人自己决定，愿买愿卖、不能强迫；公平：讲究公平正义。 |
| 诚信原则 | 不能弄虚作假、以次充好；交易中掺假即违反诚信原则。 |
| 公序良俗原则 | 不得违背公共秩序与善良风俗；<strong>违背公序良俗的协议无效</strong>，不受法律保护。 |
| 绿色原则 | 不能以污染环境为代价发展经济，要保护环境。 |
| 民事权利能力 | 依法享有民事权利、承担民事义务的<strong>资格</strong>；落在「有没有权利、有没有义务」上。 |
| 民事行为能力 | 能够独立实施有效法律行为的资格；看这个行为<strong>法律上承不承认、有没有效</strong>。 |
| 好意施惠 | 又称情谊行为，如请客吃饭、搭便车、无偿帮忙；出于情谊而非合同关系。 |
| 好意施惠的责任界限 | 约定好了却未去，<strong>不承担违约责任</strong>；履行过程中致对方损害，施惠人承担<strong>侵权责任</strong>。 |
| 好意同乘的减责 | 非营运机动车致无偿搭乘人损害，属机动车一方责任的应当<strong>减轻</strong>赔偿；使用人有故意或重大过失的除外。 |
| 民事权利能力起止 | 始于出生、终于死亡；出生时间与死亡时间就是这项能力的起点与终点。 |
| 出生死亡时间证明顺序 | 先看<strong>出生证明、死亡证明</strong>；没有的看户籍登记；再无则看其他有效身份信息登记。 |
| 胎儿民事权利能力 | 原则上没有；涉及遗产继承、接受赠与等胎儿利益保护时<strong>视为有</strong>；娩出时为死体的，自始不存在。 |
| 胎儿继承权的效力 | 属<strong>效力待定</strong>；娩出为活体则追溯至受胎时享有继承权，娩出为死体则追溯不回去。 |
| 娩出后存活又死亡 | 存活多久就享有多久的继承权；其死亡后该份额作为<strong>婴儿自己的遗产二次分配</strong>，由其母亲取得。 |
| 三类案件最低年龄 | 治安案件<strong>14 周岁</strong>；刑事案件已由 14 周岁改为<strong>12 周岁</strong>；民事案件<strong>8 周岁</strong>。 |
| 无民事行为能力 | 不满 8 周岁的未成年人；不能辨认自己行为的成年人；所实施的民事行为<strong>无效</strong>。 |
| 无行为能力人纯获利益 | 受赠、收压岁钱也须<strong>法定代理人追认</strong>：不同意则无效，同意则有效。 |
| 限制民事行为能力 | 8 周岁以上（含 8 周岁）的未成年人；不能完全辨认自己行为的成年人；放开一部分、限制一部分。 |
| 限制行为能力人有效行为 | 纯获利益的行为<strong>直接有效</strong>，无需法定代理人同意；与年龄、智力、精神健康状况相适应的行为也有效。 |
| 完全民事行为能力 | 18 周岁以上；或 16 周岁以上不满 18 周岁、以<strong>自己的劳动收入</strong>为主要生活来源的。 |
| 年龄门槛的排除项 | 民事行为能力不设 14 周岁；16 周岁只出现在劳动收入这一例外里；也<strong>未对残疾人</strong>另作规定。 |
| 以上以下的含义 | 「以上」「以下」<strong>含本数</strong>：8 周岁以上含 8 周岁，2 人以上含 2 人，24 小时以上含 24 小时。 |
| 住所的认定 | 以户籍登记或其他有效身份信息登记的居所为住所；居住证所载居所可作依据。 |
| 经常居住地 | 离开住所后<strong>连续居住一年以上</strong>的地方；经常居住地与住所不一致的，以经常居住地为住所。 |
