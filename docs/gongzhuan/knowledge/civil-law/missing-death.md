# 民法典、宣告失踪与死亡

## 知识点速记

> 来源：2027 公专 P43 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 宣告失踪满两年 | 下落不明满 <strong>2 年</strong>可申请宣告失踪；只解决人不见了、生死不明，不推定死亡。 |
| 宣告死亡满四年 | 普通情形下落不明满 <strong>4 年</strong>才能申请宣告死亡；比失踪多两年，两档期限别记混。 |
| 意外事件满两年 | 因意外事件下落不明的，满 2 年即可申请宣告死亡；与普通 4 年相比缩短一半。 |
| 不可能生存零年 | 意外事件下落不明，经有关机关证明不可能生存的，申请宣告死亡<strong>不受 2 年限制</strong>；相当于零年，可立即申请。 |
| 法院宣告公安备案 | 宣告权只在人民法院，公安只做备案（销户时备案）；<strong>不告不理</strong>，须本人或利害关系人主动申请。 |
| 失踪公告期三个月 | 法院受理宣告失踪后，公告期 3 个月；这是尽最后一次努力找人的过渡期，期满才作宣告。 |
| 死亡公告期一年 | 普通 4 年、意外 2 年的宣告死亡，公告期为 <strong>1 年</strong>；不可能生存的零年情形，公告期缩短为 3 个月。 |
| 死亡日期的确定 | 一般以人民法院宣告死亡的<strong>判决作出之日</strong>为死亡时间；因意外事件下落不明的，以意外事件发生之日为死亡时间。 |
| 宣告后先清偿债务 | 人失踪或被宣告死亡，代管人（多为配偶）保管的财产要先还其生前或失踪前所欠外债；不论失踪还是死亡，都先还债。 |
| 撤销宣告须申请 | 失踪人、被宣告死亡人重新出现，仍是不告不理；须本人或利害关系人向法院申请，才撤销原宣告。 |
| 宣告死亡三项效力 | 婚姻关系终止、监护关系终止、继承开始；宣告死亡只动这三项。 |
| 其他权利不受影响 | 被宣告死亡期间签的合同、租地协议仍有效，财产被侵占仍可起诉主张；<strong>只有</strong>婚姻、监护、继承三项变动。 |
| 配偶再婚不重婚 | 宣告死亡后婚姻关系已终止，配偶再与他人登记结婚<strong>不构成重婚</strong>；原婚姻不因事后撤销宣告而变成重婚。 |
| 撤销后婚姻自行恢复 | 婚姻关系自撤销宣告之日起自行恢复；<strong>配偶再婚</strong>或向婚姻登记机关书面声明不愿恢复的除外；再婚后又丧偶的同样不恢复。 |
| 撤销后财产返还 | 依继承取得的财产应返还原物；<strong>无法返还的适当补偿</strong>；已被第三人合法买受的，只能向继承人主张，不能向第三人追。 |
| 个体工商户 | 依法登记从事经营的自然人；<strong>不是法人</strong>，是特殊的自然人；小卖店、水果店、奶站都算。 |
| 法人是组织 | 法人是组织、<strong>不是人</strong>；法定代表人才是自然人；小米是法人，雷军是法定代表人。 |
| 法人住所 | 以<strong>主要办事机构所在地</strong>为住所，登记也按主要办事机构所在地登记；业务地、法定代表人老家都不算。 |
| 营利法人 | 以营利为目的设立；有限公司、股份公司都属；<strong>亏损的股份公司仍是营利法人</strong>，看设立目的不看当下盈亏。 |
| 非营利法人 | 事业单位、社会团体、基金会、社会服务机构；不以营利为目的，但<strong>可以盈利</strong>，如公立大学转让科研成果专利。 |
| 特别法人 | 机关法人（公安局、教育局、财政局）与基层群众性自治组织法人；后者只记<strong>村委会、居委会</strong>。 |
| 非法人组织 | 个人独资企业、合伙企业、不具有法人资格的专业服务机构（民办学校、民办医院等）；<strong>没有法人资格</strong>，出资人自担风险。 |
| 行为与事件 | 以人的意志为转移的是行为（签约、结婚、收养、立遗嘱）；地震、雷击、战争是事件；<strong>能否起诉是快速判断法</strong>。 |
| 有效民事法律行为 | 行为人有相应民事行为能力、意思表示真实、不违反强制性规定和公序良俗；三者齐备才有效。 |
| 无效民事法律行为 | 无行为能力人实施、违反强制性规定、以合法形式掩盖非法目的（阴阳合同）、恶意串通、违背公序良俗、不当免责条款；<strong>自始无效</strong>。 |
| 可撤销民事法律行为 | 重大误解、欺诈、胁迫、显失公平四种；<strong>是可撤销不是无效</strong>，须由受损一方主张。 |
| 正当防卫与紧急避险 | 正当防卫不承担民事责任，<strong>超过必要限度</strong>造成不应有损害的防卫人要赔；紧急避险由引起险情的人担责，自然原因引起的避险人不担责、可适当补偿。 |
| 见义勇为与紧急救助 | 为保护他人权益自己受伤，由侵权人担责、受益人可适当补偿；无侵权人或其逃逸、无力承担时受益人<strong>应当</strong>适当补偿；自愿紧急救助致受助人损害，救助人不担责。 |

## 课程口诀

::: tip
**口诀（宣告程序）：「法院宣告，公安备案」**

宣告权只在人民法院；公安不宣告，只在销户时备案，且不告不理。

课程位置：05:30。
:::

::: tip
**口诀（宣告死亡对民事关系的影响范围）：「婚姻监护终止，继承开始」**

只影响婚姻、监护、继承三项，其他民事权利不受影响；讲者口述「婚姻监护宗旨」为「终止」的同音误识，已校正

课程位置：12:30。
:::
