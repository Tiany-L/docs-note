# 民法典、重要分则

## 知识点速记

> 来源：2027 公专 P45 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 拾得遗失物 | 拾得遗失物应当返还权利人；拾得人应当<strong>及时通知</strong>权利人领取，或者送交<strong>公安等有关部门</strong>。 |
| 收养后的户口登记 | 收养关系成立后，由<strong>公安机关</strong>按照国家有关规定为被收养人办理户口登记；落户这一环归公安，不是民政登记那一步。 |
| 连带责任 | A 或 B <strong>单独一个</strong>原因即可导致 C 结果（原因力竞合）；权利人可向任一责任人主张<strong>全部</strong>赔偿，等于可以「多选」；各责任人单独都能造成该结果。 |
| 按份责任 | 须 A 加 B 等多个条件<strong>结合</strong>才能导致 C 结果（原因力结合）；按<strong>过错大小、损害大小</strong>确定份额，如四人各担 25%；各人只赔自己那一份，不能要求一人全赔。 |
| 直系血亲的认定 | 直系血亲是<strong>生与被生</strong>的上下关系；父母子女、祖父母与孙子女、外祖父母与外孙子女都算；兄弟姐妹、舅姑等旁系亲属不算直系。 |
| 选取姓氏的法定情形 | 原则随父姓或母姓；可选取其他<strong>直系长辈血亲</strong>的姓氏（上溯不限代）；因法定扶养人以外的人扶养而选取扶养人姓氏；有不违背公序良俗的其他正当理由。 |
| 姓氏的公序良俗底线 | 不得<strong>自创</strong>一个从来没有的姓；不得选取与本人毫无关系者的姓；不得与伟人、国家领导人重名；突破即认定违背公序良俗，户口登记被驳回。 |
| 少数民族姓氏 | 少数民族自然人选取姓氏，可以<strong>遵循本民族的文化传统和风俗习惯</strong>；2025 年国考卷考过这一点，属偏点。 |
| 法定继承顺序 | 第一顺序：配偶、子女、父母；第二顺序：兄弟姐妹、祖父母、外祖父母；<strong>有第一顺序继承人的，第二顺序不继承</strong>，第一顺序全部消灭后第二顺序才轮到。 |
| 丧偶儿媳女婿 | 儿媳、女婿不在法定继承人范围，对公婆、岳父母<strong>本无继承权</strong>；丧偶儿媳对公婆、丧偶女婿对岳父母尽了<strong>主要赡养义务</strong>的，作为第一顺序继承人。 |
| 代位继承 | 被继承人的子女<strong>先于</strong>被继承人死亡，由该子女的<strong>直系晚辈血亲</strong>代位继承；代的是先死子女应得的那一份。 |
| 遗产分配规则 | 同一顺序继承人份额<strong>一般均等</strong>；生活有特殊困难又缺乏劳动能力的应予照顾；尽主要扶养义务或与被继承人共同生活的可以多分；有扶养能力和条件却不尽义务的应当少分；协商同意的也可以不均等。 |
| 继承人以外分遗产 | 依靠被继承人扶养的人，或对被继承人扶养较多的人，<strong>可以适当分得</strong>遗产；这两类都不是继承人，属法律特别规定。 |
| 继承纠纷的解决 | 先协商；协商不成的，可请求<strong>人民调解委员会</strong>调解，或向人民法院起诉。 |
| 自助行为 | 情况紧迫、<strong>不能及时获得国家机关保护</strong>时，可在必要范围内采取扣留侵权人财物等合理措施；采取措施后<strong>应当立即报警</strong>，请求国家机关处理；属私力救济的免责事由。 |
| 高空抛物的责任主体 | 能查清侵权人的由侵权人担责；经调查难以确定具体侵权人的，除能证明自己不是侵权人外，由<strong>可能加害的建筑物使用人补偿</strong>；此处<strong>举证责任倒置</strong>，证明不了就分摊。 |
| 补偿后追偿与一楼 | 已补偿的住户查明实际侵权人后，可向其<strong>追偿</strong>；<strong>一楼默认不能</strong>成为高空抛物的责任主体。 |
| 物业与公安的义务 | 物业未采取必要安全保障措施（防护设施、隔离带、提示语等）致人损害的，承担<strong>未履行安全保障义务</strong>的侵权责任；公安机关应当<strong>依法及时调查</strong>、查清责任人。 |
| 自甘风险 | 自愿参加有一定风险的文体活动，因其他参加者行为受损的，<strong>不得请求</strong>其承担侵权责任；其他参加者对损害的发生有<strong>故意或重大过失</strong>的除外。 |
| 借款利息约定不明 | 自然人之间借款对支付利息<strong>没有约定</strong>的，视为没有利息；只还本金，出借人事后主张高额利息不予支持。 |
| 用人单位责任 | 工作人员因执行工作任务造成他人损害的，由<strong>用人单位</strong>承担侵权责任；工作人员有<strong>故意或重大过失</strong>的，单位赔偿后可向其追偿，对外仍是单位赔。 |
| 劳务派遣责任 | 被派遣人员因执行工作任务致害的，由<strong>接受派遣的用工单位</strong>承担；派遣单位有过错的，承担<strong>相应</strong>责任（如未按约培训、派出不合格人员）。 |
