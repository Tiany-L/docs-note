# 民法典、监护权

## 知识点速记

> 来源：2027 公专 P42 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 监护的两类对象 | 需要被监护的只有两类：未成年人与无、限制民事行为能力的成年人；<strong>通俗记作「一个小的、一个傻的」</strong>；两类规则相通，但法定顺位不同。 |
| 监护方式分类 | 法定、遗嘱指定、协议、指定、成年人意定、委托六类；<strong>遗嘱指定监护与指定监护是两回事，无任何关系</strong>。 |
| 法定监护 | 由法律直接为被监护人指定监护人；目的是防止各监护人之间互相推诿；顺位由法律定，不依当事人意思。 |
| 未成年人监护顺序 | 父母；祖父母、外祖父母；兄姐；其他愿意担任监护人的个人或组织；单位（民政）；<strong>五个顺位依次适用</strong>。 |
| 顺位与主体形态 | 有前一顺位原则上不启动后一顺位，前一顺位用不了才轮到下一顺位；监护人可以是自然人，也可以是组织、单位；<strong>同一顺位可一人也可多人</strong>，如「父母」即父、母两人。 |
| 父母为当然监护人 | 血缘亲情最直接，父母是当然监护人（必然监护人）；<strong>养父母属拟制血亲，与亲生父母同等对待</strong>。 |
| 离婚不影响监护权 | 父母离婚只影响抚养权，监护权不受影响，仍是父母双方；一方死亡的，另一方为当然监护人；<strong>孩子判给谁只是抚养权归谁</strong>。 |
| 监护与抚养的关系 | 监护是上位、抚养是下位；监护包括教育、抚养和保护；<strong>离婚争的是抚养权，没有人争监护权</strong>。 |
| 成年人监护顺序 | 配偶；父母、子女；其他近亲属；其他愿意担任监护人的个人或组织（须经住所地居委会、村委会或民政同意）；<strong>第一顺位是配偶，与未成年人不同</strong>。 |
| 撤销后仍负义务 | 监护人资格被撤销后，仍须继续履行负担义务；<strong>抚养费就是负担义务之一</strong>；撤销资格不等于免除经济责任。 |
| 撤销后不得恢复 | 对被监护人实施故意犯罪的，撤销后不得恢复；常见如虐待罪、故意伤害罪、非法拘禁罪、强奸罪；<strong>一次故意，终身不用</strong>。 |
| 撤销后可恢复条件 | 限于过失犯罪；须确有悔改表现、由本人提出申请；法院还须尊重被监护人的真实意愿，<strong>不是一申请就恢复</strong>。 |
| 遗嘱指定监护 | 父母临终以遗嘱为孩子指定监护人；无顺位、无人数限制，可指定任何人；<strong>属一厢情愿，不必然产生法律效果</strong>。 |
| 遗嘱指定的限制 | 主体只能是父母，祖父母、外祖父母、兄姐、亲友都不行；父母被撤销监护资格或丧失监护能力的，不能再以遗嘱指定；<strong>不合格的父母身后也不被信任</strong>。 |
| 协议监护 | 由家庭成员开会协商确定监护人；<strong>主体限于家人</strong>，邻居、外人不能参与；本质是尊重家庭的意思自治。 |
| 协议不得免职 | 父母不得通过协议免除自己的监护职责，<strong>否则协议无效</strong>；这是弃子，法律劝人为善不劝人为恶。 |
| 协议可托孤 | 父母可以与他人约定，在其丧失监护能力时由该人担任监护人；<strong>弃子不行，托孤可以</strong>；并未免除生前的监护职责。 |
| 协议可破顺位 | 协议监护不受法定顺位限制；可由顺位在后的人担任，也可不同顺位的人共同担任；人数一人、多人都可以。 |
| 指定监护的主体 | 只有四家：被监护人住所地的居委会、村委会、民政部门、法院；<strong>现已取消前置程序，可直接向法院申请</strong>。 |
| 指定监护的效力 | 法院按择优原则指定，可跨顺位、不限人数；<strong>被指定人不同意也不好使</strong>，与遗嘱指定的一厢情愿正相反。 |
| 临时监护 | 由居委会、村委会、法律规定的有关组织、民政部门担任，<strong>没有法院</strong>；监护人因突发事件暂时无法履职、被监护人无人照料的，也由上述主体安排必要临时生活照料。 |
| 委托监护 | 即找人帮忙带孩子；<strong>不导致监护职责丧失</strong>，委托人仍是监护人；受托人有过错的，在其过错范围内承担按份责任。 |
| 成年人意定监护 | 趁尚未丧失行为能力时，<strong>以书面委托合同</strong>为自己指定将来的监护人；口头约定不算；签订时双方均须有完全民事行为能力；意定优于法定。 |
| 意定合同的解除 | 双方都未丧失能力时可解除，此时合同尚未生效；一方已丧失能力，合同即生效，<strong>不得再解除</strong>。 |
| 监护终止 | 被监护人取得或恢复完全民事行为能力；监护人丧失监护能力；被监护人或监护人死亡；<strong>终止后仍需照顾的，另行确定监护人</strong>。 |
| 撤销的主体与后果 | 有关个人、其他组织、民政部门等可向法院申请，<strong>不包括公安</strong>；民政是撤销的第一责任主体；由法院撤销，并按最有利于被监护人的原则另行指定。 |

## 课程口诀

::: tip
**口诀（撤销后恢复）：「一次故意终身不用」**

指对被监护人实施故意犯罪的，监护资格被撤销后永不得恢复，也不必征求被监护人意见；过失犯罪才走申请、悔改、征询意愿那条路。

课程位置：12:00。
:::
