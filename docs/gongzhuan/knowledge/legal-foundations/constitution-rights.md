# 宪法与公民权利

## 知识点速记

> 来源：2027 公专 P38 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 宪法的根本法地位 | 宪法在法律体系中效力最高，称根本大法、母法；<strong>「根本大法」只配给宪法</strong>，刑法、民法典都不能称「某领域的根本大法」；提及根本大法即指宪法 |
| 制宪机关与修宪释宪主体 | 制宪机关是一届全国人大第一次全体会议；修改宪法的只有全国人大，解释宪法的只有全国人大常委会；两者不可混用 |
| 修宪的提议与通过 | 由全国人大常委会或五分之一以上全国人大代表提议；由全国人大代表<strong>三分之二以上</strong>多数通过；通过后由全国人大主席团公布 |
| 宪法的基本原则 | 党的领导、人民主权、权力统一与制约、法治、精简；<strong>人民主权是本节重点</strong>；尊重和保障人权于 2004 年入宪；一切国家机关实行精简原则 |
| 国体、政体与专政内涵 | 国体即国家性质，是人民民主专政；工人阶级是领导力量，工农联盟是基础；政体是人民代表大会制度，同时是政权组织形式 |
| 根本制度与根本政治制度 | <strong>根本制度是社会主义制度</strong>；加上「政治」二字才是人民代表大会制度；基本经济制度是公有制为主体、多种所有制经济共同发展 |
| 宪法沿革与五次修改 | 1949 年《共同纲领》，后有 1954、1975、1978、1982 年宪法；现行是 <strong>1982 年宪法</strong>，经 88、93、99、04、18 五次修改，最近一次为 2018 年 |
| 领导与监督关系的权限 | A 领导 B 时，A 可改变或撤销 B 的规范性文件；A 只监督 B 时<strong>只能撤销不能改变</strong>；人大领导人常是领导关系，人大常委会、上级人大常委会、授权机关对下均为监督关系 |
| 人大常委会与政府的权限规律 | 以人大常委会为主体的，只有撤销权，改变栏里找不到人常；<strong>以人民政府为主体的，既有改变权又有撤销权</strong>；先认主体再套公式 |
| 多党合作制度 | 共产党是执政党，民主党派是参政党；我国<strong>没有在野党</strong>；四项基本原则是多党合作的政治基础；党对民主党派的领导是政治领导 |
| 爱国统一战线与政协 | 范围含社会主义劳动者、社会主义事业建设者、拥护社会主义的爱国者、拥护祖国统一和致力于民族复兴的爱国者；组织形式是政协，<strong>政协既非国家机关也非一般人民团体</strong>；职能是政治协商、民主监督、参政议政 |
| 人民代表大会制度的内容 | 一切权力属于人民；人民选举代表组成人大；行政机关、监察机关、审判机关、检察机关由人大产生、<strong>对它负责、受它监督</strong>；常委会对本级人大负责，人大对人民负责 |
| 公有制经济的构成 | 全民所有制即国有经济，生产资料归国家所有、不归个人；集体所有制生产资料归集体所有；<strong>混合所有制中的国有和集体成分</strong>也算公有制；国有经济为主导 |
| 自然资源的所有权归属 | 矿藏、水流、城市土地属国家；宅基地、自留地、自留山属集体；<strong>森林、山岭、草原、荒地、滩涂既可国家所有也可集体所有</strong> |
| 非公有制经济的范围与政策 | 个体经济即个体工商户，私营经济即私营企业，三资企业分中外合资、中外合作、外商独资；是社会主义市场经济的重要组成部分，国家鼓励、支持、引导并依法监督和管理 |
| 选举权的性质与条件 | 选举权是权利不是义务，<strong>可以放弃</strong>；须同时具备中国公民、年满十八周岁、未被剥夺政治权利，三项是并列关系，缺一即无选举权 |
| 直接选举与间接选举 | 县、乡人大代表由选民直接选举；全国、省、设区的市、自治州人大代表由<strong>下一级人大代表</strong>选举；国省市间接、县乡直接 |
| 剥夺政治权利的内容与执行 | 不能举手：无选举权和被选举权；不能说话：无六大政治自由；不能当官：不得任国家机关职务及国有单位领导职务；可写书但<strong>不能出版</strong>，附加剥夺时主刑期间全程无政治权利 |
| 平等权的界限 | 不受任何不合理差别对待，但<strong>允许合理的差别对待</strong>；对妇女的特殊保护、军人优先属合理差别；按性别设限、男女不平等属不合理差别 |
| 政治权利与政治自由 | 含选举权和被选举权；六大政治自由中<strong>言论自由居首</strong>，方式可口头、书面；行使不得侮辱、诽谤他人；集会、游行、示威另有专门法律，不作考查 |
| 监督权与取得赔偿权 | 批评权、建议权、控告权、检举权、申诉权；可针对国家机关及其工作人员的行为提出；提出后是否采纳由机关决定 |
| 宗教信仰自由 | 可信不可传；公民可信仰，但只能在寺庙等特定场所，不得公开传教；<strong>人民警察不得信教</strong>，只能信仰中国共产党 |
| 人身自由与人格尊严 | 非经人民法院批准或决定、公安机关执行，不受逮捕，禁止非法拘禁；宪法规定人格尊严权，禁止用任何方法侮辱、诽谤和诬告陷害 |
| 具体人格权归民法典 | 姓名权、肖像权、名誉权、荣誉权、隐私权<strong>宪法未明确规定</strong>，由民法典规定；宪法人格尊严权依靠民法典保障实施，英雄烈士的姓名、肖像、名誉、荣誉受保护 |
| 住宅权与通信秘密 | 住宅权禁非法搜查、非法侵入，硬闯进入与被要求退出而拒不退出都算侵入；通信秘密只有<strong>公安、检察机关</strong>因国家安全或追查犯罪需要可限制，法院无侦查权不能限制 |
| 财产权的表述界限 | 公民合法的私有财产不受侵犯，非法取得的财产不受保护；<strong>「神圣不可侵犯」只用于公共财产</strong>；继承权同样受保护 |
| 劳动权、受教育权与休息权 | 劳动权、受教育权既是公民权利也是公民义务；休息权<strong>只属劳动者</strong>，不劳动的人、全职备考者不享有 |
| 物质帮助权 | 公民在年老、疾病或丧失劳动能力的情况下，有从国家和社会获得物质帮助的权利；三者是限定情形，不是普遍福利 |
| 文化自由与出版自由 | 科学研究自由、文艺创作自由属文化权利和自由；<strong>创作之后出版就转为政治权利和自由</strong>，两者不可混为一谈 |
| 宪法未明文规定的权利 | 生命权、沉默权、隐私权、环境权、私有财产权及营业自由、罢工自由、迁徙自由均未写入宪法，讲者称「五权三自由」 |

## 课程口诀

::: tip
**口诀（修宪权与释宪权）：「只有全国人大有修宪权，只有全国人大常委会才有释宪权」**

讲者口述为「只有全国人长有视线权」，按上下文校正为「人大常委会」「释宪权」。

课程位置：03:00。
:::

::: tip
**口诀（修宪程序）：「常委五一提修宪，通过只需三两天」**

常委＝全国人大常委会；五一＝五分之一以上全国人大代表；三两天＝三分之二以上。

课程位置：07:00。
:::

::: tip
**口诀（宪法五次修改年份）：「爸爸有小三，舅舅有小四，还得靠姨妈」**

爸爸＝88，小三＝93，小四＝04，姨妈＝18，中间 99 归入舅舅一路。

课程位置：13:00。
:::

::: tip
**口诀（自然资源归属）：「矿水成土都归国，宅基自流集体多，山林草滩和荒地，既可集体也可国」**

矿藏、水流、城市土地归国家；宅基地、自留地、自留山归集体；森林、山岭、草原、荒地、滩涂两可。

课程位置：33:00。
:::

::: tip
**口诀（剥夺政治权利的后果）：「不能举手，不能说话，不能当官」**

举手＝选举权被选举权；说话＝六大政治自由；当官＝国家机关职务及国有单位领导职务。

课程位置：50:30。
:::

::: tip
**口诀（物质帮助权）：「年老疾病不劳动，可获国家帮助」**

对应年老、疾病、丧失劳动能力三种情形。

课程位置：82:00。
:::

- 13:00：讲者两次把现行宪法说成「1980 年宪法」，前后又都说 1982 年宪法，疑为口误或识别错，待核
