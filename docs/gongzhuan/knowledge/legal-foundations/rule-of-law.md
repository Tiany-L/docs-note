# 法治思想

## 知识点速记

> 来源：2027 公专 P40 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 考情变化 | 2024 年前只考「十一个坚持」的大标题，问某句是不是法治思想；2025 年起改考其中<strong>具体小点</strong>，把一条拆成四个选项；本部分约 1—3 分 |
| 习近平法治思想的地位 | 顺应实现中华民族伟大复兴时代要求应运而生的重大理论创新成果；马克思主义中国化最新成果；习近平新时代中国特色社会主义思想的重要组成部分；全面依法治国的<strong>根本遵循和行动指南</strong> |
| 核心要义是十一个坚持 | 十一个坚持是习近平法治思想的核心要义；每条只是板块大标题，标题之下还有大量内容，不等于法治思想只有这十一句话 |
| 党的领导是法治之魂 | 党的领导是中国特色社会主义最本质的特征，是社会主义法治最根本的保证；是<strong>社会主义法治之魂</strong>；是我国法治同西方资本主义国家法治最大的区别 |
| 党的意志转为国家意志 | 通过法定程序把党的意志转化为国家意志，把党的路线方针政策转化为国家法律法规；党<strong>领导立法、保证执法、支持司法、带头守法</strong> |
| 依法治国与依法执政统一 | 把依法治国基本方略同依法执政基本方式统一起来；党的领导贯穿依法治国全过程各方面 |
| 法治道路是唯一正确道路 | 中国特色社会主义法治道路是社会主义法治建设成就和经验的集中体现，是建设社会主义法治国家的<strong>唯一正确道路</strong>；此处「唯一」仍为正确表述 |
| 依宪治国依宪执政 | 是全面依法治国的<strong>首要任务</strong>，也是建设社会主义法治国家的首要任务；宪法的生命在于实施，宪法的权威也在于实施 |
| 三一三治 | 依法治国是党领导人民治理国家的基本方略；依法执政是党执政的基本方式；依法行政是基本准则；法治国家是目标、<strong>法治政府是主体</strong>、法治社会是基础 |
| 立执司守四位一体 | 科学立法、严格执法、公正司法、全民守法四者<strong>捆绑出现、缺一不可</strong>，任一被删即为错项；公正是法治的生命线；谁执法谁普法 |
| 立法三要求 | 立法上坚持科学立法、民主立法、依法立法；通过这些途径提高立法质量和效率 |
| 依法治国与以德治国 | 二者相辅相成、相得益彰，但并<strong>不完全混同</strong>，法和道德是两回事；社会关系调整以法律为主 |
| 党内法规体系构成 | 以党章为根本；以民主集中制为核心；以准则条例等中央党内法规为主干；以部委党内法规、地方党内法规为重要组成部分 |
| 党内法规 1+4 框架 | 党章之下分党的组织法规制度、党的领导法规制度、党的自身建设法规制度、党的监督保障法规制度<strong>四大板块</strong> |
| 全面依法治国总目标 | 建设中国特色社会主义法治体系、建设社会主义法治国家；即<strong>一个体系、一个国家</strong> |
| 全面依法治国根本目的 | 依法保障人民权益；不是维护国家长治久安 |
| 法治体系而非法律体系 | 称中国特色社会主义法治体系，<strong>不称法律体系</strong>，法治思想里没有「法律体系」这个词；它是全面依法治国的总抓手 |
| 社会主义法治理念 | 依法治国是核心内容；执法为民是本质要求；公平正义是价值追求；服务大局是重要使命；<strong>党的领导是根本保证</strong> |
| 关键少数与法治队伍 | 领导干部是全面依法治国的<strong>关键少数</strong>；法治工作队伍要革命化、正规化、专业化、职业化 |
| 总体国家安全观五要素 | 以人民安全为宗旨；以政治安全为根本；以经济安全为基础；以军事科技文化社会安全为保障；以国际安全为依托 |
| 国家安全五个统筹 | 统筹发展和安全、统筹开放和安全、统筹传统安全和非传统安全、统筹自身安全和共同安全、统筹维护国家安全和塑造国家安全；对应「既要重视外部又要重视内部」等<strong>五对关系</strong> |
| 国家安全工作最高原则 | 党的领导、绝对领导是<strong>最高原则和根本保障</strong>；国家利益至上是国家安全准则 |
| 政治安全的构成与核心 | 包括政权安全、制度安全、意识形态安全；<strong>核心是政权安全和制度安全</strong>，不含意识形态安全；依据 2022 年 4 月 20 日《总体国家安全观学习纲要》 |
| 党内法规不高于法律 | 党内法规<strong>严于法律但不高于法律</strong>，二者不能比高低；党员违法的制裁依据是法律；法律实施以政策为指导，但不能以党的政策代替法律 |
| 法律不是万能的 | 法律中心论、法律万能论均为<strong>错误选项</strong>；「A 与 B 有机统一」的表述都对，「毫无关系」的表述都错 |
| 执法过错终身负责 | 警察办案终身负责；即使是过错导致的错案也要终身负责，只看结果不看主观 |

## 课程口诀

::: tip
**口诀（十一个坚持前四条）：「党领人民先走路」**

党领导、以人民为中心、依宪治国依宪执政、中国特色社会主义法治道路。

课程位置：18:00。
:::

::: tip
**口诀（十一个坚持第十一条等）：「内外问题治理队伍抓少数」**

内外问题＝国内法治和涉外法治；治理＝治理体系和治理能力现代化；队伍＝德才兼备的高素质法治工作队伍；少数＝领导干部这一关键少数。

课程位置：22:30。
:::

::: tip
**口诀（十一个坚持结构记忆）：「二三四体系要记住」**

二＝国内法治与涉外法治；三＝三一三治；四＝立执司守；合起来是中国特色社会主义法治体系。

课程位置：24:00。
:::

::: tip
**口诀（全面依法治国的核心内容与根本保证）：「一知公福党，和本价使政」**

一＝依法治国（核心内容），知（执）＝执法为民（本质要求），公＝公平正义（价值追求），福（服）＝服务大局（重要使命），党＝党的领导（根本保证）；「和本价使政」是对应五个地位的串记

课程位置：34:30。
:::
