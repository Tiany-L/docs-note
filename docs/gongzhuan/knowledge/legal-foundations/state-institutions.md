# 国家机构

## 知识点速记

> 来源：2027 公专 P39 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 全国人大与常委会 | 全国人大是国家最高权力机关，行使最高监督权；<strong>全国人大会议不是常设机构</strong>，开会十余天即散会，闭会期间由常委会作为常设机构行使职权，常委会对全国人大负责 |
| 国务院与一府一委两院 | 国务院即中央人民政府，是政府的老大，省政府往上就是国务院；一府指国务院、一委指监察委、两院指法院检察院；<strong>公安部是国务院下属部门</strong>，比法检低一层；军委一般不考 |
| 常委会组成人员限制 | 常委会组成人员必须是<strong>本级人大代表</strong>；不得同时担任行政机关、审判机关、检察机关、监察委员会职务；乡级人大只限制主席、副主席不得任行政机关职务 |
| 修宪释宪与宪法监督 | 只有全国人大有修宪权；<strong>解释宪法只有全国人大常委会</strong>；监督宪法实施全国人大和常委会都有，选项里只给常委会时单选常委会 |
| 基本法与非基本法 | 全国人大制定基本法，即刑法、民法典等打地基的大法；常委会制定非基本法，如文物保护法、专利法、人民警察法，并对基本法有<strong>补充修改权</strong>，但不得违背公平、公序良俗等基本原则 |
| 特区基本法修改权 | <strong>特别行政区基本法只能由全国人大修改</strong>，常委会无权修改；普通基本法常委会可以修改 |
| 法律解释七个主体 | 两央即国务院、中央军委，两高即最高法、最高检，三委即监察委、全国人大各专门委员会、省自治区直辖市人大常委会，共七个主体；只能向<strong>全国人大常委会</strong>提出解释要求 |
| 全国人大选举产生人员 | 三席为国家主席、副主席、军委主席；两高为最高法院院长、最高检检察长；一主任为<strong>监察委主任，不叫书记</strong>；两组员为常委会组成人员、专门委员会组成人员 |
| 主席提名定总理 | 国务院总理由<strong>国家主席提名</strong>、全国人大决定；此项不开会期间不平移，常委会不能决定总理 |
| 总理提名定其他 | 副总理、国务委员、秘书长、各部部长、各委员会主任、审计长、人民银行行长，由总理提名、<strong>全国人大决定</strong>；问提名答总理，问决定答人大 |
| 闭会期间人事平移 | 全国人大闭会期间，常委会依总理提名决定副总理、国务委员、部长等国务院组成人员；<strong>唯独主席提名定总理这一句不平移</strong> |
| 免职的对应规则 | 常委会依委员长会议或总理提名撤销国务院个别组成人员；谁选举谁罢免、谁决定谁罢免，人大产生的人大罢免，常委会产生的常委会罢免 |
| 两高副职由常委会定 | 监察委主任、最高法院院长、检察长分别提名副主任、副院长、副检察长，报<strong>全国人大常委会</strong>决定 |
| 国民经济计划与预算 | 全国人大<strong>审查和批准</strong>国民经济和社会发展计划及执行情况报告、预算及预算执行情况报告；两类报告均由国务院提交 |
| 批省建与特区设立 | 全国人大批准省、自治区、直辖市的建置，<strong>决定特别行政区的设立及其制度</strong>；常委会、国务院均无权 |
| 战争与和平决定权 | 开会期间由全国人大决定；<strong>闭会期间由全国人大常委会决定</strong> |
| 勋章特赦的决定与宣布 | 常委会决定授予国家勋章和荣誉称号，<strong>国家主席颁布</strong>；我国无大赦只有特赦，常委会决定特赦，主席宣布 |
| 动员决定与实施 | 常委会决定全国总动员或局部动员；主席宣布；<strong>政府实施</strong>；决定、宣布、实施三者不混 |
| 紧急状态决定权 | 全国或整个省自治区直辖市进入紧急状态，由<strong>常委会决定、主席宣布</strong>；省区内部分地区由国务院决定、总理宣布 |
| 撤销违宪行政法规 | 常委会撤销国务院同宪法法律相抵触的行政法规、决定和命令；本质是比较权力主体大小，大的撤小的 |
| 发布决定命令的主体 | 只有<strong>国务院和县级以上地方政府</strong>才能发布决定和命令，其他机关不可；2023 年卷考过 |
| 法律监督机关是检察院 | 宪法只规定<strong>检察院</strong>是法律监督机关；公安、法院、监察委都不是，2023 年卷考过 |
| 监督权与报告义务 | 全国人大改变或撤销常委会不适当决定；国务院、两高对全国人大负责并报告；<strong>中央军委只负责不报告</strong>，因涉密 |
| 质询权人数门槛 | 开会时一个代表团或<strong>30 名以上</strong>代表书面提质询案；闭会时常委会组成人员<strong>10 人以上</strong>联名书面提；均必须答复，可口头可书面 |
| 暂停法律适用权 | 全国人大及常委会可授权特定事项，在规定期限和范围内暂时调整或暂停适用法律部分规定；<strong>实践证明可行后及时修改法条</strong> |
| 临时召集全国人大 | <strong>五分之一以上</strong>全国人大代表提议，可以临时召开全国人大会议 |
| 副部长由国务院任命 | 部长等正职由总理提名、全国人大或常委会决定；<strong>副部长等副职由国务院自行任命</strong> |
| 宪法宣誓范围与组织 | 人大及县级以上人大常委会选举或决定任命者、政府及监委法院检察院任命者就职时公开宣誓；<strong>政协主席不宣誓</strong>；谁产生谁组织，全国人大产生的由主席团组织 |
| 言论免责权 | 人大代表在人大各种会议上的发言和表决不受法律追究；<strong>散会后</strong>在街头辱骂他人照常追责 |
| 人身特别保护权 | 县级以上代表开会非经主席团许可、闭会非经常委会许可不受逮捕或刑事审判，现行犯先拘留再立即报告；<strong>乡级代表只报告不许可</strong>；是保护不是豁免，许可后照常追捕判刑 |

## 课程口诀

::: tip
**口诀（法律解释提请主体）：「一府三委两院省人常」**

同指七个提请主体，讲者说这条也行，但他更推荐上一条。

课程位置：23:30。
:::

::: tip
**口诀（全国人大选举产生人员）：「三席两高一主任，外加俩组员」**

三席＝国家主席、副主席、军委主席；两高＝最高法院院长、最高检检察长；一主任＝监察委主任。

课程位置：25:00。
:::

::: tip
**口诀（人事提名与决定）：「主席提名定总理，总理提名定其他」**

决定一律由全国人大作出；闭会期间只有后一句平移到常委会。

课程位置：30:30。
:::

::: tip
**口诀（人事免职）：「总理提名撤其他」**

与总理提名定其他同程序反向走，撤销由常委会作出。

课程位置：36:00。
:::

::: tip
**口诀（重大问题决策权）：「全国人大批省建」**

批＝批准省、自治区、直辖市建置；省建＝决定特别行政区设立及制度。

课程位置：42:00。
:::

::: tip
**口诀（紧急状态）：「紧急状态有分别，全国各省常委定，省内部分不方便，转眼再看国务院」**

全国或整省由常委会定、主席宣布；省内部分地区由国务院定、总理宣布。

课程位置：52:00。
:::
