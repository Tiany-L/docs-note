# 立法法与法律解释

## 知识点速记

> 来源：2027 公专 P37 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 基本法与非基本法 | <strong>全国人大</strong>制定基本法，如刑法、民法典、行政法；<strong>全国人大常委会</strong>制定非基本法，如文物保护法；二者统称法律，区分依据是制定主体，不是重要程度 |
| 全国人大与常委会关系 | 全国人大是最高权力机关，每年开会数日、散会即散；常委会是它的<strong>常设机构</strong>，处理日常国家事务；二者合称「全国人大及常委会」，区人大、省人大都无权制定法律 |
| 广义法律与狭义法律 | 广义泛指<strong>一切规范性法文件</strong>，老百姓口语「学法」即是；狭义特指全国人大及常委会制定的基本法与非基本法；题干问「法律」先看语境再定性 |
| 依法治国中法是广义 | 「依法治国」的法含宪法、法律、行政法规、部门规章、地方性法规、自治条例单行条例；是全部规范性法文件，取广义 |
| 依法依宪治国中法狭义 | 「依法、依宪治国」并列，宪法已单独列出；此处的法若仍作广义便与宪法重复冲突，故取<strong>狭义</strong>，仅指全国人大及常委会制定的法律 |
| 正式渊源 | 以宪法为核心，含宪法、法律、法规、自治条例单行条例；<strong>司法解释</strong>在我国也属正式渊源，作用是堵立法漏洞；正式渊源是法官可依据、警察可据以处罚的条款 |
| 非正式渊源 | 含政策、道德、信念、习惯、判例、民俗、社会思潮、社团规章、权威著作；<strong>可作参考、不能作依据</strong>，无明文规定的法律效力 |
| 党章不是法的渊源 | 党章只规范党员的行为、工作与生活；既不是正式渊源也不是非正式渊源，压根不是法的渊源 |
| 根本法优于普通法 | 宪法是母法、根本法，效力最高；治安管理处罚法、刑法、民法典都<strong>不能抵触宪法</strong> |
| 上位法优于下位法 | 由高到低：宪法—法律—行政法规—地方性法规与部门规章—地方政府规章；下位法不得抵触上位法 |
| 新法优于旧法 | 同一事项新旧规定冲突适用新法；如治安管理处罚法修改后旧程序规定未跟上，冲突部分让位；流氓罪被寻衅滋事罪取代即新旧更替 |
| 特别法优于一般法 | 治安管理处罚法只适用公安，优先于适用所有行政机关的行政处罚法；<strong>特别法条也优于一般法条</strong>，法条冲突同理 |
| 法律与行政法规主体 | 法律由全国人大及常委会制定；<strong>行政法规由国务院</strong>制定，国务院即中央人民政府，是行政机关的最高层级 |
| 地方性法规与规章主体 | 地方性法规—省级、设区的市及自治州人大及常委会；部门规章—<strong>国务院组成部门及直属机构</strong>，如公安部、财政部；地方政府规章—省级、设区的市政府 |
| 自治条例报批生效 | 自治区人大制定的自治条例、单行条例报<strong>全国人大常委会</strong>批准后生效；自治州、自治县人大制定的报<strong>省人大常委会</strong>批准后生效；2025 年联考考过审批 |
| 法文件命名看主体 | 名称只是表象，叫「条例」也可能是法律；一律按制定主体定性，国务院制定的文件即使叫「XX 法」也是行政法规 |
| 位阶实质比制定主体 | 上级大于下级；<strong>同级人大大于同级政府</strong>；比较前先把名称翻译成背后机关，法律→全国人大及常委会，行政法规→国务院 |
| 法规与规章冲突的裁决 | 地方性法规与部门规章对同一事项规定不一致：国务院认为适用<strong>地方性法规</strong>的，由国务院直接决定；认为适用<strong>部门规章</strong>的，提请全国人大常委会裁决；俗称交叉管，为避嫌 |
| 规章之间冲突裁决 | 部门规章之间、部门规章与地方政府规章之间不一致的，由<strong>国务院</strong>裁决；两者共同上级都是国务院，直接找共同上级 |
| 法律绝对保留事项 | 只能由全国人大及常委会制定法律：犯罪和刑罚；剥夺公民政治权利、<strong>限制人身自由的强制措施和处罚</strong>；司法制度即诉讼与仲裁；<strong>不得授权国务院</strong> |
| 相对保留与授权立法 | 绝对保留以外事项尚未制定法律的，全国人大及其常委会有权授权<strong>国务院</strong>按实际需要先制定行政法规；税收基本制度、海关基本制度属相对保留，已考过 |
| 修宪权与释宪权 | 只有<strong>全国人大</strong>能修改宪法；只有<strong>全国人大常委会</strong>能解释宪法；常委会没有修宪权 |
| 行政处罚设定权限 | 法律可设全部处罚；行政法规不能设<strong>限制人身自由</strong>；地方性法规不能设<strong>吊销企业或个人营业执照、限制从业</strong>，但可暂扣许可证执照；规章只能设警告、通报批评和一定数额罚款 |
| 行政许可设定权限 | 法律可设全部许可；行政法规可设经常性许可；地方性法规可设本行政区域内经常性许可；<strong>规章只能设临时性许可</strong> |
| 省级规章临时许可一年 | 省级政府规章可设<strong>一年内</strong>的临时性许可；期满仍需实施的，应提请本级人大及常委会制定地方性法规；国务院可决定全国性临时许可，不受一年限制 |
| 行政强制设定权限 | 法律可设所有行政强制；行政法规不能设<strong>限制人身自由、冻结存款汇款</strong>；地方性法规只能设查封、扣押；<strong>规章一律不得设定</strong> |
| 正式解释四类主体 | 立法解释—<strong>全国人大常委会</strong>；司法解释—最高法、最高检；行政解释—国务院及其各部委；监察解释—<strong>国家监察委</strong>；均为机关作出，可作执法依据 |
| 非正式解释 | 含学理解释、任意解释、无权解释；学者、教授、讲课老师对法条的解释属学理解释；不具约束力，<strong>不能作为执法依据</strong>；考试范围集中在学理解释 |
| 限制扩充字面解释 | 限制解释—字面含义比立法原意广，缩到原意，标志是「且」或逗号；扩充解释—字面窄，用「和」扩展；字面解释—既不扩大也不缩小，同义置换 |
| 解释方法的标志词 | 文义—「××的定义/概念」；体系又称系统—法之间无冲突、依据某原则；历史—参照历史事件；比较—出现国外；主观目的—立法者的立法意图；客观目的—不提倡、考不到 |
| 当然解释 | 举重以明轻：重的都不算犯罪，轻的更不算；举轻以明重：轻的构成犯罪，重的更构成；江苏卷爱用文言文出此题 |
| 提出法律解释要求主体 | 只有两央两高三位：<strong>国务院、中央军委</strong>；最高法、最高检；国家监察委、全国人大专门委员会、省级人大常委会；与「谁作解释」不是一回事 |
