# 法理学基础

## 知识点速记

> 来源：2027 公专 P36 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 法的概念 | 由国家制定或认可；由国家强制力保证实施。<strong>制定</strong>是从无到有，<strong>认可</strong>是从有上升为法律（依法治国先为口号，1999 年写入宪法）；并反映特定物质生活条件决定的统治阶级意志 |
| 法以权利义务为内容 | 法的主要内容是权利和义务，不是道德或习惯；同一事项可兼具双重属性，如受教育既是权利又是义务 |
| 法规范行为不约束思想 | 法调整人的外部行为；心里想什么、打算吃什么，法律管不着；一旦付诸行动才进入法的调整范围 |
| 国家强制力非唯一保障 | 国家强制力是法实施的<strong>最后</strong>保障；但守法的自觉、普法教育同样是法实施的保障途径，故「唯一保障」表述错误 |
| 法的三大本质 | 国家性，又称正式性、官方性，三者同指一物；阶级性；物质制约性，即经济基础决定上层建筑，法是上层建筑 |
| 本质题抓关键词 | 题干出现经济、物质生活条件→选物质制约性；出现国家制定、国家认可、强制力、正式官方→选国家性；出现统治阶级、整体意志、共同意识→选阶级性 |
| 法是历史的、普遍联系的 | 任何法都受客观规律和物质条件制约；概念之间是<strong>相对独立</strong>而非绝对独立，说「毫无联系」「一点关系没有」的选项必错 |
| 法以社会为基础、有滞后性 | 法的性质与功能由社会决定，法随社会变迁而变迁；法常滞后于社会（正当防卫解释因个案推动而更新）；立法者不是在创造法律，而是在表述法律 |
| 法反映整体意志 | 反映统治阶级的整体意志、共同意识，不是个别成员、个别派别意志的简单相加；一国法整体上是统治阶级意志，但并非每部法都只体现统治阶级意志，被统治阶级的某些要求也会被反映 |
| 法的六大特征 | 规范性；国家意志性；强制性；程序性；可诉性；普遍性。特征是概念拆开后的分项，不是新内容 |
| 平等不含立法平等 | 法律面前人人平等指<strong>执法、司法、守法</strong>平等；立法上允许合理差别，如低保、物质帮助权、姓氏选取、少数民族风俗 |
| 法的规范作用五种 | 指引自己；评价他人（法院判案、公安处罚）；预测对方后果；教育大家（普法宣传）；强制违法者（各类强制措施） |
| 强制作用择优选 | 单选优先选<strong>强制措施</strong>（强制传唤、拘传、拘留、逮捕），行政处罚只具强制性；多选可并选。同一行为可同时对应多个作用 |
| 法律万能论错误 | 法的作用有局限，只解决部分社会问题；法律万能论、法律中心论、法律万能主义一律判错 |
| 道德的双向作用 | 道德可促人守法，也可能促人违法；极端情形下道义感反而推动人越法，如辱母案 |
| 法律未经解释无法适用 | 法依赖语言表达，语言有模糊性；故法律解释必然存在、必须存在，司法解释年年出台 |
| 法产生最晚、范围最小 | 与道德、宗教相比，法产生最晚；调整范围最小；最具外在强制力；现代社会最需要 |
| 规则三要素 | 假定条件；行为模式；法律后果。法条常省略法律后果，三者不必全部呈现，但逻辑结构齐备 |
| 授权性 vs 义务性规则 | 有权、可以、享有→授权性（可为模式）；应当、必须→命令性；不得、禁止、不准→禁止性，后两者统属义务性；<strong>刑法分则的具体罪名即禁止性规则</strong>，无须标志词 |
| 权义复合规则 | 同一主体对同一事项既是权利又是义务；如全国人大制定基本法，既是其权利也是其义务 |
| 委任性 vs 准用性规则 | 按确定性程度分三类。委任性＝委托另一<strong>机关、部门</strong>制定实施办法；准用性＝参照另一<strong>法条、法文件</strong>执行；其余 99% 为确定性规则，内容明确、无需找帮手 |
| 强制性 vs 任意性规则 | 按能否变更分。强制性规则不许变动，如民警遇群众危难必须救助；任意性规则可协商，如子女随父姓或随母姓 |
| 规范性语句与陈述性语句 | 按条文表达分。带道义助词（应当、必须、禁止、可以）为规范性语句；不带则为陈述性语句。同一规则按不同标准可同时归入多类 |
| 规则具体、原则抽象 | 规则内容具体，如 8 小时、24 小时、3 天；原则内容抽象，如公序良俗、公平正义、人人平等；以「我国」「国家」开头、提政策（宽严相济、教育与处罚相结合）的都是原则 |
| 穷尽规则才用原则 | 有规则先用规则，无规则才用原则兜底；无更强理由不得弃规则直接用原则，除非为实现个案正义 |
| 秩序为基础、自由为最高 | 秩序是法的首要任务与基础（地基）；正义居中；自由是最高价值（塔尖）；秩序受自由与正义的规制 |
| 自由的界定 | 法理上的自由不是为所欲为，而是<strong>不想做什么就能不做什么</strong>；衍生出「法不禁止皆可为」 |
| 限制自由的四原则 | 伤害原则：侵害他人合法权益即禁止；冒犯原则又称法律道德主义：须<strong>既违法又违反道德</strong>，如卖淫嫖娼；家长主义：禁止自我伤害，如吸毒、自残、不系安全带；容忍原则兜底 |
| 分配正义与差别原则 | 分配正义即平等；差别原则即得其所应得、凭本事吃饭；个人需求原则由国家兜底，保障基本所需 |
| 权利可放弃、义务不可 | 选举权可行使也可不行使；义务教育等义务必须履行，不得放弃 |
| 价值位阶 vs 个案比例 | 位阶原则：高位阶优于低位阶，完全摒弃低位阶（自由优于秩序，如上位法优于下位法）；个案比例原则：两者兼用但低位阶保留必要限度，不可「大炮轰蚊子」，典型为紧急避险、调整摄像头方位 |
| 客观事实 vs 案件事实 | 客观事实是纯客观存在、各方均承认（转账 500 元、二人陌生）；案件事实即法律事实，是经价值判断、法律人认定后的事实（认定为卖淫嫖娼） |

## 课程口诀

::: tip
**口诀（法的规范作用）：「教育抢瓶子」**

教＝教育、预＝预测、强＝强制、评＝评价、指＝指引，五字对应五种规范作用

课程位置：47:30。
:::

::: tip
**口诀（法律规则的确定性程度分类）：「委任主体，准用文件，其他都是确定性」**

委任性规则找的是机关，准用性规则找的是法条法文件，其余均属确定性规则

课程位置：81:30。
:::
