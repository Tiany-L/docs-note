# 组织管理与基本政策

## 知识点速记

> 来源：2027 公专 P32 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 公安机关领导体制 | 中央集权与地方分权相结合；概括为统一领导、分级管理、条块结合，<strong>以块为主</strong>。 |
| 分级管理与条块结合 | 公安部管省厅、省厅管市局、市局管分局、分局管派出所；<strong>条</strong>是公安系统上下级，<strong>块</strong>是分局与同级党委政府；工资补贴由区政府财政发放，故以块为主。 |
| 职能体系四要求 | 职能科学、事权清晰、指挥顺畅、运行高效。 |
| 重大事项双重报告 | 县局发生重大案件既向市局报告，也向同级党委政府报告；市局重大部署须同时通报县委县政府；<strong>只报市局一头</strong>即为错项。 |
| 警衔五等十三级 | 警员、警司、警督、警监、总警监五等，合计十三级；<strong>一级、二级警员</strong>主要留作降衔使用，正常转正一般授三级警司。 |
| 警衔晋升年限 | 警员、警司三年晋一级；警督四年晋一级；警监为选升，无固定年限，与领导职务职级挂钩。 |
| 警衔与职务不挂钩 | 警监以上为高级警官，警督为中级，警司、警员为初级；<strong>警衔与职务不挂钩</strong>，普通民警可以是一级警督，年轻支队长可能只是三级警督。 |
| 离退休与警衔收回 | 离退休警衔不收回，可留作纪念但不得佩戴；调离公安岗位、辞职退职、被开除的收回警衔并缴回警官证；被开除公职、犯罪、被剥夺政治权利、判有期徒刑以上刑罚的<strong>取消警衔</strong>。 |
| 首次授衔批准权限 | 总警监、副总警监、一级警监、二级警监由国务院总理批准；三级警监和警督由公安部部长批准；警司由厅长批准；警员由省厅政治部主任批准；<strong>公安部直属局</strong>的警司由公安部政治部主任批准。 |
| 职务序列三类 | 分为警官、警员、警务技术三类；警官是领导指挥岗，警员是执行岗，警务技术是技术岗。 |
| 综合管理内设机构 | 多为处、室、部，如政治部、警务保障室、人事处；<strong>车管所</strong>属特殊的综合管理。 |
| 执法勤务内设机构 | 都带「队」：总队驻省厅、支队驻市局、大队驻分局、中队驻派出所；<strong>情报指挥中心</strong>（原 110 指挥中心）不带「队」也属特殊的执法勤务。 |
| 警官与警员的归属 | 警长是<strong>警员</strong>不是警官，属执行岗；政委、教导员、指导员是主管政治工作的警官。 |
| 派出所的定位 | 派出所是分局的<strong>派出机构</strong>，不属于内设机构，既不是综合管理也不是执法勤务；两队一室（社区警务队、案件办理队、综合指挥室）只是公安内部叫法，不能据此归类。 |
| 军警民改革去向 | 边防、警卫（特勤局）由武警划归公安；消防划归应急管理部门；<strong>海警</strong>虽带「警」字但不是警察。 |
| 内部执法监督与过错认定 | 内部执法监督的主管部门是<strong>法治</strong>不是督察，执法问题上督察要让位；执法过错由法治部门认定，处分由公安局党委会决定、以公安局名义下达并抄送纪委。 |
| 执法过错的判断标准 | 只看结果，不看过程，也不问故意还是过失；过错不影响案件处理结果正确性、效力的，<strong>不属于执法过错</strong>；办案实行终身追责。 |
| 公安工作特点 | 复杂性、艰苦性、危险性、易受腐蚀性（风险性）。 |
| 公安机关权力四分 | 行政执法权、刑事司法权、使用武器警械权、紧急状态处置权；行政执法权再分处置、处罚、监督检查、强制。 |
| 行政处置权三项 | 命令（责令霸座者离开座位）、取缔（取缔赌博点）、许可（特种行业发许可证）。 |
| 根本原则与党的领导 | 根本原则是坚持党对公安工作的绝对领导；体现在政治、思想、组织、决策、法治五方面；提四个意识、纲领路线方针政策是政治领导，提队伍建设、党内组织生活是<strong>组织领导</strong>。 |
| 根本路线与四懂四会 | 根本路线是群众路线；四懂为法律法规、业务知识、信息应用、群众心理；四会为化解矛盾、管控要素、处警办案、群众工作。 |
| 服务群众的边界 | 接待群众、公布联系电话、代办户口身份证、上门服务、社会公益活动属服务群众；<strong>执法办案、调查取证、追回被骗资金</strong>不属于；题目只能一步到位，禁止二次推导。 |
| 基本方针与路线区分 | 基本方针是党委领导下的专门机关与广大人民群众相结合，<strong>党是领导、公安是主导</strong>；仅当选项同时给出两概念时用：公安帮群众是根本路线，群众帮公安是基本方针。 |
| 易混表述总表 | 根本宗旨是为人民服务；执法思想核心是执法为民；根本保证是人民群众的支持；初心使命是人民公安为人民。 |
| 严肃与谨慎相结合 | 刑事政策共五项，首项即严肃与谨慎相结合，毛泽东 1945 年《论联合政府》提出；严肃即执法必严，谨慎即重证据重调查研究；总精神是<strong>稳准狠，准为关键</strong>。 |
| 依法从重从快 | 即「严打」，针对严重刑事犯罪分子；从重仍成立，<strong>从快</strong>现在不提倡，一味求快容易出虚假证据。 |
| 宽严相济的「宽」 | 表现为非犯罪化（年龄小不作犯罪处理）、非监禁化（缓刑、假释）、<strong>非司法化</strong>（刑事公诉案件和解）。 |
| 重证据与保障人权 | 重证据、重调查研究、严禁刑讯逼供；尊重和保障人权由宪法原则引入，是后来加的一项。 |
| 治安政策与教育处罚 | 基本政策中唯一的治安政策是教育与处罚相结合，教育为主、处罚为辅；先判案件性质，治安案件才选它，刑事案件对应<strong>宽严相济</strong>。 |
