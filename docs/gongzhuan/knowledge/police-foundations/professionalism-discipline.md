# 警察素养与纪律条令

## 知识点速记

> 来源：2027 公专 P30 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 公安基础知识分值 | 100 道题里约 7 到 8 分，10 分以内；2017 年之前占 100%，现在逐年缩减，减下来的分挪给公安业务能力；<strong>福建考纲仍写「公安基础知识」，实际考的已是公安专业科目</strong> |
| 人民警察六项素质 | 政治、业务、法律、文化、心理、身体；心理素质用题干长、图表多、压缩答题时间来考<strong>抗压能力</strong> |
| 首要政治品质 | 就是政治素质，核心是<strong>忠诚</strong>：对党忠诚、对人民忠诚、对法律忠诚；选项里没有「忠诚」就选贴边的，如「站在党的立场」「忠诚核心、捍卫核心」 |
| 职业道德七个特征 | 政治性、法律性、自觉性、他律性、示范性、导向性、职业性；他律性是<strong>迫使民警遵守职业道德的外在力量</strong>，如公安部禁令 |
| 三个最显著特征 | 鲜明的阶级性（公安姓党）、广泛的人民性（<strong>只有中国警察冠「人民」二字</strong>）、行为的表率性 |
| 职业道德规范十点 | 忠诚可靠、秉公执法、英勇善战、热诚服务、文明理性、严守纪律、爱岗敬业、甘于奉献、清正廉洁、团结协作；十点后各跟三个小点，<strong>合起来 40 点</strong> |
| 忠诚可靠 | 十点中考得最多；三忠诚即对党、对人民、对法律；<strong>多选题出现「忠诚可靠」基本都是正确选项</strong>，因带「党」层级最高 |
| 英勇善战三战 | 坚韧不拔＝持久战、机智果敢＝地道战、崇尚荣誉＝荣誉战；两类情形：<strong>与犯罪嫌疑人对抗、抢险救灾</strong>；选项写「英勇顽强」一律不选 |
| 热诚服务与文明理性 | 热诚服务对<strong>态度好</strong>的群众：情系民生、服务社会、热情周到；文明理性对<strong>态度不好</strong>的群众：理性平和、文明礼貌、诚信友善 |
| 严守纪律 | 遵章守纪、保守秘密、令行禁止；<strong>考得较少</strong> |
| 爱岗敬业 | 克尽职守、勤学善思、精益求精；题干出现<strong>创新工作法、建电子档案</strong>就选它，出题频次与忠诚可靠相当 |
| 甘于奉献 | 任劳任怨、顾全大局、舍身使命；题干出现<strong>民警牺牲</strong>必选此项 |
| 清正廉洁 | 艰苦朴素、情趣健康、克己奉公；<strong>情趣健康是指不沉迷酒场夜店</strong> |
| 团结协作 | 竞争合作、勇于担当、积极向上；与英勇善战对比记：<strong>一人独斗选英勇善战，团队作战选团结协作</strong> |
| 单选优选大点 | 选项里既出现十点中的大点、又出现其下三个小点，且是单选题时，<strong>一律选前面的大点</strong>，层级高者优先 |
| 考点名称的多种写法 | 问「职业道德规范」只是其中一种；职业素养、职业品质、职业品格、职业品德、职业宗旨、职业精神、职业要求、追求、准则，问的都是<strong>这 40 点</strong> |
| 核心价值观四词 | 忠诚、为民、公正、廉洁；忠诚＝根本政治要求、政治品格，为民＝根本宗旨、根本出发点和落脚点，公正＝价值追求（实体公正＋程序公正），廉洁＝内在要求、思想基础；<strong>先看选项，四词之外的一律排除，题干可不读</strong> |
| 治警十六字方针 | 对党忠诚是政治灵魂、服务人民是根本宗旨、执法公正（原文作「执法公证」）是价值取向、纪律严明是重要保证；<strong>提到政治、党、忠诚三者捆绑，提到宗旨即为民</strong> |
| 纪律五项 | 政治纪律、组织纪律、工作纪律、内务纪律、保密纪律；以人民警察法和公安机关人民警察纪律条令编写，<strong>考 2 到 3 分</strong> |
| 政治纪律 | 不得散布有损国家声誉形象的言论，不得参加非法组织，不得参加以反对国家为目的的集会游行示威，<strong>不得罢工</strong>；信仰只能有一个，即中国共产党 |
| 组织纪律 | 规律是<strong>老大说话你得听</strong>：不服从上级命令、擅自把 24 小时勤务改成 12 小时，均属此项；纪律部分最爱考 |
| 工作纪律与内务纪律 | 工作纪律又称执法执勤纪律：履行公务、秉公执法、文明执勤；内务纪律又称群众纪律，对内是人事管理选人用人公正，对外是文明理性不吃拿卡要；<strong>着装不规范也属内务纪律</strong> |
| 保密纪律与九不准 | 不得泄露国家秘密和警务工作秘密；公安一多半工作涉密；不得擅自发布涉警警务工作秘密的文字图片音视频，未经批准不得以警察身份开微博微信，<strong>头像不得用公安标识，须县级以上公安机关审批</strong> |
| 禁酒规定 | 工作日指<strong>24 小时</strong>，不是早八晚五，工作日晚上同样禁酒；值班备勤、安保任务、出差、学习培训及其他工作时间禁酒；不得上下级或单位之间互相宴请，不得接受管理服务对象宴请，不得出入私人会所、参加一桌餐，任何时间任何场所不得酗酒滋事 |
| 三项禁令与五条禁令 | 三项禁令（2013 年）：绝不允许面对群众危难不勇为、绝不允许酗酒滋事、绝不允许进入夜总会娱乐场所，违者<strong>先予禁闭</strong>，造成严重后果或影响恶劣的开除；五条禁令为 2003 年 1 月 22 日发布，近年已极少考 |
| 处分种类 | 行政处分六档由轻到重：警告、记过、记大过、降级、撤职、开除；<strong>警纪处分另算四种：降低警衔、取消警衔、停止执行职务、禁闭</strong>，看题干问哪一种 |
| 处分幅度规律 | 一般给记过或记大过，情节较重给降级或撤职，情节严重给开除；违规使用警用品、违规收钱、违规办证多为警告或记过；<strong>对待群众蛮横、故意刁难吃拿卡要、不按规定着装、非因公务着警服进娱乐场所，须造成不良影响才给警告</strong> |
| 直接开除情形（上） | 第一条自己逃往境外、非法出境，与第五条私放他人出境一起记；第二、三条参与或包庇纵容危害国家安全、黑社会组织犯罪；第四条向犯罪嫌疑人通风报信，多见于看守所民警；第六条以收费、罚款没收名义收钱物<strong>不出具票据</strong>；以上均直接开除 |
| 直接开除情形（下） | 第七条涉毒、卖淫嫖娼、色情淫秽、组织支持容留卖淫；第八条携枪饮酒、酒后驾车、工作期间或公共场所酗酒滋事，<strong>须造成严重后果</strong>；第九条把配备管理的枪支借出；第十条违反枪支管理规定构成犯罪；构成犯罪即同时触犯行政、党纪、警纪处分 |

## 课程口诀

::: tip
**口诀（职业道德七个特征）：「自导他子儿是政法」**

自＝自觉性，导＝导向性，他＝他律性，子儿＝职业性，是＝示范性，政法＝政治性、法律性

课程位置：08:00。
:::

::: tip
**口诀（人民警察职业道德规范十点）：「热爱中英文请团言饼干」**

热＝热爱人民／中＝忠诚可靠／英＝英勇善战／文＝文明理性／请（清）＝清正廉洁／团＝团结协作／言（严）＝严守纪律／饼（秉）＝秉公执法／干＝甘于奉献

课程位置：12:30。
:::

::: tip
**口诀（纪律条令直接开除情形）：「他是谁他是谁，喝着酒夹着枪开车独自去嫖娼，果然是大雷呀，黑风在打雷呀，出境不买票啊，活该被开除」**

喝酒夹枪＝携枪饮酒、酒后驾车；嫖娼＝涉黄涉毒；大雷＝危害国家安全；黑风打雷＝黑社会、通风报信；出境不买票＝非法出境、收钱不出票据

课程位置：72:30。
:::
