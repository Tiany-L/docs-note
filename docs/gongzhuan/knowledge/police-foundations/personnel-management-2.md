# 人事管理02

## 知识点速记

> 来源：2027 公专 P34 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 奖励原则 | 按绩施奖，看成绩业绩不看资历；以基层一线为重点；精神奖励与物质奖励相结合，<strong>以精神奖励为主</strong>。 |
| 奖励等级与金额 | 由低到高为嘉奖、三等功、二等功、一等功、<strong>授予荣誉称号</strong>，集体与个人同一序列；个人标准约嘉奖 2000 元、三等功 5000 元、二等功 1 万元、一等功 2 万元；因公牺牲或病故、生前有重大贡献或突出事迹的可追授。 |
| 奖励对象范围 | 集体含组织部门批准的建制单位（大队、派出所、处室）与临时成立的专班；个人限<strong>在职在编人民警察</strong>；辅警另设优秀辅警、有的地方改称四级嘉奖；离退休民警、在职在编工勤人员、公安院校学生参照执行。 |
| 特别优秀辅警 | 五年内获三次以上市级表彰、<strong>35 周岁以下</strong>；省考单设岗位供其竞争；<strong>不能直接转正</strong>，目前没有免试入警的通道。 |
| 借调民警奖励申报 | 在借调单位工作满<strong>一年以上</strong>的，由临时所在单位按申报程序申报；不满一年的由原单位申报。 |
| 见习期与初任培训 | 见习期 <strong>1 年</strong>；初任警培训 3 个月至半年，<strong>结业考试不合格即见习期不合格</strong>；另有初级、中级、高级执法资格考试，暂不与待遇挂钩。 |
| 荣誉称号与英模 | 个人授予荣誉称号即二级英模、一级英模；一级英模须由<strong>公安部会同人力资源和社会保障部</strong>审批，因英模家属享受国家待遇。 |
| 英模子女优待 | 一、二级英模子女符合条件的可保送公安院校；实际执行是<strong>大幅降分</strong>录取，并非免试入学。 |
| 一等功以上晋衔 | 受一等功以上奖励或荣誉称号的可<strong>提前晋升警衔</strong>，警衔工资随之上调；<strong>不能提前晋升职务</strong>。 |
| 县局市局审批权限 | 县局只能批集体、个人嘉奖；市局能批集体、个人<strong>三等功</strong>，三等功以下各级自然包含。 |
| 省厅审批权限 | 集体、个人最高批到<strong>二等功</strong>；个人一等功须<strong>经公安部批准</strong>；<strong>集体一等功省厅无权</strong>。 |
| 公安部审批权限 | 各级各类奖励均可批准，包括授予荣誉称号，是审批链条的顶端。 |
| 奖励载体与奖章 | 集体奖励给单位发奖金、举行受奖仪式、颁给奖状或奖牌，<strong>不发给个人</strong>；个人嘉奖只发证书（奖状），<strong>三等功以上及荣誉称号才有奖章</strong>。 |
| 处分三大类 | 行政处分（政务处分）、警纪处分、刑事处罚三条线；<strong>题干问哪一类就答哪一类</strong>，不得混串。 |
| 行政处分与影响期 | 警告、记过、记大过、降级、撤职、开除六种；影响期依次 6、12、18、24、24 个月，<strong>开除为终身</strong>；以 6 为基数逐级加 6，<strong>24 个月封顶</strong>。 |
| 处分决定与后果 | 由任免机关（公安局党委）或监察机关决定；处分期间不得职务、职级、级别晋升，已提的应延期；<strong>记过以上不得晋升工资档次，警告不影响</strong>。 |
| 不服处分的救济 | <strong>不能申请复议</strong>，处分与复议不搭边；可申请复核或申诉；复核申诉期间<strong>不停止执行</strong>，也不得因此加重处分。 |
| 警纪处分种类 | 降低警衔、取消警衔、停止执行职务、禁闭四项；降低、取消警衔由<strong>政工部门</strong>办理，涉罪则移送司法机关。 |
| 辞退法定情形 | 连续两年考核不称职（须连续）；不胜任现职又不接受其他安排、拒不接受机构调整安排；不履行义务不遵守纪律经教育仍不转变；<strong>旷工连续超 15 日或一年累计超 30 日</strong>。辞退是不适合干警察，与开除（违法犯罪，前集口诀复述）不同。 |
| 不得辞退与不得辞职 | 因公致残、患病负伤在医疗期内、女性孕期产期哺乳期不得辞退；未满<strong>最低服务年限 5 年</strong>、涉密岗位未满脱密期、重要公务未办完、正受审计纪律审查或司法程序未终结的不得辞去公职。 |
| 监督主体与分类 | 人大、检察院、法院、监察委、公安内部、社会监督六类；<strong>政协属社会监督</strong>；<strong>只有社会监督是间接监督</strong>，其余全部为直接监督；羁押（看守所）期间的监督属事中监督，没有「全程监督」这一说。 |
| 督察机构设置 | 公安部设督察委员会，由<strong>一名副部长</strong>任督察长，对公安部部长负责；县级以上公安机关督察机构由<strong>行政首长兼任</strong>督察长。 |
| 督察撤销变更权 | 针对本级所属单位和下级公安机关的错误决定、命令；由<strong>督察机构</strong>作出撤销或变更决定，报<strong>本级行政首长</strong>批准后执行。 |
| 停职禁闭的批准 | 同样由督察机构作出决定，但报<strong>督察长</strong>批准后执行，不是行政首长；两者常为同一人，答题仍须写督察长。 |
| 督察当场处置权 | 违反警容风纪的当场纠正；违规使用武器警械、警用车辆、警用标志的可暂扣；违法违纪情节严重或拒绝阻碍督察的，可带离现场。 |
| 停职禁闭期限与申诉 | 停止执行职务 <strong>10 日以上 60 日以下</strong>、禁闭 <strong>1 日以上 7 日以下</strong>；向作出决定机关的上一级机关申诉，公安部则向督察委员会申诉；不服停职 5 日内、不服禁闭 24 小时内决定是否撤销；申诉期间不停止执行。 |
| 内部监督与公安赔偿 | 内部监督含督察、法制、行政复议、公安赔偿，行政复议归属有争议、讲者主张属内部监督；<strong>内部执法活动监督的主管部门是法制</strong>，督察不越位；赔偿须行使职权行为违法、只看客观结果、行为与结果有因果关系；由<strong>单位赔偿</strong>，民警有重大故意或重大过失的单位事后追偿。 |
| 执法权威维护与澄清 | 执法权威工作委员会办公室设在督察；民警本人、近亲属或所在单位可申请，一般书面、紧急可口头；查实后在一定范围公开澄清、消除影响，已作处分的应撤销并恢复公职、原职务职级。 |
