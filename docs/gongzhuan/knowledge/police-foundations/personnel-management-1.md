# 人事管理01

## 知识点速记

> 来源：2027 公专 P33 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 录用条件六项 | 年满 18 周岁；拥护中华人民共和国宪法；良好的政治业务素质和良好品行；身体健康；高中毕业以上文化程度；自愿从事人民警察工作。<strong>18 周岁、高中</strong>是两条最硬的杠。 |
| 刑事处罚与劳动教养 | 曾被判刑，或依刑法被免除刑事处罚（低龄盗窃不追刑责也属此类）；被劳动教养、收容教育的，一律政审不过。<strong>免予处罚也算</strong>。 |
| 行政拘留与治安调解 | 结伙斗殴、盗窃、诈骗、哄抢、抢夺、敲诈勒索等受行政拘留即不合格，实务中只要被行政拘留过就过不了；<strong>治安调解可以过</strong>，但调解协议书要随政审材料报上级备案。 |
| 记大过以上处分 | 指在国企、央企、事业单位受过记大过，或被撤销党内职务以上处分；<strong>校内警告、记过不算</strong>。 |
| 辞退、开除与辞职限制 | 被机关取消录用、被机关或企业辞退、事业单位降低岗位等级或撤职以上均不合格；辞退原为 5 年内不得担任警察，现改为<strong>曾被辞退即不能当警察</strong>，开除则终身；领导职务引咎辞职或被责令辞职不满 <strong>3 年</strong>不合格；只限机关、事业单位、国企，私企辞退不算。 |
| 贪污贿赂与财经违纪 | 贪污、行贿受贿、利用职务之便为他人谋取利益；违反财经纪律、浪费国家或集体资财，均不合格。 |
| 黄赌毒与迷信活动 | 组织、参加、支持色情、吸毒、赌博、迷信活动的过不了；发朋友圈、抖音晒求签跳大神，被截图举报同样按参与迷信活动处理。 |
| 作弊与开除团籍学籍 | 在国家法定考试中组织作弊或本人作弊有记录的不得录用；曾被开除团籍，或高等教育期间被开除学籍的也不合格，<strong>校内警告、记过无影响</strong>。 |
| 三龄两历不得缺 | 出生日期、参加工作时间、入党入团时间、学历学位、经历不得缺失或造假；<strong>政审考察期限内补不全即不合格</strong>。 |
| 失信联合惩戒对象 | 被依法列为失信联合惩戒对象（老赖）不合格；房贷、京东白条等正常在还的不算，需到银行打征信记录。 |
| 网上不良言论 | 反对党、反对社会主义、反对法律法规、挑战国家执法权威、抹黑路线方针政策、诋毁公权力机关的言论要审；此项不在政审工作办法内，<strong>各省已逐步纳入</strong>。 |
| 家庭成员审查 | 父母、爷爷奶奶、姥姥姥爷必审，与本人关系密切的其他家庭成员（如抚养自己长大的亲属）也在内；家庭成员犯故意杀人、故意伤害致重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质等罪（复述口诀「烧杀奸抢，伤贩爆投」），或贪污贿赂数额巨大、情节严重受刑事处罚的；<strong>家庭成员有事，考生本人即不合格</strong>。 |
| 新警一年试用期 | 新录用后试用期 <strong>1 年</strong>，在警校培训，结业考试合格才正式任命；不合格取消录用。 |
| 领导职务任职条件 | 具有法律专业知识，不要求法律专业毕业；有组织管理能力、指挥能力；<strong>专科以上学历</strong>；经人民警察院校培训考试合格。 |
| 正副职任免程序 | 分局局长等正职提名，须事先征得上一级公安机关同意；副职任免只需征求上级意见；口诀「正职提名须同意，副职任免听意见」。 |
| 训练体制与五类 | 新版公安机关人民警察训练条例 2025 年 1 月 1 日施行；体制为统一领导、分工负责、分级管理、分类实施，由地方警校和市级训练基地承担；类别改为政治、入警、晋升、专业、发展<strong>五类</strong>，旧分类已废。 |
| 各类训练天数 | 政治训练每期不少于 <strong>5 天</strong>；入警训练警校 30 天、非警校社招及新调入 90 天；晋升训练不少于 15 天，须先培训取得编号才能申报警衔。 |
| 考核等次与内容 | 分优秀、称职、基本称职、不称职四等；一次优秀提前半年晋级晋衔，连续两年不称职辞退；内容为德、能、勤、绩、廉五方面，<strong>以政治素质和工作业绩为重点</strong>。 |

## 课程口诀

::: tip
**口诀（录用条件）：「限量自身十八高」**

限＝拥护宪法，量＝良好政治业务素质和良好品行，自＝自愿从事，身＝身体健康，十八＝年满 18 周岁，高＝高中毕业以上文化程度

课程位置：03:00。
:::

::: tip
**口诀（正副职任免）：「正职提名须同意，副职任免听意见」**

正职提名须上一级公安机关同意，副职任免只需征求上级意见

课程位置：27:30。
:::

## 待核对事项

::: danger
**以下为来源文件保留的疑点，复习时需结合原课或正式规定核对。**

- 17:00：「三零两例」应为「三龄两历」（年龄、工龄、党龄＋学历、经历），人事档案术语，语音识别疑似出错。
- 30:00：「现处级复植植物以下」疑为「县处级副职职务以下」，即入警训练 90 天的适用对象表述，需核对。
- 01:30：录用条件六条讲者称依新版人民警察法草案，尚未正式实施，第五条「高中毕业以上文化程度」大概率修改，口径未定。
:::
