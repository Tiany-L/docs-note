# 公安历史沿革

## 知识点速记

> 来源：2027 公专 P31 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 中央特科成立时间 | 有两种口径：<strong>1927年11月</strong>出自中央党史研究室，<strong>1927年12月</strong>出自公安部2013年《公安基础知识》教材；2022年国考卷按11月命题，2023年四川省考、2024年黑龙江省考按12月命题；做题先用其他选项排除 |
| 中央特科关键定位 | 成立于<strong>上海</strong>，是中央机关设立最早的保卫组织；由<strong>周恩来</strong>组织设立；任务是搜集情报、抓特务；骨干含龙潭三杰钱壮飞、李克农、胡底 |
| 国家政治保卫局 | <strong>1931年11月</strong>成立，设在<strong>江西瑞金</strong>；是最早人民政权的保卫组织；2022年之后开始频繁考其成立时间 |
| 陕甘宁边区人民警察 | <strong>1938年5月</strong>成立；简称边警，又称延安市警察队；是当时比较正规的警察组织；已不在土地革命时期的范围之内 |
| 社会部（中社部） | <strong>1939年2月</strong>成立；是在党的高级组织内设立的；任务仍是搜集情报、锄特 |
| 中央军委公安部 | <strong>1949年7月</strong>成立；在华北社会部与华北公安部的基础上建立；是现行公安部的前身 |
| 土地革命时期范围 | <strong>1927年8月</strong>至<strong>1937年7月</strong>；该时期成立的保卫组织是中央特科与国家政治保卫局；边警1938年5月成立，不属此期 |
| 首任部长与建部时间 | 首任部长<strong>罗瑞卿</strong>，副部长杨奇清；公安部于<strong>1949年11月1日</strong>成立 |
| 老枫桥经验 | 20世纪60年代初，浙江诸暨枫桥镇；由<strong>毛泽东</strong>批示要求各地效仿推广；做法是发动和依靠群众，坚持矛盾不上交、就地解决，实现捕人少、治安好 |
| 新时代枫桥经验 | 五个坚持：党建引领、人民主体、三治融合、四防并举、共建共治共享；党建是政治灵魂、人民主体是核心价值；内涵为矛盾不上交、平安不出事、服务不缺位 |
| 三治与四防 | 三治指<strong>自治、法治、德治</strong>；四防指<strong>人防、物防、技防、心防</strong>；人防靠巡逻、物防靠警械、技防靠监控、心防靠拒腐防变 |
| 东莱精神 | <strong>2020年</strong>由公安部党委提出学习弘扬；东莱派出所被国务院命名为人民满意的派出所；三个传家宝为百家熟、拒腐蚀永不沾、警民鱼水情；基本内涵为讲忠诚、爱人民、守廉洁、创平安 |
| 两队一室 | 即<strong>社区警务队、案件办理队、综合指挥室</strong>；派出所须有40%以上警力为社区民警；分局须有40%以上警力为派出所民警 |
| 2017年十六字总要求 | <strong>2017年5月19日</strong>全国公安系统英雄模范立功集体表彰大会提出；内容为对党忠诚、服务人民、执法公正、纪律严明 |
| 2018年现役部队改革 | 按<strong>「军是军、警是警、民是民」</strong>原则改革公安现役部队；边防、警卫（改设特勤局）转人民警察编制；消防转应急管理部为行政编制；海警转部队为军事编制 |
| 2019年公安工作会议 | <strong>2019年5月7日至8日</strong>召开全国公安工作会议；新十六字为政治建警、改革强警、科技兴警、从严治警；四个铁一般指理想信念、责任担当、过硬本领、纪律作风 |
| 人民警察节 | <strong>2020年7月21日</strong>确定；自<strong>2021年</strong>起每年1月10日；2021年1月10日为第一个人民警察节，此后按年份推算第几个 |
| 警旗与警歌 | <strong>2020年8月26日</strong>习近平总书记授旗并致训词；警旗为长方形，上红下蓝，红色喻党对公安队伍的绝对领导，蓝色喻职业特点；警歌为《人民公安向前进》，<strong>2017年6月</strong>确定 |
| 警徽构成要素 | 由<strong>国徽、盾牌、长城、松枝、飘带</strong>组成，<strong>2000年2月</strong>由公安部规定；国徽居中是国家的象征，长城与盾牌喻维护主权和领土完整，松枝喻坚贞不屈的革命意志，飘带的作用是美观 |
| 人民警察誓词 | 最新版<strong>2021年11月18日</strong>公布；开头为我是中国人民警察、我宣誓坚决拥护中国共产党的绝对领导、矢志献身崇高的人民公安事业；结尾为捍卫政治安全、维护社会安定、保障人民安宁而英勇奋斗 |
| 公安机关性质 | 人民民主专政的重要工具，即<strong>阶级属性</strong>，也称政治属性、根本属性；具有武装性质的治安行政力量和刑事司法力量，即组织属性；是行政机关，是国家意志的忠实执行者，属暴力机关但不是唯一暴力机关 |
| 公安执行的刑罚 | 公安执行<strong>拘役、剩余刑期三个月以下有期徒刑、剥夺政治权利、驱逐出境</strong>；剩余刑期按判决执行前羁押一日折抵一日计算；折抵后不足三个月由看守所执行，判两个月但从未羁押折抵的仍送监狱 |
| 新时代职责定位 | 首要任务是捍卫<strong>政治安全</strong>，政治安全是党和国家的生命线、公安机关的首要职责；基本任务是社会大局稳定；价值追求是公平正义；根本目标是人民安居乐业 |
| 专政与民主职能 | 专政对敌人、秘密进行；民主对人民、<strong>公开进行</strong>；二者对立统一，目标和方法不能混淆；专政是民主的基本保障，民主是专政的社会基础 |
| 公安职责五性 | 即法律性、政治性、行政性、有限性、责任性；近年考查频率已下降，本部分分值在压缩 |
| 综治六个环节 | 依次为打击、防范、教育、管理、建设、改造；打击是首要环节，防范是基本措施，教育是战略性措施，管理是重要手段，建设是关键，改造是特殊预防；方针是打防结合、预防为主 |
| 教育与改造之分 | 面向学生、群众的普法警示课堂属于<strong>教育</strong>；面向在押罪犯的普法课堂属于<strong>改造</strong>；两者按对象区分，不看形式 |
| 非工作时间履职 | 人民警察没有上下班之分，<strong>24小时</strong>待岗待命；休假期间遇抢劫、盗窃等紧急情况应当履行职责；不存在「暂时性履行职责」这一说法 |

## 课程口诀

::: tip
**口诀（成立前保卫机关时间）：「2712中央科，3111保卫局，人民边警385，三舅爱当社会人，四舅气到公安部」**

2712＝1927年12月（一说11月）中央特科；3111＝1931年11月国家政治保卫局；385＝1938年5月边警；三舅＝1939年2月社会部；四舅＝1949年7月中央军委公安部

课程位置：09:00。
:::

::: tip
**口诀（社会治安综合治理六个环节）：「赵范建打管教」**

赵＝改造的「造」，范＝防范，建＝建设，打＝打击，管＝管理，教＝教育；讲者用老赵不服管教的故事串起来

课程位置：64:00。
:::

::: tip
**口诀（公安机关职责五性）：「行政法有责」**

对应行政性、法律性、有限性、责任性

课程位置：58:30。
:::
