# 内务条令

## 知识点速记

> 来源：2027 公专 P35 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 内务条令规范的内容 | 规范人民警察的<strong>工作、学习、生活</strong>秩序；着眼于公安机关内部工作秩序与对外联系活动；2023 年联考即考此点，干扰项「感情和睦」不选。 |
| 内务建设基本原则 | 政治建警、改革强警、科技兴警、从严治警；其后另加<strong>从优待警</strong>与战斗力标准；前四项为 2019 年全国公安工作会议提出。 |
| 改革强警的层级责任 | 党委领导、部级抓总、省级主责、市县主战、<strong>派出所主防</strong>；五级须按顺序记全，多年连续考查。 |
| 新型警务运行模式 | 专业、机制、<strong>大数据</strong>三者合成一体；记「大专机」——大＝大数据、专＝专业、机＝机制；2025 年多次考查。 |
| 荣誉仪式的组织权限 | 只有<strong>县级以上</strong>公安机关可以组织；适用于新警入警、授衔、表彰奖励、从警 30 年等特殊年限、退休等节点；派出所为退休民警办仪式是错项。 |
| 两类宣誓与适用人员 | 公安机关新任命的领导干部、新入职民警均应进行宪法宣誓；新警还须进行<strong>入警宣誓</strong>（人民警察宣誓）。 |
| 宪法宣誓的组织与场所 | 由<strong>任命机关</strong>组织，按干部管理权限确定宣誓人和组织人；场所悬挂国旗或国徽、奏唱国歌；民警着统一制式警服、其他人员着正装，面向国旗国徽举右拳。 |
| 入警宣誓的旗歌与顺序 | 悬挂国旗和警旗（不含国徽）、奏唱国歌和警歌；新警应<strong>先授衔授装、再宣誓</strong>；2025 年国考即考这一顺序。 |
| 入警宣誓的组织与时点 | 由县级以上公安机关<strong>政工部门</strong>或受委托的公安院校训练基地组织；在入警培训合格、上岗之前宣誓；宣誓前对宣誓人员进行集体教育。 |
| 上下级关系的认定 | 领导职务高的为上级、职务相同为同级；无领导职务或难以确定时，以<strong>警衔高</strong>者为上级；政治上地位一律平等，互为同志关系。 |
| 命令的下达与越级 | 原则上逐级下达，情况紧急可以越级下达；越级下达时除特殊情况外，应将命令通知受令者的<strong>直接上一级</strong>；下级也可直接向上级报告。 |
| 命令异议与拒绝执行 | 认为命令有错误<strong>可以</strong>提出意见（不是应当），但不得终止或改变执行，后果由下达命令的上级负责；明显超越法定职责的命令有权拒绝，并向下达命令者的<strong>上一级</strong>报告。 |
| 越级命令的报告时限 | 接到越级命令必须坚决执行；执行的同时直接上报，因故不能报告的，应在障碍情形解除后<strong>24 小时</strong>内报告。 |
| 不同建制与抽调管理 | 不同建制民警共同执行任务，服从统一上级指定的负责人指挥；建制不明找在场最高领导，仍难区分看警衔；抽调民警接受<strong>抽调单位</strong>领导管理，除特殊要求外定期向原单位报告。 |
| 不得着装的情形 | 执行侦查、警卫、外事等特殊工作；工作期间<strong>非因公外出</strong>；女民警怀孕期间；被留置、停止执行职务、禁闭或被采取刑事强制措施。 |
| 仪容与发式要求 | 不得化浓妆、留长指甲、染指甲；男民警不得留长发、大鬓角、卷发、胡须，除病理因素外不得剃光头；女民警长发盘起，发辫<strong>不得过肩</strong>；除工作需要或眼疾外不戴有色眼镜。 |
| 换装与警用标志收回 | 换装由<strong>市级以上</strong>公安机关统一确定时间和要求，由市局政治部下文；调离、辞职、辞退、开除公职的收回警官证、警服、警衔、警号；离退休可以保留<strong>一套</strong>警服或警衔警号作纪念。 |
| 警容举止与同行规范 | 两名以上民警外出，两人成行、三人成列；不得在公共场所吸烟、嬉笑打闹；不得背手、袖手、插兜、搭肩、挽臂、叉腰。 |
| 饮酒禁止 | 工作期间不得饮酒；不得携带枪支饮酒；未经审批不得着警服饮酒；<strong>一级勤务</strong>期间同样不得饮酒。 |
| 救助的定性 | 遇人民群众生命财产受威胁，应当积极救助或寻求支援；2024 年国考按<strong>义务</strong>命题，依据人民警察法第三章「义务和纪律」，不选职责。 |
| 学习与会议制度 | 每月至少组织 1 次集中学习；市局每年至少召开 1 次年度工作会议，县局每年至少 1 次全体大会或民警代表大会；年度会议可邀请群众代表参加。 |
| 请示报告制度 | 可以口头或书面，口头应有记录留痕；下级一般<strong>半年</strong>报告一次工作情况和队伍建设情况；双重领导、条块结合以块为主，向负主要职责的上级报告并抄报另一上级。 |
| 请销假制度 | 局长与政委（分管日常工作的负责人）不得同时离岗；非因公外出应请假，未经批准不得逾期不归；工作需要召回的必须立即返回。 |
| 人民警察证管理 | 由<strong>公安部</strong>统一制发、实行分级管理；严禁向非警察人员配发；上交、发放的证件应予回收；工作期间一般应携带。 |
| 窗口单位的范围 | 与群众直接接触的才算，如户政大厅、车管所、交通违法处理、派出所报警室；<strong>警务保障室、政治部办公室</strong>不是；报警接待 24 小时，其他窗口可实行弹性工作。 |
| 值班备勤与影像保存 | 24 小时值班备勤、领导带班，各部门设值班室；值班影像监控保存不得少于 <strong>90 日</strong>，办案区、办公区同为 90 日，其他区域不少于 30 日；值班备勤前 12 小时至结束后不得饮酒。 |
| 警车驾驶规范 | 除工作需要外应着警服，携带行驶证、驾驶证、人民警察证<strong>三证</strong>；<strong>实习期</strong>民警不得驾驶警车；除执行重大紧急任务外按规定地点停放，途中遇群众报警应及时受理。 |
| 授旗与阅警的组织 | 授旗由授旗单位所隶属或上级公安机关组织实施，通常在单位新组建成立时进行，程序为宣布开始、唱国歌、宣读决定、授旗人讲话、民警宣誓、唱警歌、宣布结束；阅警由<strong>设区的市级以上</strong>公安机关经上级（省厅）批准举办。 |

## 课程口诀

::: tip
**口诀（新型警务运行模式）：「大专机」**

大＝大数据、专＝专业、机＝机制，对应专业、机制、大数据的新型警务运行模式。

课程位置：07:30。
:::

::: tip
**口诀（不同建制的指挥）：「建制不同听上级，建制不明找领导，难以区分看警衔」**

共同执行任务先听统一上级指定的负责人；建制不明找在场最高领导；仍难区分看警衔高低。

课程位置：36:00。
:::

## 待核对事项

::: danger
**以下为来源文件保留的疑点，复习时需结合原课或正式规定核对。**

- 04:30：「科技刑警」疑为「科技兴警」的同音误识，同一段讲解中两次出现，需核对讲者原话与条令原文。
- 06:00：「党委领导不及抓种、省级主折、视线主战、拍手术主房」一段识别严重失真，应为「部级抓总、省级主责、市县主战、派出所主防」，其中「视线」是否为「市县」无法从音频稿确认。
- 07:30：「大专机」口诀中「专」对应专业还是专业机制，讲者口述含糊，按上下文记为「专业」。
:::
