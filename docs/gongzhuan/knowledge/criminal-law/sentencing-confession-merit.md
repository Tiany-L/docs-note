# 量刑、自首、坦白、立功

## 知识点速记

> 来源：2027 公专 P17 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 累犯的两种类型 | 分一般累犯与特殊累犯；总则里与正当防卫并列的高频考点；字面理解就是屡教不改、反复犯事 |
| 一般累犯·故意要件 | 前后两罪都必须是故意犯罪；过失犯罪一律不行，最典型的是<strong>交通肇事罪</strong>；一罪故意一罪过失也不构成 |
| 一般累犯·刑度要件 | 前后两罪都必须是有期徒刑以上的刑罚；<strong>管制、拘役不行</strong>；两罪都要满足，缺一不可 |
| 一般累犯·时间要件 | 后罪须发生在前罪<strong>刑罚执行完毕或赦免以后五年内</strong>；「刑罚执行完毕」是判断累犯的核心时间点，后面假释、缓刑全靠它 |
| 一般累犯·年龄要件 | 不满 18 周岁的人犯罪不构成累犯；前后两罪行为时都须<strong>已满 18 周岁</strong>；犯第一个罪时未满 18 也不构成 |
| 一般累犯四要件串记 | 按顺序串成一句：故意—有期—五年内—两罪均需 18 岁；考场先默口诀再逐条对要件 |
| 假释与假释考验期 | 假释＝<strong>假装释放</strong>，刑期未满提前出狱；考验期内表现不好收监续服，表现好则期满转为真正释放；考验期满之日才等于刑罚执行完毕之日 |
| 假释考验期内又犯罪 | 不构成累犯；此时刑罚<strong>尚未执行完毕</strong>，「执行完毕五年内」这个要件直接不符合；前后虽都是故意、都有期、都满 18 岁也不行 |
| 假释期满后五年内又犯罪 | 构成累犯；假释考验期满＝刑罚执行完毕；从期满之日起往后数五年内再犯新罪即成立 |
| 缓刑与缓刑考验期 | 判三缓二，考验期在<strong>前</strong>而非在后；考验期内表现好，原判三年不再执行；表现不好才收监执行 |
| 缓刑考验期内又犯罪 | 不构成累犯；刑罚<strong>压根没有开始执行</strong>，谈不上执行完毕；这个节点离「执行完毕」还差得远 |
| 缓刑期满后再犯罪 | 也不构成累犯；考验期合格则原判刑罚不再执行，没有「执行完毕」这个点；只有考验期不合格、原判刑罚照常执行完毕，此后五年内再犯才构成累犯 |
| 特殊累犯的罪名与时间 | 前后两罪都是<strong>国恐黑</strong>：危害国家安全、恐怖活动、黑社会性质组织犯罪；三者可任意搭配，不要求同种；<strong>没有时间间隔限制</strong>，隔多少年都算；两罪仍须均满 18 周岁 |
| 自首的两类与从宽 | 分一般自首与特别自首；对自首的犯罪分子<strong>可以</strong>从轻或减轻处罚；犯罪较轻的<strong>可以</strong>免除处罚；都是「可以」不是「应当」 |
| 一般自首的定义 | 自动投案＋如实供述<strong>公安机关未掌握</strong>的本人罪行；大白话：你没查到我，我自己上门说 |
| 投案的两种特殊情形 | 仅因<strong>形迹可疑</strong>被有关组织或司法机关盘问、教育后主动交代的，视为自动投案；向所在单位、村委会居委会等城乡基层组织投案的，也认定为自首 |
| 投案后逃跑的认定 | 自动投案后又逃跑的，不成立自首；自首成立后逃跑、再回来投案的，仍成立；规律是<strong>捏住小尾巴</strong>——最终以自首收尾就是自首 |
| 被动归案后的投案 | 被采取强制措施后逃跑、再投案的，原罪不认定自首；但逃跑期间<strong>新犯的罪</strong>如实供述的，新罪仍成立自首 |
| 亲友送首的界限 | 亲友规劝、陪同、送去投案的，属自首；亲友<strong>捆绑</strong>送去、或带侦查人员上门抓捕的，不属自首 |
| 对罪名定性的辩解 | 承认事实、只对<strong>罪名定性</strong>有不同理解并辩解的，仍属如实供述，成立自首；如自认盗窃、公安认定抢劫 |
| 共犯与数罪的自首 | 共犯除供述自己罪行，还须供述<strong>所知道的同案犯</strong>罪行，否则不成立；犯数罪只如实供述部分的，仅该部分认定自首 |
| 翻供对自首的影响 | 自首后翻供的，不认定自首；翻供后又如实供述的，仍认定；最迟算到<strong>一审判决前</strong>仍如实供述的，仍为自首 |
| 坦白 | 供述公安机关<strong>已掌握</strong>的本人罪行；可以从轻处罚；因如实供述避免特别严重后果发生的，可以减轻处罚 |
| 立功 | 揭发<strong>他人</strong>的犯罪行为；一般立功可以从轻或减轻处罚；重大立功可以减轻或免除处罚 |
| 立功须本人实施 | 必须是<strong>犯罪分子本人</strong>揭发；家属代为揭发的，不能算在本人头上，不构成立功 |

## 课程口诀

::: tip
**口诀（一般累犯的构成要件）：「故意有期五年内，两罪均需18岁」**

故意＝前后两罪均为故意犯罪；有期＝两罪均为有期徒刑以上；五年内＝后罪在前罪刑罚执行完毕或赦免后五年内；18 岁＝两罪时均满 18 周岁

课程位置：04:00。
:::
