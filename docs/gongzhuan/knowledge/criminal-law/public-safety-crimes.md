# 刑法分则、危害公共安全罪

## 知识点速记

> 来源：2027 公专 P20 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 本章的考查方式 | 刑法分则第三大类，考查频率高；多以<strong>具体警情</strong>、案例模型方式出题，判断时必须落到情节 |
| 以危险方法的危险性质 | 必须是<strong>具体危险</strong>，不能是抽象危险；靠抽象思维推想「万一将来发生」的，不是本罪的危险 |
| 具体危险的典型情形 | 多人通行处私拉电网、火灾现场破坏消防器材、破坏<strong>矿井通风设备</strong>、邪教人员自焚自爆、传播突发传染病病原体、高速逆行、公共场所随意冲撞、醉驾肇事后再冲撞；危险都在当下且紧迫 |
| 危险内容的范围 | 只限<strong>人身伤亡与财产损失</strong>；不含恐慌、焦虑等精神损害，精神层面的损害不入本罪 |
| 投放虚假危险物质罪 | 寄面粉冒充传染病病原体或剧毒物，引起单位与社会恐慌的；按<strong>投放虚假危险物质罪</strong>，不成立以危险方法危害公共安全罪 |
| 公共安全的判断标准 | 公共安全指危险范围不固定、无法预料、不可估量；<strong>对象特定</strong>的伤害（如只刺指定几名学生）按数个故意伤害罪处理 |
| 危险程度与兜底定位 | 危险须达到与放火、爆炸、投放危险物质罪<strong>相同</strong>的程度；不是够不上就降一格的次等罪名；同为兜底罪名的还有寻衅滋事罪 |
| 明确罪名的优先适用 | 符合其他罪名构成要件的，优先定其他罪；劫持火车电车定破坏交通工具罪；盗窃道路上的井盖定<strong>破坏交通设施罪</strong> |
| 交通肇事罪的罪过 | 是<strong>过失犯罪</strong>，没有例外；题干问「故意犯罪」时不选交通肇事罪 |
| 交通肇事罪的成立条件 | 违反交通法规，并发生<strong>重大事故</strong>；事故须致人伤亡或造成重大财产损失，两个要件齐备 |
| 交通肇事罪的主体 | 不限于驾驶员，<strong>行人</strong>也能构成；行人闯红灯致后车连环相撞、有伤亡或财产损失的同样入罪 |
| 交通肇事罪的地点 | 须发生在公共交通领域即马路上；驾校训练场等<strong>内部培训场地</strong>不算，可定过失致人死亡罪 |
| 交通肇事罪的入罪门槛 | 死亡 1 人，或重伤 3 人；<strong>重伤 1 人</strong>须再加酒驾、毒驾、无证、严重超载、肇事逃逸之一 |
| 逃逸的认定 | 逃逸指<strong>逃避法律追究</strong>，不是逃离现场；须明知已发生事故；离开现场求救、报警的不算逃逸 |
| 因逃逸致人死亡 | 属不作为犯罪，要有作为义务和<strong>作为可能性</strong>；因家属阻挠、殴打等客观原因救不了的，不构成这一升格 |
| 带离现场隐藏遗弃 | 为逃避追究将被害人带离现场后隐藏或遗弃，致其无法获救而死亡或伤残的；分别按<strong>故意杀人罪</strong>、故意伤害罪处 |
| 肇事行为与肇事罪的界分 | 前行为只是交通肇事行为、未构成肇事罪时，后行为单独定罪，<strong>不并罚</strong>；前行为已构成肇事罪，才与故意杀人、故意伤害罪并罚 |
| 肇事后抛尸的处理 | 误以为被害人已死亡而抛尸，实际溺水身亡的；定交通肇事罪与<strong>过失致人死亡罪</strong>并罚 |
| 追逐竞驶型危险驾驶 | 须情节恶劣才构成；<strong>一人</strong>也可以与时间比，计时赛、绕环线跑同样算追逐竞驶 |
| 醉驾的酒精标准 | 血液酒精 <strong>80mg/100ml</strong> 为醉驾，20mg/100ml 为酒后；醉驾不要求情节恶劣，是危险犯，有行为即构成 |
| 超载超速与危化品运输 | 从事校车业务或旅客运输，严重超载或严重超速；<strong>违规运输危险化学品</strong>危及公共安全的，均按危险驾驶罪 |
| 醉驾加暴力抗检 | 醉驾又以暴力、胁迫方法阻碍公安检查的，同时构成<strong>妨害公务等罪</strong>；具体罪名还看暴力程度与对象是民警还是辅警 |
| 危险驾驶罪的罪过 | 是<strong>故意犯罪</strong>；不知情被利用（吃荔枝、饮料被掺酒）的不构成，利用者成立间接正犯 |
| 妨害安全驾驶罪的前提 | 三种情形都以<strong>行驶中</strong>的公共交通工具为前提；车辆停靠、未启动、未行驶的，抢方向盘也不构成犯罪 |
| 妨害安全驾驶罪三情形 | 乘客打司机；乘客抢方向盘；司机与乘客争执中动手、<strong>双手脱离控制装置</strong> |
| 抢方向盘的罪名变迁 | 2021 年 3 月 1 日刑法修正案（十一）生效前，按以危险方法危害公共安全罪；生效后定<strong>妨害安全驾驶罪</strong> |
