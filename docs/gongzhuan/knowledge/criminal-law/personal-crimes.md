# 刑法分则、人身犯罪

## 知识点速记

> 来源：2027 公专 P18 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 故意杀人罪 | 故意非法剥夺他人生命，法益是<strong>他人生命权</strong>；分则罪名概念简单，考试按案例模型记构成要件，光背法条不会用 |
| 安乐死仍构成故意杀人 | 生命权<strong>绝对保护</strong>，不得承诺放弃；即使被害人自愿、双方签免责协议，实施者仍构成故意杀人罪（部分国家允许安乐死，我国不允许） |
| 帮助自杀仍构成故意杀人 | 递毒药等帮助自杀行为按<strong>多数说</strong>构成故意杀人罪；少数说依共犯从属性认定无罪（自杀者无罪、帮助者亦无罪），做题按多数说 |
| 伤害承诺按伤情分档 | 轻伤及以下承诺有效，砍掉小指不构成犯罪；<strong>重伤</strong>承诺无效，砍掉右臂仍构成故意伤害罪；摘取器官是重伤承诺的例外，可承诺 |
| 故意伤害罪构成要件 | 主观须有造成<strong>轻伤</strong>的意图；客观行为须有造成轻伤的一般可能性；仅一般推搡、两要件皆无，不构成伤害致死，有过失定过失致人死亡罪 |
| 连砍数刀致死如何定性 | 先伤害后生杀意、只一刀致命且查不清第几刀，按<strong>第一刀</strong>主观定性，伤害目的即故意伤害致死；不得拆成故意伤害与故意杀人两罪并罚（「死得越早对兄弟们越有利」系白老师观点，此处为复述） |
| 遗弃罪的对象与方式 | 对象为年老、年幼、患病或无独立生活能力且负有扶养义务的人；<strong>积极丢弃</strong>与消极不管不顾均可构成，不是只有「扔」才成立 |
| 遗弃与故意杀人的界限 | 看生命权受威胁是否<strong>紧迫</strong>；弃于医院、福利院、民政局、农户门口为遗弃，弃于废弃厂房、荒山野岭构成故意杀人 |
| 强奸罪的手段与三不 | 暴力、胁迫或其他手段，致妇女<strong>无法反抗、不敢反抗、不知反抗</strong>；违背妇女意志强行发生性关系 |
| 强奸罪主体与女性共犯 | 直接实行犯只能是男性；女性可成立教唆犯、帮助犯，对实行者形成<strong>支配力</strong>时成立间接正犯 |
| 胁迫须以恶害相通告 | 恶害须由行为人对<strong>被害人</strong>施加并使其产生恐惧；许诺给女一号属利诱、「不上床我就自杀」属对己，均不构成强奸罪 |
| 昏醉型与冒充型强奸 | 用药物麻醉、酒精麻痹致不知反抗后性交；冒充妇女丈夫或情人骗奸；均属暴力胁迫以外的其他手段 |
| 奸淫幼女的明知 | 幼女已满12不满14须<strong>明知</strong>是幼女才构成强奸罪；不满12周岁不要求明知；幼女同意亦构成 |
| 负有照护职责人员性侵罪 | 对象为已满14不满16周岁未成年女性，须发生性关系、不含猥亵；主体照护职责须<strong>稳定</strong>，辅导员构成，课外班老师、一次性接诊医生不构成 |
| 14-16 岁承诺效力 | 对<strong>照护人</strong>同意性交构成本罪、不同意构成强奸；对一般人同意性交无罪、不同意构成强奸；同意猥亵的承诺有效，不同意定强制猥亵 |
| 强制猥亵罪与猥亵儿童罪 | 法益为<strong>性羞耻心</strong>（强奸罪为性自主权）；主体须已满16周岁；对象为已满14周岁的人，男女均可，猥亵不满14周岁定猥亵儿童罪，更重 |
| 猥亵的三种方式 | 直接对他人实施；强迫他人对行为人自己或第三人实施；强迫他人观看第三人猥亵 |
| 强制侮辱罪与侮辱罪 | 强制侮辱罪法益为<strong>性羞耻心</strong>，侮辱罪法益为名誉；同词不同义，须按罪名分别记 |
| 非法拘禁罪的认定 | 非法剥夺他人人身自由；<strong>欺骗</strong>使被害人误以为自己出不去亦构成；仅如实告知病情、建议别外出不构成 |
| 绑架罪的性质与公式 | 属人身犯罪而非财产犯罪；<strong>绑架＝非法拘禁＋敲诈勒索</strong>；以向第三人提不法要求为目的实力控制人质 |
| 绑架罪的既遂与人质 | 勒索行为可有可无，未开口要钱、要钱未得均既遂；人质须能引起<strong>第三人担忧</strong>，不能引起担忧者不构成绑架罪 |
| 绑架与非法拘禁竞合 | 二者为<strong>法条竞合</strong>的包容关系；定绑架罪即不再与非法拘禁罪、敲诈勒索罪数罪并罚 |
| 为索债拘禁定非法拘禁 | 为索取债务扣押、拘禁他人，无<strong>非法占有目的</strong>，只构成非法拘禁罪；拘禁债务人亲属向债务人索债亦然 |
| 超额索财转化为绑架 | 欠30万索30万仍为非法拘禁；索300万即对超出部分有<strong>非法占有目的</strong>，构成绑架罪 |
| 债务含赌债与高利贷 | 司法解释对债务作<strong>扩大解释</strong>，赌债、高利贷之债均属债务；为索要而拘禁仍只定非法拘禁罪 |
| 扩大解释与类推解释 | 类推解释超出用语可能含义、一律错误，我国不承认；「汽车」含大型拖拉机是扩大解释，「汽车」含火车地铁是类推解释 |
| 侮辱罪的对象与公然性 | 法益为外部名誉权，对象须为<strong>特定</strong>自然人；须公然使多数人或不特定人知晓，骂街不特定、私下辱骂不构成；侮辱死者不构成，借以侵害家属名誉则构成；不含单位，指向单位内特定人可构成 |
| 侮辱与诽谤的界分 | 侮辱内容可真可假，假内容须<strong>不足以</strong>使一般人相信；诽谤只能是虚假内容且足以使一般人相信；两罪均属亲告罪 |
| 重婚罪 | 有配偶而重婚，或明知他人有配偶而与之结婚；法律婚姻加法律婚姻、法律婚姻加<strong>事实婚姻</strong>（同居、对外以夫妻相称、群众公认）均构成 |
| 虐待罪 | 对象为家庭成员，含共同生活的管家保姆与事实婚姻夫妻；属亲告罪，致重伤、死亡或被害人无法告诉的转公诉 |
| 虐待被监护看护人罪 | 幼师、养老院护工虐待未达轻伤无法定故意伤害，故设本罪；属<strong>公诉</strong>案件，因非家庭成员不适用虐待罪 |
| 侵犯公民个人信息罪 | 违反国家规定出售、提供、窃取或以其他方法非法获取公民个人信息；信息含姓名、身份证号、联系方式、住址、账号密码、行踪轨迹等 |
