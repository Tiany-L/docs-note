# 刑法分则、财产类犯罪

## 知识点速记

> 来源：2027 公专 P19 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 侵占罪的行为方式 | 将代为保管的他人财物非法占为己有，数额较大，<strong>拒不退还</strong>；或将他人遗忘物、埋藏物非法占为己有，数额较大，拒不交出；属亲告罪，不告不理，自己到法院起诉 |
| 侵占罪的构成要件 | 将他人所有、自己占有的财物变为自己所有；占有权原本就在行为人手里，被剥夺的是<strong>所有权</strong>；与盗窃的差别全看占有权在谁手上 |
| 盗窃罪的四类行为 | 盗窃公私财物数额较大的构成盗窃罪；<strong>多次盗窃、入户盗窃、携带凶器盗窃、扒窃</strong>四类不看金额只看行为；四类中任何一种，偷一块钱也按盗窃罪定 |
| 盗窃数额较大的标准 | 法律没有统一的具体数额，由各地按财力自定；讲者举例辽宁3000元（原2000元）、北上广3500至4000元；出题会把差距拉大，偷十元是治安案件、偷百万是刑事案件 |
| 多次盗窃的认定 | 两年内三次以上；同一地点、同一区域连续针对多个被害人只算<strong>一次</strong>，金额累计；时间、地点拉开才算多次 |
| 入户盗窃的成立 | 不看金额，偷一分钱也算；入户必须是<strong>非法入户</strong>，受邀合法入户后临时起意只是普通盗窃；煎饼车、小推车不能成为户 |
| 携带凶器盗窃 | 不要求显示、不要求使用，带着就按盗窃罪定；但凶器须有<strong>对人使用</strong>的意图；带镰刀割麦、顺手偷邻居麦子不算 |
| 扒窃的成立 | 在公开场合盗窃他人财物；公交车上扒一块钱也构成盗窃罪；同样没有金额限制 |
| 盗窃既遂的标准 | 看财物大小；大件财物须转移出场所才算既遂，背冰柜没出商场是未遂；小件财物如戒指、耳钉，藏起来即既遂 |
| 盗窃与侵占的区分 | 只盯占有权，不盯所有权；主人在占有、行为人破坏其占有→盗窃；行为人先前占有、主人索要拒不退还剥夺所有权→侵占 |
| 紧密占有与松弛占有 | 贴身、随身、手拎是紧密占有；有空间距离但未脱离实际控制是松弛占有，如食堂占座书包、试鞋跑掉、高铁行李架；松弛占有仍归主人，拿走是盗窃 |
| 观念上的占有 | 财物已出实力控制范围，但依社会一般观念可推知有人占有；火灾中搬到路边的财物、停在自己院里的摩托车，拿走仍定盗窃 |
| 场所内财物的占有 | 手机落餐桌、人还在店内，属主人松弛占有而非遗忘物，服务员藏起拿走是盗窃；投入许愿池的钱归<strong>寺庙</strong>占有，路人抠走也是盗窃 |
| 出租车钱包的两种定性 | 落在车上被<strong>司机</strong>拿走、拒不退还→侵占；被后上车乘客拿走→盗窃，侵犯的是司机对钱包的占有权 |
| 盗窃是否要求秘密 | 学说有争议；法考主张不要求秘密手段，公开盗窃也成立；法硕主张必须秘密；公安专业科目借鉴法考，按不要求秘密掌握 |
| 抢夺罪的构成要件 | 对物暴力、对人有危险；比盗窃重、比抢劫轻，正处在两者中间；对人达到暴力程度就是抢劫 |
| 携带凶器抢夺 | 法律拟制，直接按抢劫罪定；凶器可由第三人携带，不要求显示、不要求暗示；但须有<strong>随时可使用</strong>的可能性和对人使用的意图 |
| 飞车抢夺与结果加重 | 被害人不放手仍强行夺取、逼挤撞击逼倒、明知会致人伤亡仍夺取，三种按抢劫论，本身已符合抢劫要件、不是法律拟制；抢夺致人重伤死亡仍定抢夺罪加重处罚，须有因果和紧密联系，且对伤亡是过失 |
| 抢劫罪的构成要件 | 以非法占有为目的，用暴力、胁迫或其他方法压制反抗后强行取财；对象包括财物占有者、占有辅助者、<strong>财物保护者</strong>，不包括无关第三人 |
| 昏醉型与拘禁型抢劫 | 用药物、酒精麻痹被害人后取走财物，是抢劫不是盗窃；把主人骗到阳台反锁、使其不能反抗后取财，也是抢劫 |
| 暴力与取财的紧密联系 | 暴力与取财须同时或紧接；先打人、隔天或异地再取财，没有紧密联系，按故意伤害、故意杀人与盗窃并罚 |
| 事后转化型抢劫 | 犯盗窃、诈骗、抢夺罪，为<strong>窝藏赃物、抗拒抓捕、毁灭罪证</strong>，当场使用暴力或以暴力相威胁，转化为抢劫罪；三罪有其一即可，三目的有其一即可 |
| 未成年人不转化抢劫 | 已满14不满16周岁只对八种罪负责；八种罪不含盗窃、诈骗、抢夺，前提要件不成立，就转化不出抢劫 |
| 入户抢劫中户的认定 | 看有无住宅安宁权；集体宿舍、旅馆宾馆、临时工棚、流浪汉住的垃圾桶都不算户，在其中抢劫只是普通抢劫 |
| 入户抢劫的三要件 | 人身进入户内；<strong>暴力行为在户内</strong>；在户内取得财物；把主人骗出户外、或在户外打晕后再入户取财，都不算入户抢劫 |
| 公共交通工具上抢劫 | 公交车、大中型出租车、火车、船只、飞机等运营中的交通工具；<strong>小型出租车</strong>依司法解释不算；针对车上乘客即可，不要求抢劫时人在车上 |
| 抢劫的其他加重情形 | 抢劫银行等金融机构；多次即三次以上抢劫或数额巨大；冒充军警须足以让一般人相信；持枪须是真枪、不要求实弹、须使用或展示，口头声称不算 |
| 抢劫致人重伤死亡 | 须由抢劫行为导致，且有紧密的因果联系；抢劫后为逃跑、灭口而伤害、杀害被害人，按抢劫罪与故意伤害、故意杀人并罚 |
| 诈骗罪的五环构造 | 欺骗行为→对方产生或维持错误认识→基于错误认识处分财物→行为人取得财物→被害人财产损失；五环缺一不可 |
| 不作为的诈骗 | 对方已陷入错误认识，行为人负有告知义务而不告知，默许其处分财物，可构成诈骗；不作为的欺骗同样算欺骗行为 |
| 不合格的错误认识 | 骗小孩、精神病人，因其无意识自治能力，错误认识不合格，<strong>定盗窃不定诈骗</strong>；对ATM机、自动售货机做手脚，如铁片换货、故障取款、作废卡取款，也一律定盗窃 |
| 财产法益的位阶 | 合法占有 &gt; 所有权 &gt; 非法占有 &gt; 一般人；位阶低的侵夺位阶高的构成犯罪，反之不构成；偷他人偷来的车定盗窃，偷回自己被偷的车无罪，偷回借出未到期的车定盗窃 |
