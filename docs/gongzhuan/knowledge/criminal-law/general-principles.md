# 刑法总则

## 知识点速记

> 来源：2027 公专 P15 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 罪刑法定原则 | 法无明文规定不为罪、不为处罚，处罚必须有法律依据；<strong>通奸在我国不是犯罪</strong>，只受道德谴责，个别国家才规定为犯罪。 |
| 属地管辖 | 在中国领域内犯罪适用中国刑法；领陆、领水（黄海、渤海）、领空均属领域；<strong>中国驻外使领馆视为中国领土</strong>。 |
| 船舶与航空器的管辖 | 采旗国主义，关键看<strong>登记地</strong>；船舶、航空器登记在中国即视为中国领域；在公海或外国上空发生的刑事案件，中国刑法可以管辖。 |
| 犯罪地的认定 | 分行为地与结果地；<strong>二者只要有一个发生在中国</strong>，中国刑法即可管辖。 |
| 属人管辖 | 中国人在国外犯罪，中国刑法可管；按中国刑法<strong>法定最高刑3年以下</strong>的，可以不予追究；国家工作人员和军人一律追究，不看刑期。 |
| 保护管辖 | 外国人在国外对中国公民犯罪；须<strong>最低刑3年以上</strong>；并须<strong>双重犯罪</strong>，即两国都认为是犯罪。 |
| 从旧兼从轻 | 行为后法律有变更的，比较新旧法；<strong>哪个对行为人有利</strong>就适用哪个。 |
| 作为与不作为 | 作为是<strong>不当为而为之</strong>；不作为是<strong>当为而不为</strong>；判断先看有无作为义务。 |
| 救助义务的法律界限 | 母子、夫妻之间有法律救助义务，不救致死构成不作为犯罪；<strong>女友未领证只有道德义务</strong>；医生护士救死扶伤也仅是道德义务，不构成不作为犯罪。 |
| 刑事责任年龄按周岁 | 法律学科一律按<strong>周岁</strong>计算；不按虚岁、毛岁折算。 |
| 刑事最低责任年龄 | 不满12周岁完全不负刑事责任；对照记忆：<strong>治安最低责任年龄14周岁</strong>、民事最低责任年龄8周岁。 |
| 已满12不满14周岁 | 仅限故意杀人、故意伤害两罪；须致人死亡，或以特别残忍手段致人重伤造成严重残疾、情节恶劣；<strong>经最高检核准追诉</strong>才负刑事责任。 |
| 已满14不满16周岁八罪 | 故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质；<strong>只有这8种</strong>；故意伤害须<strong>致人重伤或死亡</strong>，轻伤不负刑责；绑架、盗窃不在其内。 |
| 完全负责任的年龄 | 已满16周岁，对一切犯罪负刑事责任。 |
| 未成年人犯罪从宽 | 已满14不满18周岁犯罪，<strong>应当</strong>从轻或减轻处罚，不是可以；不予行政处罚的，责令父母或监护人严加管教，必要时专门矫治教育。 |
| 已满75周岁从宽 | <strong>故意</strong>犯罪的，<strong>可以</strong>从轻或减轻；过失犯罪的，<strong>应当</strong>从轻或减轻。 |
| 精神病人的责任能力 | 完全不能辨认或控制自己行为的，不负刑事责任，必要时由政府强制医疗；间歇性的<strong>看行为时状态</strong>；尚未完全丧失辨认控制能力的，应当负刑事责任，可以从轻或减轻。 |
| 醉酒的人 | <strong>生理性醉酒应当负刑事责任</strong>，无从轻减轻余地；病理性醉酒按精神病处理。 |
| 直接故意与间接故意 | 直接故意是明知会发生而希望、追求结果发生；间接故意是明知可能发生而<strong>放任</strong>，结果发生与否都不违背其意愿。 |
| 过于自信与疏忽大意 | 过于自信是已预见可能发生但<strong>轻信能够避免</strong>；疏忽大意是应当预见而因马虎<strong>没有预见</strong>。 |
| 意外事件 | 行为人<strong>不能预见</strong>而没有预见，无罪过，不作为犯罪处理。 |
| 预备阶段的预备与中止 | 从开始购买工具、毒药即进入预备；因<strong>意志以外</strong>原因未得逞是犯罪预备；因<strong>意志以内</strong>主动放弃是预备阶段犯罪中止。 |
| 实行阶段的未遂与中止 | 已着手后，因意志以外原因未得逞是犯罪未遂；主动放弃是犯罪中止。 |
| 着手的认定 | 着手即<strong>发生现实紧迫的危险</strong>；未着手为预备阶段，已着手为实行阶段；强奸以实施暴力、胁迫为着手，<strong>不是奸淫时</strong>；抢劫以暴力胁迫或强取财物、诈骗以开始行骗、保险诈骗以提出理赔、诬告陷害以告发为着手。 |
| 共同犯罪的成立条件 | 二人以上共同故意犯罪，每人都须有责任能力、都须对该罪负刑事责任；15周岁的人与成年人共同绑架<strong>不构成共犯</strong>（绑架不在八罪内）；<strong>过失犯罪不构成共犯</strong>，交通肇事是典型；此点与法考不同。 |
| 共谋即共犯 | <strong>共谋+犯罪结果发生即构成共犯</strong>；一人既遂、全体既遂；未到场、未分赃都不影响；共谋后又有效阻止结果发生的不构成。 |
| 同时犯 | 同一时间、同一地点各自实施犯罪，<strong>无意思联络</strong>，不构成共犯；一旦形成共同故意并约定分赃，即构成共犯。 |
| 刑法中的两个从重 | 只有两处：<strong>累犯</strong>；<strong>教唆不满18周岁的人犯罪</strong>。 |

## 课程口诀

::: tip
**口诀（已满14不满16周岁的八种罪）：「烧杀奸抢，伤贩爆投」**

依次对应放火、故意杀人、强奸、抢劫、故意伤害致人重伤或死亡、贩毒、爆炸、投放危险物质；原话谐音作「商贩爆头」。

课程位置：35:30。
:::
