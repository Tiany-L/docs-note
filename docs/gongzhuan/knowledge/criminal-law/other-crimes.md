# 刑法分则、其他罪名

## 知识点速记

> 来源：2027 公专 P21 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 袭警罪三要件 | 暴力袭击；对象须是<strong>正在执行职务</strong>的人民警察（以公安机关民警为考查范围）；三要件缺一不可，民警休假、下班期间被袭击不成立本罪，按故意伤害、故意杀人处理 |
| 袭警罪的暴力认定 | 撕咬、掌掴、踢打、抱摔、投掷物品等；<strong>造成轻微伤以上后果</strong>即构成，门牙打掉、鼻骨骨折、脑袋开瓢均达标准；打砸、毁坏、抢夺警车警械且足以危及人身安全的同样算 |
| 不属暴力袭击的情形 | 轻微肢体冲撞；被抓时甩手、蹬腿等挣扎抵抗；辱骂、侮辱、讽刺性言语；危害不大，<strong>不构成袭警罪，但可构成治安违法</strong> |
| 袭警的从重情形 | 使用枪支、管制刀具等杀伤力武器，或驾驶机动车撞击民警及其乘坐的公务用车（<strong>不限警车</strong>），处三年以上七年以下；另有致轻伤、致不能正常履职、致他人伤亡、嫌疑人逃脱、关键证据毁灭、公共财物重大损失、纠集煽动多人、袭击二人以上 |
| 民警执法过错的三种处理 | 民警有严重执法过错，行为人一般不作犯罪处理；过错较大且袭击轻微、危害不大的，可以不作犯罪处理；<strong>袭击后果严重需追责的，应作犯罪处理但应当从宽</strong>；题干关键词分别为「严重过错」「过错较大」「袭击后果严重」 |
| 袭击辅警的定性 | 暴力袭击正在<strong>配合</strong>民警执行职务的辅警，定<strong>妨害公务罪</strong>，不构成袭警罪；前提是辅警处于配合民警执行职务期间 |
| 一并袭击与单独袭击 | 执行职务中把民警和辅警一起打，定袭警罪；<strong>单独</strong>袭击执行职务的辅警无对应条文，因辅警不能单独执行职务，考试不涉及 |
| 高空抛物罪的构成 | 从建筑物或其他高空抛掷物品；须<strong>情节严重</strong>才构成，扔分手信、吐痰、扔蟑螂均因情节不够不构成本罪 |
| 「高空」是相对概念 | 树上、山上、轮船、热气球抛物均属高空；从地面向井下作业面投物也算；<strong>一楼不能实施</strong>；同一水平面相互投掷不算高空 |
| 高空抛物致人伤亡 | 过失致物品坠落伤人的，按过失致人重伤、过失致人死亡；<strong>坠楼砸死人定过失致人死亡罪</strong>，并无「高空抛自己」之罪；瞄准特定人投掷的按故意伤害、故意杀人 |
| 高抛与公共安全的竞合 | 抛掷浓硫酸等危及不特定多数人的，同时触犯以危险方法危害公共安全罪；<strong>想象竞合择一重</strong>，通常以后者处断；只可能砸到个别人的一般仅构成高空抛物罪 |
| 非法侵入计算机信息系统罪 | 侵入国家事务、国防建设、<strong>尖端科学技术</strong>领域的系统；特殊点就在领域特定，如政府内网、国防内网 |
| 非法控制、获取数据罪 | 侵入上述特定领域<strong>以外</strong>的系统，定非法控制计算机信息系统罪，如车辆定位监控系统；题干出现「数据」的定非法获取计算机信息系统数据罪，同样限于特定领域以外的系统 |
| 非法利用信息网络罪 | 在网上发布销售毒品等信息；网上售卖教人自杀的课程；行为方式是发布信息、设立网站或通讯群组 |
| 帮信罪 | 帮助信息网络犯罪活动罪的简称；断卡行动的两卡指<strong>银行卡与电话卡</strong>；卖卡、供卡即入罪，诈骗分子借此逃避侦查，办卡人多不知是犯罪 |
| 信用卡诈骗的情形 | 使用伪造的信用卡；使用以虚假身份骗领的信用卡；使用作废的信用卡；冒用他人信用卡；恶意透支即<strong>以非法占有为目的</strong>、经催收仍不归还；均须<strong>数额较大</strong> |
| 信用卡的范围 | 不限于可透支的信用卡；<strong>无透支功能的储蓄卡、借记卡也算</strong>本罪中的信用卡 |
| 对 ATM 机使用信用卡 | 机器不能被骗，按构成要件本应降格定盗窃；但 <strong>2018 年 11 月 28 日</strong>两高解释规定对机器使用一律定信用卡诈骗罪，与对银行工作人员使用同一处理 |
| 抢劫、盗窃信用卡 | 抢劫信用卡并使用定<strong>抢劫罪</strong>；盗窃信用卡并使用定<strong>盗窃罪</strong>，其中的「盗窃」既包括亲自偷亲自用，也包括<strong>亲自偷让别人用</strong> |
| 侵占等取得信用卡 | 侵占、诈骗、抢夺、敲诈勒索取得信用卡并使用，定信用卡诈骗罪；以非法方法获取信用卡信息资料后使用，同样定信用卡诈骗罪 |
| 微信支付宝内资金 | 盗划（转入自己账户）与盗刷（直接消费购物）均定<strong>盗窃罪</strong>；先盗手机再盗划盗刷的，数个盗窃行为只定一个盗窃罪从重 |
| 花呗、借呗 | 冒用他人花呗，取得蚂蚁公司垫付的资金，定<strong>贷款诈骗罪</strong>；既不是盗窃罪，也不是信用卡诈骗罪 |
| 亲告罪的范围 | 诽谤、侵占、侮辱、暴力干涉婚姻自由、虐待；均属自诉案件，不告不理，<strong>自己到法院起诉，不归公安</strong> |
| 亲告罪的例外 | 诽谤、侮辱严重危害社会秩序和国家利益的，公安介入；虐待致人重伤、死亡的，公安介入；<strong>侵占是绝对自诉，无例外</strong>；被害人受恐吓无法告诉的，检察院或近亲属可告诉 |
| 侵占罪 | 合法占有他人财物后<strong>拒不退还</strong>；前提是所有权与占有权分离，如代为保管的财物；绝对自诉案件 |
| 暴力干涉婚姻自由罪 | 既干涉结婚也干涉离婚，强迫他人结婚或离婚均构成；主体<strong>可以是第三人，也可以是当事人本人</strong>，如持刀逼他人与自己领证；关押并干涉的与非法拘禁罪竞合，打死人的与故意杀人罪竞合择一重 |
| 虐待罪与虐待被监护看护人罪 | 虐待罪对象是<strong>共同生活的家庭成员</strong>，致人重伤、死亡为结果加重；幼儿园老师虐童、养老院护工虐老不属家庭成员，情节恶劣的定虐待被监护、看护人罪，<strong>三年以下</strong> |
| 洗钱罪 | 掩饰、隐瞒七类上游犯罪所得及其收益的来源和性质；上游七类为毒品、黑社会性质组织、恐怖活动、走私、贪污贿赂、破坏金融管理秩序、金融诈骗 |

## 课程口诀

::: tip
**口诀（洗钱罪上游七类犯罪）：「毒黑恐走贪两斤」**

毒＝毒品犯罪，黑＝黑社会性质组织犯罪，恐＝恐怖活动犯罪，走＝走私犯罪，贪＝贪污贿赂犯罪，两斤＝破坏金融管理秩序犯罪、金融诈骗犯罪

课程位置：79:30。
:::
