# 正当防卫、紧急避险

## 知识点速记

> 来源：2027 公专 P16 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 正当防卫定义 | 目的：使国家、公共利益、本人或他人的人身、财产等权利免受侵害；对象是<strong>正在进行的不法侵害</strong>；方式是制止侵害、给侵害人造成损害 |
| 正当防卫的大白话 | 你打我我就打你，你凭什么打我；落到法律上就是不负刑事责任 |
| 治安案件同样适用 | 2026 年 1 月 1 日起施行的新版治安管理处罚法，把原本刑事案件专属的正当防卫下放到治安案件；刑事<strong>不负刑事责任</strong>，治安<strong>不追究治安责任</strong> |
| 防卫对象包括他人 | 不限于本人；为他人的人身、财产免受侵害而反击，同样成立正当防卫，即见义勇为 |
| 正在进行的时间条件 | 必须是侵害正在进行（现在进行时）；判断标准是侵害已经开始、尚未结束，不在侵害前也不在侵害后 |
| 事前防卫与事后防卫 | 侵害前先动手叫<strong>事前防卫</strong>，侵害结束后再动手叫<strong>事后防卫</strong>；两者都不属于正当防卫，都要按相应罪名处理 |
| 一般人视角、整体判断 | 不能站上帝视角、圣贤视角；要把自己想象成当事人；一连串防卫动作要当成<strong>一个整体</strong>评价，不能像切蛋糕一样切成几段 |
| 特殊防卫（无限防卫） | 对行凶、杀人、抢劫、强奸、绑架及其他严重危及人身安全的暴力犯罪；造成侵害人<strong>伤亡</strong>也不属防卫过当，不负刑事责任；它仍归属于正当防卫 |
| 特殊防卫的适用范围 | 只有法定那几类严重暴力犯罪才适用；一般侵害仍受必要限度约束，不能一律往死里打 |
| 假想防卫 | 客观上不存在不法侵害，是防卫人<strong>自己幻想</strong>出来的；定罪一般按过失犯罪，没有过失的按<strong>意外事件</strong>处理 |
| 事前防卫的定罪 | 侵害尚未开始就下手，不成立正当防卫；毁坏的是他人财物，就定故意毁坏财物罪 |
| 事后防卫的定罪 | 侵害结束后出于报复泄愤再动手，可构成故意杀人；此时已不是针对正在进行的不法侵害 |
| 动物侵害的定性 | 野生动物侵袭时反击，不属于正当防卫，属于<strong>紧急避险</strong>；饲养的动物被主人驱使伤人，反击属于<strong>正当防卫</strong> |
| 防卫挑拨 | 故意激怒、引诱对方先动手，再借「他先打我」实施加害；主观上事前就有加害故意，不成立正当防卫 |
| 防卫过当 | 损害的权益明显大于所保护的权益；<strong>应当负刑事责任</strong>，但<strong>应当减轻或免除处罚</strong>；如为护几个瓜而夺人性命 |
| 偶然防卫 | 主观上没有防卫意图，客观上偶然保护了他人；了解名词即可，不常考 |
| 抢劫后追回仍属正在进行 | 财产犯罪中侵害人已取得财物，但通过追赶、撞击等能够追回的，<strong>仍视为不法侵害正在进行</strong>；此时反击属正当防卫 |
| 紧急避险定义 | 为使国家、公共利益、本人或他人的人身等权利免受<strong>正在发生的危险</strong>，<strong>不得已</strong>损害另一<strong>较小</strong>合法利益 |
| 被胁迫损害较小权益 | 为保全生命不得已损害他人较小权益的，属紧急避险，不构成犯罪；胁迫者对被胁迫者形成支配力，成立<strong>间接正犯</strong> |
| 权利位阶 | <strong>生命权 &gt; 健康权（身体权）&gt; 财产权</strong>；只有损害较小权益、保全较大权益，才是避险 |
| 避险过当 | 超过必要限度造成不应有的损害；如为保自己的命而剥夺他人生命，损害的是<strong>同等</strong>生命权；主观一般为过失，应当减轻或免除处罚 |
| 不得已要件 | 必须无其他办法才可损害第三人利益；能请示、能另找替代办法的，就不叫不得已，不构成紧急避险 |
| 防卫与避险的对象差别 | 正当防卫打的是<strong>侵害人本人</strong>——你打我我打你，或你打他我打你；紧急避险损害的是<strong>无辜第三人</strong>——你打我我打他 |
| 主体范围差别 | 正当防卫是每个公民的法定权利，人民警察也有；紧急避险不适用于职务上、业务上<strong>负有特定职责的人</strong>，<strong>警察没有紧急避险</strong> |

## 课程口诀

::: tip
**口诀（特殊防卫（无限防卫）的适用对象）：「杀人帮凶强抢人身」**

杀＝杀人，帮＝绑架，凶＝行凶，强＝强奸，抢＝抢劫，人身＝其他严重危及人身安全的暴力犯罪；对这几类实施防卫致人伤亡，不负刑事责任

课程位置：19:00。
:::
