# 监察法

## 知识点速记

> 来源：2027 公专 P48 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 立案权与公开 | 监察机关立案由自己决定，无需报上一级批准；决定应向被调查人宣布，并通报相关组织、告知家属；同时向社会公开发布。 |
| 调查禁止手段 | 禁止暴力、胁迫、诱骗、欺骗取证；禁止辱骂、体罚；应当保障饮食、休息与医疗服务；不得滥用权力干扰企业经营。 |
| 监察委无侦查权 | 监察机关只有调查权，没有侦查权；搜查、扣押等只能称调查措施；凡称监察委享有侦查权的选项一律错误。 |
| 调查须持证 | 采取任何调查措施都必须持证；不存在公安那种紧急情况先执行后补证的做法；无证即不得开展调查。 |
| 调查范围与集体研究 | 应严格执行调查方案，不得随意扩大调查范围；重要事项须集体研究后按程序请示报告；不得由一人决定。 |
| 谈话询问时间 | 法律只规定应当安排合理时间；具体时长未作规定，由监察机关自行掌握；不适用公安 12 小时、24 小时的限制。 |
| 调查阶段无辩护人 | 监察机关调查阶段，被调查人无权委托辩护人，也不存在法律援助；公安侦查阶段律师即可介入；进入审查起诉阶段律师才可作为辩护人介入。 |
| 调查终结集体审议 | 调查终结应形成审理报告；提请集体审议，不得由个人审理；对应公安的侦查终结，是移送检察院前的衔接环节。 |
| 从宽处理意见 | 须经领导人员集体研究决定；并报上一级监察机关批准；适用于自动投案、主动配合、如实供述、退赃、立功等情形。 |
| 补充调查与救济 | 检察院认为需要补充核实的，退回监察机关补充调查，必要时可自行补充侦查，1 个月内完成、2 次为限；认为不起诉有错误的，可向上一级检察院申请复议。 |
| 死亡仍须调查 | 被调查人逃匿或死亡的，有继续调查必要的仍应继续调查并作出结论；查的主要是违法所得，人事未了。 |
| 违法所得没收路径 | 监察机关无权自行没收；须提请检察院，由检察院向法院提出没收申请；不能越过检察院直接找法院。 |
| 四项措施轻重顺序 | 由轻到重依次为强制到案、责令候查、管护、留置；强制到案类比拘传；管护类比拘留；留置类比逮捕。 |
| 强制到案 | 由监察机关主要负责人批准，无须集体研究；监察机关自行执行，公安机关配合；不得超过 12 小时，采取管护或留置的不得超过 24 小时。 |
| 责令候查适用 | 适用于不符合留置条件的人员；患严重疾病、怀孕或哺乳、唯一抚养人等参照监视居住；留置期满或无需留置的可转为责令候查。 |
| 责令候查义务 | 未经批准不得离开所居住的市、县；住址、单位、联系方式变动 24 小时内报告监察机关；传讯及时到案；不得干扰作证、毁灭证据。 |
| 责令候查期限 | 最长不超过 12 个月，批准与执行同强制到案；违反应遵守义务的，可以依法转为留置。 |
| 管护适用与场所 | 适用于未被留置但有逃跑、自杀等重大安全风险的人员；采取后应立即送留置场所，不得超过 24 小时；没有先行管护。 |
| 管护期限与通知 | 一般应在 7 日内作出留置或解除决定，特殊情况可延长 1 至 3 日，最长 10 日；24 小时内通知单位和家属；本人及近亲属可申请变更；1 日折抵管制 2 日、拘役有期徒刑 1 日。 |
| 留置情形 | 案情重大复杂、可能逃跑自杀、可能毁证串供、有其他妨碍调查行为的可以留置；行贿人、共同职务犯罪涉案人员同样可以留置。 |
| 留置审批 | 须由监察机关领导人员集体研究决定；不同于其他措施由主任一人批准；因其最重，立法上比照逮捕设置。 |
| 留置报批层级 | 设区的市级以下监察机关留置，报上一级监察机关批准；省级监察机关留置，只需向国家监察委员会备案。 |
| 留置一般期限 | 一般不超过 3 个月；特殊情况可延长一次，延长不超过 3 个月；延长须报上一级监察机关批准。 |
| 重罪与漏罪延长 | 可能判处 10 年以上刑罚的，经国家监委批准可再延长 2 个月；发现漏罪重新计算的，最长<strong>14 个月</strong>，不是 16 个月。 |
| 留置变更 | 不需要继续留置或留置不当的，解除留置；也可变更为<strong>责令候查</strong>，不是管护；应在 3 日内作出决定并说明理由。 |
| 留置折抵与看护 | 留置 1 日折抵管制 2 日、拘役有期徒刑 1 日；省级以下留置场所的看护勤务由公安机关负责。 |
| 技术调查 | 由监察机关决定，交有关机关即公安机关执行；有效期 3 个月，可延长 3 个月；监察委自身不实施。 |
| 通缉与限制出境 | 通缉由监察机关决定，公安机关发布；限制出境须经省级以上监察机关批准，由公安机关执行。 |
| 涉案财物移送 | 监察机关无权决定没收；应当随案移送检察院，再由检察院移送法院裁决；与追缴、收缴程序无关。 |
| 监察委定公安执行 | 技术调查、通缉、限制出境、省级以下留置场所看护共四项；均由监察机关决定，由公安机关执行。 |

## 课程口诀

::: tip
**口诀（责令候查应当遵守的义务）：「候查禁足 便要告 不扰证据 传及到」**

候查＝责令候查，禁足＝未经批准不得离开所居住的市县，便要告＝住址工作单位联系方式变动 24 小时内报告，不扰证据＝不干扰证人作证、不毁灭伪造证据，传及到＝传讯时及时到案。原音识别为「后查禁主」，按上下文校正为「候查禁足」。

课程位置：51:00。
:::

::: tip
**口诀（留置的适用情形）：「大复逃杀 毁证碍查」**

大复＝案情重大复杂，逃杀＝可能逃跑自杀，毁证＝毁灭伪造证据，碍查＝其他妨碍调查行为。原音「大富逃杀毁正爱查」，按法条用语校正为「大复／毁证／碍查」。

课程位置：63:30。
:::

::: tip
**口诀（留置的报批层级）：「市报上批 省报国备」**

设区的市级以下监察机关留置，报上一级监察机关批准；省级监察机关留置，报国家监察委员会备案（不是批准）。原音「事报上批」，校正为「市报上批」。

课程位置：70:00。
:::
