# 行政复议、行政诉讼、国家赔偿

## 知识点速记

> 来源：2027 公专 P47 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 新法规模与分值 | 2024 年 1 月 1 日实施；共 90 条，旧法仅 43 条，新增 51 条、修改 38 条、删 4 条；本科目约考 1 至 2 分。 |
| 复议原则 | 合法、公正、公开、高效、便民、为民共<strong>六项</strong>；原则题现在很少考，若考多为抠字眼，别记成五项。 |
| 复议的一般管辖 | 对本级政府工作部门（公安分局、县公安局）的行为不服，向<strong>同级人民政府</strong>申请；对下级政府的行为不服，向上一级政府申请。 |
| 派出机关与派出机构 | 街道办是政府设立的派出机关，不服找区政府；派出所是公安机关的派出机构，县级公安设立的，不服找县政府。 |
| 市设分局与市派出所管辖 | 市政府工作部门按行政区设立的派出机构（市局分局、市属派出所）作出的行为，<strong>市政府或区政府均可管辖</strong>。 |
| 复议与诉讼不得并行 | 复议期间不得向法院起诉；法院已受理的不得再申请复议；两条救济渠道只能择一走，避免重复处理。 |
| 申请材料补正 | 收到申请起 5 日内书面通知补正；须<strong>一次性载明</strong>需补内容，不得分次让当事人反复跑腿。 |
| 先行自纠程序 | 当场处罚、依据电子技术监控记录作出的处罚，复议申请交原处罚机关；机关可先行自查纠错，认为需维持的 5 日内转交复议机关。 |
| 复议听证的适用 | 重大、疑难、复杂案件应当组织听证；<strong>1 名主持人、2 名以上听证员、1 名记录员</strong>，人数要求与处罚听证不同。 |
| 简易程序的适用范围 | 当场作出的行为、警告或通报批评、涉案金额 3000 元以下、政府信息公开案件；<strong>以书面审理为常态</strong>，比口头听取意见更快。 |
| 复议可以调解 | 复议案件可以调解，遵循<strong>合法、自愿</strong>原则；题干只要问「能不能调解」，答可以。 |
| 复议前置四种情形 | 当场作出的处罚、自然资源权属争议、不履行法定职责（不作为）、政府信息公开；<strong>只能先复议</strong>，不服复议决定再起诉。 |
| 复议与赔偿一并提出 | 申请复议时可一并提赔偿请求；复议机关认为应赔则同时决定赔偿，认为不赔则<strong>一并驳回</strong>，捆绑提出、捆绑处理。 |
| 复议决定抄告上级 | 复议决定书、意见书同时抄告被申请人的<strong>上一级主管部门</strong>（分局报市局法制部门），据此开展执法监督。 |
| 复议申请与审理期限 | 知道或应当知道之日起<strong>60 日</strong>内申请；机关 60 日内作出决定，复杂可延长 30 日；简易程序 30 日；未告知复议权的，自知道之日起算 1 年。 |
| 复议中的委托代理 | 申请人、第三人可委托 1 至 2 名律师；<strong>被申请人不得委托律师</strong>，进入诉讼后行政机关才可委托律师出庭。 |
| 复议终局的情形 | 外国人对居留审查、限制活动、遣送出境不服，<strong>只能复议不能诉讼</strong>，复议决定即为终局。 |
| 公安部复议与国务院终局 | 对公安部行为不服，先向公安部申请复议，也可直接诉至<strong>中级法院</strong>；对复议结果仍不服再报国务院裁决，到此终局。 |
| 行政诉讼的界定 | 民告官，诉讼对象是<strong>行政行为</strong>；机关采购、买卖等民事行为引发的是民事诉讼。 |
| 被告的确定 | 复议维持→原机关与复议机关共同被告；复议改变→只告复议机关；复议不作为→可择一告；派出所越权拘留或罚 1000 元以上，<strong>以派出所为被告</strong>。 |
| 起诉期限 | 对复议决定不服，收到决定书 15 日内起诉，复议不作为同样 15 日；<strong>未经复议直接起诉为 6 个月</strong>。 |
| 负责人出庭应诉 | 正职或副职负责人出庭；可另行委托 1 至 2 名诉讼代理人（可为律师）；确实不能出庭的，委托本机关工作人员出庭。 |
| 赔偿主管部门 | 国家赔偿案件由<strong>法治部门</strong>主管办理，因其懂法、能判断该不该赔。 |
| 行政赔偿义务机关 | 谁侵犯谁赔；<strong>派出所永不是赔偿义务机关</strong>，由分局赔；两个机关共同行使职权致害的，共同赔偿。 |
| 复议加重的赔偿 | 经复议的案件，最初造成侵权的机关为义务机关；复议机关只对<strong>加重部分</strong>赔偿，如 10 天变 15 天，分局赔 10 天、政府赔 5 天。 |
| 行政赔偿程序与期限 | 知道或应当知道起<strong>2 年</strong>内提出，可口头可书面；先向义务机关申请，不服诉至一审法院，再上诉至中级法院。 |
| 刑事赔偿义务机关 | 按刑诉阶段定：公安刑拘致害→公安赔；检察院批捕→检察院赔；法院判有罪、再审改判无罪→法院赔。 |
| 刑拘赔偿的两种情形 | 无任何证据即刑拘；刑拘超期且最终判无罪；<strong>未超期、无罪释放不赔</strong>；按羁押天数计赔，拘几天赔几天。 |
| 赔偿归责原则 | 违法才赔偿、合法仅补偿；行使职权致害由国家承担，<strong>个人行为个人赔</strong>。 |

## 课程口诀

::: tip
**口诀（复议原则）：「一合一高两公两民」**

合=合法，高=高效，两公=公正、公开，两民=便民、为民。

课程位置：03:30。
:::

::: tip
**口诀（行政复议应当组织听证的情形）：「大姨父夫一要停车」**

大＝重大，姨＝疑难，父＝复杂，一要停车＝应当组织听证；讲者用「大姨父，夫一要停车」的谐音串起来，原话就是这么念的，未作改写

课程位置：25:30。
:::

::: tip
**口诀（简易程序）：「当场公开警告批评三千下」**

当场作出、政府信息公开、警告或通报批评、涉案金额 3000 元以下，可走简易程序。

课程位置：29:00。
:::

::: tip
**口诀（被告确定）：「复议维持共同告，复议改变单独告，复议不作为选择告」**

维持告原机关加复议机关，改变只告复议机关，不作为可择一告。

课程位置：66:30。
:::
