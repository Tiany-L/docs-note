# 人民警察法

## 知识点速记

> 来源：2027 公专 P46 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 紧急优先权 | 须同时满足<strong>人民警察身份、履行职责、紧急需要</strong>三者；出示证件可优先乘坐公共交通工具、交通堵塞时优先通行；可优先使用机关团体企事业和个人的交通工具、通讯工具、场地、建筑物；用后归还，由所在公安机关支付适当费用。 |
| 优先通行与优先使用 | 是两个独立权利，不是一回事；优先通行指道路交通堵塞时先行通过，优先使用指借用单位、个人的车辆、手机、场地、房屋；题干问「什么权利」要按对象作答。 |
| 紧急征用权 | 适用于处置暴力犯罪、重大治安灾害事故、追捕逃犯等情形；可征用急需的人员、物资和场所，如整栋会所；用后返还，造成损失按现行做题口径处理。 |
| 合法补偿违法赔偿 | 国家合法行为致损为补偿，违法行为致损为赔偿；<strong>紧急优先致损人民警察法写的是赔偿</strong>，属合法却赔偿的特例；赔偿主体是民警所在公安机关，不是民警个人。 |
| 征用损失口径冲突 | 人民警察法只规定紧急优先赔偿，未规定紧急征用；2013 年公安部小蓝本与命题习惯把两者捆绑按赔偿；2024 年应急处突法改为补偿。<strong>抓捕搏斗类案例按赔偿，爆炸等突发事件类按补偿</strong>。 |
| 紧急排险权 | 在紧急处置重大灾害事故或平息叛乱时行使；<strong>不得已</strong>时可拆除建筑物、摧毁设施；所有者必须无条件服从现场指挥员指挥、履行拆除义务。 |
| 交通管制审批 | 由县级以上公安机关决定，即分局及分局以上层级；不需再报同级人民政府。 |
| 现场管制审批 | 针对严重危害社会治安秩序的突发事件，可按实际情况实施；由分局报<strong>上一级公安机关（市局）和同级人民政府</strong>批准，两者是「和」不是「或」。 |
| 部分地区戒严 | 省、自治区、直辖市范围内部分地区的戒严，由<strong>国务院决定、总理发布</strong>戒严令。 |
| 全国或全省戒严 | 全国或个别省、自治区、直辖市的戒严，由<strong>全国人大常委会决定、国家主席发布</strong>；必要时派人民解放军协助执行。 |
| 非工作时间履职 | 警察 24 小时 365 天待命，无上下班之分；休假在外遇歹徒行凶应上前制止；<strong>没有「暂时性履行职责」这一说法</strong>。 |
| 基本义务 | 共六项：秉公执法、办事公道；模范遵守社会公德、礼貌待人、文明执勤；尊重人民群众的风俗习惯。本集为复述，另用四字压缩语记忆。 |
| 救助属义务 | 人民警察遇到公民人身、财产安全受侵犯或处于危险情形，应当立即救助，属<strong>义务</strong>；只有题干同时给出「义务」「职责」两个选项时才需区分。 |
| 纠纷求助要给帮助 | 民事纠纷不属公安管辖，但对群众提出的解决纠纷要求应给予适当帮助；<strong>「直接」告知去法院起诉是错误选项</strong>，错在「直接」。 |
| 执行上级命令 | 上级命令必须执行，通常逐级下达，特别紧急时可越级；认为命令有误<strong>「可以」提出建议</strong>，提不提均可，但不得中止或改变；后果由上级承担。 |
| 越级命令的执行 | 接到越级命令必须坚决执行；除下达机关明确要求外，执行同时直接向上级报告；因故不能及时报告的，允许时迅速补报。 |
| 不同建制共同执勤 | 先服从上级指定负责人的领导和指挥；建制不明时由<strong>行政职务高</strong>者指挥；职务难以区分时由<strong>警衔高</strong>者指挥；本集复述第 35 集口诀「建制不同听上级，建制不明找领导，难以区分看警衔」 |
| 可拒绝执行的命令 | 命令明显超越法律法规、属违法犯罪时有权拒绝执行；同时应向<strong>上级机关报告</strong>，也可向督察反映。 |
| 警车与警用摩托 | 警车含大、中、小、微型客车及紧急救援、现场处置等专门用途车辆；摩托车标志灯具装在<strong>后轮右侧</strong>；汽车前后各一面号牌，摩托车只在车身后部装一面。 |
| 驾驶警车的条件 | 由所属单位人民警察或<strong>辅警</strong>驾驶；除警卫任务外着制式服装、可不戴警帽，驾摩托须戴头盔；持驾驶证和人民警察证，辅警另加工作证；试用期、实习期内不得驾驶。 |
| 警报器使用规则 | 一般情况只使用标志灯具；通过车辆人员繁杂路段或警告他车让行时可<strong>断续</strong>使用警报器；两车以上列队前车用过后车不再用；禁鸣路段区域禁用。 |
| 紧急任务优先通行 | 使用标志灯具、警报器执行紧急任务时享有优先通行权；可不受行驶路线、方向、速度、信号灯和标志限制；撞人仍须赔偿，只免违反交通法规的行政责任。 |
| 警械与武器 | <strong>防爆枪属武器</strong>，手枪、冲锋枪、狙击枪同属武器；手铐、脚镣、催泪喷射器、警棍、<strong>特种防爆枪属警械</strong>。 |
| 易燃易爆场所用枪 | 原则上不得使用武器，防止引发更大灾害；只有不使用武器会造成更严重后果时才迫不得已使用；特种防爆枪射橡胶弹，可以使用。 |

## 课程口诀

::: tip
**口诀（损失赔偿）：「合法补偿，违法赔偿；紧急优先特殊，既合法还赔偿」**

国家合法行为致损叫补偿，违法致损叫赔偿；紧急优先是人民警察法里写「赔偿」的立法特例。

课程位置：12:00。
:::
