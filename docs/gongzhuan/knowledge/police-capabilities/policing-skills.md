# 警务技能

## 知识点速记

> 来源：2027 公专 P53 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 武器警械的界限 | 武器只指枪支弹药等致命性警用装备；警械分手铐、脚镣、警绳等约束性和警棍、催泪喷射器、高压水枪等制服驱逐性；<strong>特种防暴枪属警械</strong>，普通防暴枪属武器。 |
| 警械的两大分类 | 约束性警械用于限制人身自由，如手铐、脚镣、警绳、约束带；制服性、驱逐性警械用于强行制止，如警棍、催泪喷射器、高压水枪、特种防暴枪。 |
| 醉酒者禁用铐镣 | 对醉酒的违法嫌疑人<strong>不得使用手铐、脚镣</strong>；可以改用警绳、约束带等约束性警械；约束至其酒醒，不得超范围使用。 |
| 体前上铐的适用 | 嫌疑人完全配合、危险程度最低时用体前上铐；指认现场、上法庭、体检、去洗手间、会见均属此类；抓捕和拒不配合的用背手上铐。 |
| 搜身的人身检查顺序 | 令嫌疑人背对开阔地带，双手抬起扶墙或扶车；从双手开始自上而下查到脚，鞋底也要查；腋下、衣领、腰部、胸部、口袋、皮带处重点轻拍。 |
| 人包分离与人车分离 | 先查人再查物、先查人再查车，人与包、车必须分离；例外是物品在衣裤兜内，确保安全时可让其自己掏出；民警不得替嫌疑人背包。 |
| 盘查的安全第一原则 | 接近前先控制安全距离；带离时避开闹市区，防止其逃窜；不得让嫌疑人自己背着包；主副盘查手都要随时观察其情绪变化。 |
| 警械使用的限度 | 以制止违法犯罪行为为必要限度，行为停止即停止；不得出于泄愤继续加害；使用中要保护公民合法权益，命令无关人员躲避。 |
| 警械与武器的警告 | 使用警械前<strong>必须警告</strong>，没有例外；使用武器前来不及警告的可不予警告，直接射击；警告时一并命令无关人员躲避。 |
| 警棍的打击部位 | 优先打击小臂、大腿、腹部等非要害部位；避免攻击头部、颈部、裆部、太阳穴、耳根等致命部位；狭小空间挥不开，一般不宜使用警棍。 |
| 催泪喷射器的站位 | 必须站在上风口、上风方向使用；逆风使用药剂会被吹回自己脸上；考试常以小旗子示意风向，先判风向再选站位。 |
| 喷射后的现场处置 | 令嫌疑人向其侧后方退步离开污染区；民警待其脱离后再上前，避免自己中剂；刀棍等凶器先踢远，再上前控制。 |
| 喷射后的眼部处理 | 先问有无心脏病、哮喘等病史及是否戴眼镜、美瞳；用流水冲洗，水龙头、瓶装水均可；不得用脸盆水撩洗，污水回流越洗越疼；避免揉眼、避免平躺。 |
| 卡弹故障排除 | 64 式、92 式手枪的常见基础故障；按「一锁二退三拉四装」排除；侧拉套筒时另一只手接住退出的弹；复装后即可恢复射击。 |
| 武器不得使用的情形 | 怀孕妇女、儿童原则上不得使用武器，其使用枪支爆炸物实施严重暴力除外；人群密集或存放危险物品场所不得使用；盗窃、抢夺、诈骗等非暴力犯罪不得使用。 |
| 不得鸣枪的情形 | 人群密集场所不得鸣枪；重要设施、设备场所不得鸣枪；鸣枪可能造成更严重后果的不得鸣枪；鸣枪前须抬头确认上方无人。 |
| 使用武器后的流程 | 第一步先救人，不得因其是嫌疑人而拒绝施救；第二步由民警个人向所属或当地公安机关报告；第三步技术人员到场勘查弹道；最后<strong>由公安机关</strong>向检察院和当地党委政府报告。 |
| 违规用枪的后果 | 不该用枪而用枪，可能按故意杀人罪定罪判刑；合法用枪也要接受检察院审查、写报告；赔偿由所在公安机关承担，不由民警个人赔付。 |
| 五大安全要素 | 戒备、距离、位置、掩体、沟通五项并重；掩体能挡子弹和砍刀，如墙、车、房屋；遮蔽物只挡视线不挡弹，如草丛、灌木、草垛。 |
| 行动前的敌情掌握 | 明确参战人数、携带装备和车辆；掌握嫌疑人人数、装备、头目与同伙；了解房屋布局与进出路线；入室行动至少留一人在外警戒。 |
| 切角战术的60度 | 沿门框、墙角逐步切角，边切边观察；切到 <strong>60 度</strong>时必须决断前进还是后退；这就是黄金 60 度角原则，不可贴墙不动。 |
| 双警与三警作战 | 双警作战两枪指向互补、交替式前进，枪口不得指向同伴；三警作战前锋与掩护蛙跳式推进，第三人居后警戒后方。 |

## 课程口诀

::: tip
**口诀（卡弹故障排除）：「一锁二退三拉四装」**

手枪卡弹的排除顺序：一锁＝锁套筒；二退＝退弹夹；三拉＝侧拉套筒退出卡弹；四装＝重新装套筒、弹匣。

课程位置：46:30。
:::
