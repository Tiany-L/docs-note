# 公安勤务能力、接处警

## 知识点速记

> 来源：2027 公专 P51 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 巡逻三种方式 | 步巡隐蔽安静、速度慢效率低；车巡机动快速、高效，但隐蔽性差；空巡主要靠无人机高空监控。步巡、车巡是常规主力。 |
| 重点区域配置 | 居民区、繁华商场以步巡为主、车巡为辅；党政机关周边优先步巡，避免车辆噪音干扰办公；空旷地带以车巡为主，可配无人机巡查。 |
| 着装便衣之别 | 着装巡逻公开、威慑力大但隐蔽性差，便衣巡逻隐蔽性强而威慑力小；便衣由所领导批准即可，但应主动出示警官证，警械须隐蔽伪装。 |
| 警官证出示 | 着警服本身就是执法依据，当事人要求时再出示警官证；可以举给对方看，<strong>不得递给当事人</strong>，防止被抢、被摔或拍照炒作。 |
| 巡逻纪律报告 | 按指定路线、时段巡逻，不得无故脱区、减时减密；到重点区域应停留巡查；遇事要先期处置并报110指挥中心，不得擅自脱岗送人。 |
| 人包分离 | 盘查带包人员第一步人包分离，令其退开几步、碰不到包；第二步先查人、后查包，因为人能跑能打，比包更危险。 |
| 主副盘手分工 | 主盘手负责问话和检查，副盘手负责警戒；副盘手既要盯嫌疑人的神情和小动作，也要观察周边有无同伙，不能只盯一边。 |
| 盘查站位距离 | 侧应、弧形、前后夹击、三角四种站位；主盘手与嫌疑人相距1.5至2米，副盘手2至3米；规范只要求1米以上。 |
| 安全检查免证 | 盘查中的人身检查属于安全检查，由民警当场自行决定，不需要审批、不需要检查证，事后也不用补证。 |
| 查包规范 | 查包先听、闻、摸，慢拉拉链，物品逐件取出查看；全程让嫌疑人看着民警查，防止事后诬称包内丢钱丢物。 |
| 衣兜裤兜例外 | 只有衣兜、裤兜内的物品，在确保安全的前提下可命令嫌疑人自己掏出；手提包、背包、单肩包一律由民警检查。 |
| 人身检查姿势 | 令其双臂举过头顶，面向墙壁或车辆扶好，双脚后移使重心不稳；民警一脚踩在其两腿之间，随时可以控制。 |
| 人身检查顺序 | 从上到下、从右至左检查，从高举的双手开始；重点查腋下、腰部、裆部、双腿和鞋内，动作轻拍不乱摸。 |
| 女性检查要求 | 检查女性嫌疑人应当由女性工作人员进行；情况紧急、不检查即危及安全时可例外，但必须尊重人格尊严。 |
| 证件查验 | 命令嫌疑人自己掏出证件，民警不得搜身取证件；证件举到与肩同高、人证三点一线，让其自述姓名住址再核对。 |
| 阻碍执法处置 | 以言语纠缠、索要执法证为由拒不配合，即涉嫌阻碍执行职务；先口头传唤，仍不配合即强制传唤，武力逐级升级。 |
| 追捕逃犯 | 嫌疑人逃跑应当追，但要控制距离、从侧面按倒，不能从背后抓，防止其急停回身用刀刺伤民警。 |
| 车辆冲卡 | 遇车辆冲卡坚持能拦不追，立即报车牌、车型、逃窜方向，通知前方设卡堵截；只有可能造成更大危险时才追。 |
| 截停地点 | 卡点选收费站、检查站、弯道、上坡等能自然减速处；不选下坡、易逃窜路段和人流密集处，必要时设障碍引导减速。 |
| 卡点人数岗位 | 每个卡点<strong>不少于4人</strong>以便轮岗；设观察岗、拦截区、警戒岗、机动岗、安检区和驶离区，警戒岗取有利位置。 |
| 车辆截停接近 | 由前截停从车右侧绕到主驾，途经车尾不停留；由后截停警车停其后<strong>5至10米</strong>、车头偏左，后排无人到B柱侧后，有人到C柱侧后。 |
| 车辆盘查流程 | 命令熄火、钥匙放车顶、双手放在方向盘上，车内人员逐个下车；先查证、再查人、后查物，接近时先按尾箱看是否藏人。 |
| 110三类警情 | 打110分报警、求助、投诉三类；刑事案件、治安案件、交通警情、群体性事件和治安灾害事故都属于报警。 |
| 险情与事故 | 水电油气热设施仅怀疑出问题、尚未造成后果是险情，按求助处置；已经酿成事故的属治安灾害事故，按报警处置。 |
| 投诉转12389 | 投诉警情110不再转督察，直接告知拨打12389专用平台；投诉内容和投诉人情况应当严格保密，不得透露给被投诉人。 |
| 反诈96110 | 涉电信诈骗立即转96110反诈中心，核实后可紧急止付、冻结；紧急止付比冻结更快，专门解决冻结审批慢的问题。 |
| 派警与出警 | 一级出警、就近出警、分类出警；有人员伤亡先拨120；城市5分钟内到达，乡村尽快；出警<strong>不得少于两名正式民警</strong>。 |
| 处警报告 | 到达现场、处置完毕、需要增援三种情形都要向指挥中心报告；警力不足由指挥中心调特警机动组增援，不得自行了结不报。 |
| 执法记录仪使用 | 接警出警、现场处置处罚、检查搜查、交通管理、突发事件处置等只要执法就应当开启，没有可以不录的情形；带人上警车不得关机，进办案场所才能关。 |
| 记录保存公开 | 一般保存<strong>6个月</strong>，作为证据的刻盘永久保存；当日导出，异地或交通不便的24小时内导入；视频不属政府信息公开范围，但不涉密。 |
