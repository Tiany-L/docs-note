# 应急处突能力

## 知识点速记

> 来源：2027 公专 P52 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 突发事件四分类 | 共分自然灾害、事故灾害、公共卫生事件、社会安全事件 4 类；恐怖袭击、重特大刑事案件、踩踏事件归入社会安全事件。 |
| 四级分级与颜色 | 一般为四级蓝色，较大为三级黄色，重大为二级橙色，特别重大为一级红色；等级数字越小越严重，颜色由冷到暖排列。 |
| 突发事件领导权 | 具有统一领导权的是<strong>政府</strong>，不是公安机关；事件发生地县级政府为第一责任人，须及时向上一级政府报告，必要时可越级报告。 |
| 跨区域事件负责 | 涉及两个以上行政区域的，由共同的上一级政府负责；两区分属不同市的，由各有关行政区域的上一级政府共同负责。 |
| 群体性事件主管 | 群体性事件第一负责人是<strong>公安机关</strong>而非政府；上级公安机关可派人到现场指导，认为下级处置不力时可直接负责处置。 |
| 群体性事件跨区 | 凡跨区域的群体性事件，由共同上级公安机关负责；也可由上级公安机关指定另一机关负责处置，不硬压给属地分局。 |
| 核心区民警不配枪 | 处置群体性事件，核心区域一线民警<strong>不得配枪</strong>，可配警棍等警械；人群密集情绪激动，枪支一旦被夺后果不可收拾。 |
| 预警发布权限 | 县级以上政府可依法律法规和国务院规定发布相应级别警报；宣布有关地区进入预警期，同时向上一级政府报告，必要时可越级。 |
| 预警期不等于事发 | 预警期只表示存在危险、事件尚未确定发生；预警期内不控制企业法人代表，凡超出预警权限的选项一律不选。 |
| 安全撤离顺序 | 先撤附近居民，再撤媒体，然后是维持现场秩序的民警，消防人员最后撤离；因消防须留下灭火，故排在最后。 |
| 现场三层保护区 | 核心保护区即操作层，只允许勘察、消防、医护、专家进入；区域保护区即管理层，可停车辆并设现场指挥部；一般保护区即决策层安排新闻媒体。 |
| 舆情处置选项 | 舆情类题目一律选迅速、立即公布事实真相的选项；其余选项再有道理也不选；要害在快，慢了谣言先占舆论场。 |
| 新闻发布会主持 | 突发事件的新闻发布会由政府主持，不由公安机关主持；凡与突发事件相关的统一领导权，都在政府手里。 |
| 三慎三可原则 | 三慎指慎用警力、慎用强制措施、慎用武器警械；三可三不可指可散不可聚、可顺不可激、可解不可结。 |
| 警力调动审批 | 调用 100 人以下由分局长批准；100 至 300 人由市局局长批准；300 人以上由省厅厅长批准并报公安部备案；异地调警由共同上级批准。 |
| 爆炸物警情处置 | 派出所民警只能疏散群众、拉警戒线、向指挥中心报告、请求专业排爆人员到场；不得自行搬抱、丢弃爆炸物。 |
| 救人控场看危险源 | 先救人还是先控场没有固定顺序；有危险源且阻碍施救时，先排除危险源再救人；无危险源或危险轻微时先救人。 |
| 指挥部设上风口 | 事故现场指挥部应设在有毒气体泄漏点的上风口；不得设在下风口，否则处置人员先中毒，指挥随即失灵。 |
| 现场处置先后次序 | 先向上级报告、疏散围观群众，再保护现场，调查取证放最后；情况紧急来不及报告时，可先疏散群众、报告后推。 |
| 西北风含义 | 西北风指从西北方向吹来的风，不是吹向西北的风；判断火势蔓延方向和撤离路线，都要按这个含义来。 |
| 征用补偿与赔偿 | 人民警察法案例中征用致损叫<strong>赔偿</strong>，突发事件应对法中征用致损叫<strong>补偿</strong>；判断先看题干描述属哪类警情。 |
| 应急指挥机构效力 | 应急指挥机构发布的决定、命令、措施与政府发布的具有同等效力，法律责任由政府承担；发布后须向<strong>本级人大常委会备案</strong>。 |
| 公安不担的救援事项 | 搭建救灾帐篷归民政部门，心理疏导、理赔亦非公安职责；应急处突中公安负责治安维稳、秩序维护与舆情引导监测。 |
