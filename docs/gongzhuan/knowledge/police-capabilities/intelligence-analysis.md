# 情报分析能力

## 知识点速记

> 来源：2027 公专 P50 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 图表题定位 | 情报分析只考图表题，没有理论知识点；要在大量杂乱数据里筛出有用信息，再让几条信息互相碰撞选出答案；本质考逻辑思维，不考背诵。 |
| 题量分布 | 2025 多省联考图表题史上最多，100 道题里约 <strong>30 多道</strong>；国考、公安院校题量与之相近；自主命题省份明显偏少，反映命题能力偏弱。 |
| 图表题位置 | 多排在 <strong>40 到 50 题</strong>、单选最后十道；此时已连做几十题，眼和脑都疲劳；放在这里就是考你懵的时候还能不能拎清逻辑。 |
| 图表题读图顺序 | 图先扫 3 到 5 秒，只认清横轴纵轴各是什么、数据怎么打架，别细研究；然后读选项，选项问哪个指标就回图里找哪个指标。 |
| 数据碰撞看横纵 | 先认横纵：横向多是场所或案件类型，纵向多是警务室或区域；问哪个维度就沿哪个维度加总；合计要彼此接近才算平均，差得多直接排除。 |
| 时间推算题 | 用出发时间加单程耗时推到达，用离开时间加单程耗时推返回；只符合一头的是陷阱，两头都对才算嫌疑对象。 |
| 探路车判断 | 探路车、前导车出现时间必定早于目标车辆；以目标车时间为基准，晚于它的一律排除；只留时间更早且能衔接的那辆。 |
| 标准项法 | 先看选项找反复出现的那一项，它就是标准项、一定成立；再拿其余各选项与标准项逐项比对，差得多的直接排除。 |
| 出题人设坑处 | 最常在做案时间上设坑，上半夜混进下半夜就要警惕；其次是身高，差 5 厘米以上多半不对；长脸方脸、外套、有无持刀一般不设坑。 |
| 主叫与被叫 | <strong>主叫</strong>是嫌疑人主动打出，<strong>被叫</strong>是对方打进来被动接听；判读前先看清这份话单是谁的，嫌疑人、亲属、买家、被害人结论完全相反。 |
| 话单找老大 | 通话次数最多、每通时间最短的，多半是背后的 boss；案发前通话量突然变多，或固定时间拨固定号码的规律呼叫，也多指向主犯。 |
| 话单异常信号 | 案发前后凭空冒出的陌生号码，多是为躲追踪换的黑卡；案发之后通话量骤减乃至归零，也大概率指向 boss 本人。 |
| 亲属话单新号 | 嫌疑人换号后亲属并不知情，所以新号码在亲属话单里第一次出现必然是被叫；首次即主叫的一律排除，再看出现次数选更频繁的。 |
| 话单题干翻译 | 先把题干译成可数的条件，如当天两次主叫就是同一天内出现两次、两次都主动打出；再回话单用不同记号逐条勾画，别把数据看混。 |
| 通话时间找老大 | 命令按层级逐级下达，通话时间<strong>最早</strong>的那个就是源头；从最早一通往下捋，捋两步接不上就弃掉，换下一个时间段的人重新起头。 |
| 矩阵图符号 | 实心点表示已确定关系，空心点表示未确定关系；加号表示已确定参与人，横线表示尚未确定关系人；两方连线相交处的符号就是答案。 |
| 资金流向找老大 | 只看钱最后流进谁的口袋、谁收得最多；钱只出不进的是过路账户，进出都有的也不是，箭头全指向的那一个才是。 |
| 层级留成辨主犯 | 每层截留一点再往下转，是层层分赃；全部先打给同一个人再由他往下分，那人就是主犯；各层截留数额不一，还可能分赃不均。 |
| 虚拟币洗钱单价 | 判断加价还是折价要算单价，用总价除以币数；单价相同即同价，回收价低于卖出价即折价，只看总额容易误判。 |
| 年龄结构图 | 比较两类人数量差，看同一年龄段两柱相差几格；两者都是 0 的年龄段没有比较意义，不能当成相差最小；主集中区间看柱子整体偏向哪边。 |
| 增幅计算 | 增幅等于本期减同期再除以同期；这类题 80% 靠眼睛比高低就能定，只有 20% 要动笔算，动笔前先筛掉下降项。 |
| 同类重复案件 | 同类重复指两次落在同一类型上，把第一次与第二次同类型的数对应相加；选项尾数互不相同时用尾数法，只算个位即可。 |
| 热点图布警 | 颜色越深表示该类案件越高发，巡逻重点就压在深色区域；人流骤增的场所要提前疏导分流，别等拥堵成型。 |
| 预案启动时点 | 实际人数曲线开始高于原计划，就是拐点，预案自此启动；此后仍高于原计划就不能撤，增派警力要留余量。 |
| 图表题心法 | 图越复杂题往往越简单，图越简单反而越难；本质考心态，遇复杂图先闭眼缓两三秒再动笔，往往事半功倍。 |
