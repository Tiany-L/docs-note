# 群众工作能力

## 知识点速记

> 来源：2027 公专 P49 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 法治副校长 | 由社区民警、派出所民警或辖区民警担任；只给名分，不加编制、不另发工资；不能因为当了副校长就不回派出所上班。 |
| 宣传保密 | 不得泄露被宣传对象的个人隐私；不得公开工作中获知的商业秘密；不得让有违法犯罪前科的人以嫌疑人身份现身说法。 |
| 不得宣传的警务秘密 | 打击违法犯罪的具体部署、行动方案、情况报告不公开；正在侦查案件的方案、案情与进展不公开；特情、技术侦查手段、详细作案手段及凶杀场面、色情细节一律不公开。 |
| 现场民警不得受访 | 现场民警一律不得接受记者采访、不得透露案情；记者须持记者证到政工部门或政治部联系；重特大案件经上一级机关批准后才可选择报道。 |
| 两队一室 | 社区警务队管社区、案件办理队管办案；综合指挥室是派出所中枢，多由内勤带人承担；两队协作共同落实派出所主防。 |
| 两个40% | 派出所警力数占分局总警力数<strong>40%</strong>以上；社区民警占派出所总警力数 40% 以上；比值由公安部规定，用于充实基层警力。 |
| 一管三防 | 一管指管控治安要素；三防指防范辖区发案、防范涉稳事端、防治安事故；考试只考名词对应，不展开解释。 |
| 暂住人口协查 | 以上级推送的异常轨迹动向核查为主；以实际走访为主并及时录入系统；必要时才通过基础管控中心向流出地发起协查协作。 |
| 走访重点人群 | 危险人员是涉恐、涉稳、重大刑事犯罪前科、涉毒、在逃、肇事肇祸精神病人；重点住户含单身独居、私房出租、人户分离；重点地区是交通要道、复杂场所、城乡结合部。 |
| 刑满释放不满五年 | 属重点人员，首次见面时进行一次法治谈话；同时逐人建立档案；只在首次，不是每次见面都谈话、都建档。 |
| 吸毒人员管控 | 社区民警至少每半年开展一次评估；发现持有驾驶证的通报交管部门；是否收回、注销由交管依法处理。 |
| 剥夺政治权利人员 | 每月向公安机关报告一次活动情况；由民警当面了解当月行踪和收入来源；报告频次按月计算。 |
| 家暴告诫书查访 | 送达告诫书后<strong>7 日</strong>内首次查访；未再实施家暴的改为每 3 个月一次；连续 3 次未发现即不再查访，中途中断则重新计算。 |
| 严重不良未成年人 | 未达刑事责任年龄不予追究的、吸食注射毒品或向他人提供毒品的；应责令未成年人及其监护人每月报告一次；孩子和监护人要一起来。 |
| 肇事肇祸精神病人 | 用的是随访，没有次数和时间间隔限制；只针对有严重伤害行为或自杀行为的；普通精神病人不纳入随访。 |
| 取保与监视居住 | 及时告知应当遵守的规定和违反后果；发现违反规定应当制止；告知情况须在 3 日内向决定机关反馈。 |
| 民警不承诺 | 对任何一方都不承诺能办成什么；承诺讨回欠款、承诺一定抓到真凶都是大忌；兑现不了会引发上访和次生事端。 |
| 协调用语 | 不用要求、责令、命令这类强硬词；改用建议、提议、协商、协调、沟通；提的建议还要合理、有针对性、能解决问题。 |
| 警力有限民力无穷 | 可以组织发动群众参与维护社会治安；群众只能发现线索并向公安机关报告；不能让群众查身份证、搞侦查、参与抓捕。 |
| 与治保会的关系 | 公安机关对治保会、联防队、治安志愿者等群众组织是指导关系；不是领导与被领导关系；只能指导，不能下命令。 |
| 纠纷应当帮助 | 群众提出解决纠纷要求的应当给予帮助；帮助不等于解决，民事、消费纠纷告知或协助联系主管部门即可；不能不闻不问。 |
| 三类调解 | 治安调解由公安机关主持，针对轻微治安案件；司法调解由法院主持；人民调解由村委会、居委会等民间组织主持。 |
| 现场不得等待 | 凡只写等待的多为不作为；打完 120 还要维护现场、采取必要措施、呼叫增援；有后续处置动作的等待才可以选。 |
| 治安检查方式 | 对人身只能轻拍和摸索；不得直接伸入内衣内层翻摸；检查女性须由女性工作人员徒手或使用安检仪进行。 |
| 事前与事后 | 预防、防范、早感知、早预判都翻成事前；打击、处罚、惩戒、整治、查处都翻成事后；看清题干问的是哪一头。 |
| 旅馆检查流程 | 先确定参检人员；再做岗前教育、强调保密纪律；然后表明身份、出示证件，边检查边记录，发现问题责令整改。 |
| 大型活动审批 | 预计 1000 人至 5000 人的由分局审批；5000 人以上的由市局或直辖市公安机关审批；跨省、自治区、直辖市举办的由公安部审批。 |
| 大型活动处置 | 有严重安全隐患可责令停止；对正在实施违法行为的人强行带离现场；命令解散而拒不离开的可以强行驱散，驱散带一定强制性。 |
| 行政许可禁申期 | 隐瞒情况或提供虚假材料、尚未取得许可的，1 年内不得再申请；以欺骗、贿赂手段已取得许可的，3 年内不得再申请；均以涉及公共安全、人身健康、生命财产安全为前提。 |
| 娱乐场所禁设地点 | 不得设在住宅建筑物内及商住两用楼；不得设在博物馆、图书馆、居民住宅区、学校幼儿园医院周边、党政机关周边、车站机场等人员密集场所；不得与危险化学品毗邻。 |
| 消防疏散要求 | 疏散通道和安全出口设明显标志，不得遮挡；通道、出口须畅通，不得封堵、锁闭、设障碍物；逃生门必须向外推，不能向里拉。 |
| 娱乐场所监控留存 | 歌舞娱乐场所出入口和主要通道须装闭路电视监控；营业期间不得中断；录像资料留存 30 日备查，营业日志留存 60 日。 |

**以下为来源文件保留的疑点，复习时需结合原课或正式规定核对。**

- 29:00：讲者反复说「两个百分之四」「两个百分之四十」，语音混乱，清单按派出所警力占分局 40%、社区民警占派出所 40% 记载，待核对。
- 32:30：一管三防中三防语音为「防范辖区」「防涉稳事端」「防治安事故」，第一项是否为「防范辖区发案」需核对讲义原词。
- 40:00：帮教转化人员属地分工一句语义混乱，似为「以公安机关帮教转化为主、以居住地为主，户籍地与实际居住地配合」，因无法确认未收入清单。
- 51:00：讲「八周岁的小孩抢劫」处疑为语音误识或口误，未达刑事责任年龄的具体表述需按现行刑法核对，清单只写未达刑责年龄。
- 141:00：语音作「营业之志」「阴约日制」，应为「营业日志」，留存 60 日；请确认讲义用词。
:::
