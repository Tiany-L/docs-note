# 治安处罚的种类及执行

## 1. 处罚种类

基本四种：**警告、罚款、行政拘留、吊销公安机关发放的许可证件**。

对外国人，可以附加限期出境或驱逐出境。

- 处罚意义上的警告，应有书面决定，不能与一般口头提醒混同。
- 行政拘留通常单项不超过15日；数种违法行为合并执行，最长**20日**。
- 行政拘留送**拘留所**执行。
- 送入拘留所当日不计，次日为实际执行第一日。

## 2. 不执行行政拘留

一般适用于：

| 人员 | 一般规则 |
|---|---|
| 已满14、不满16周岁 | 不执行 |
| 已满16、不满18周岁，初次违反治安管理 | 不执行 |
| 已满70周岁 | 不执行 |
| 怀孕或哺乳自己不满1周岁婴儿 | 不执行 |

::: danger
**新法例外必须记：**

- 前三类人员，情节严重、影响恶劣的，可以依法执行。
- 14—16周岁人员、70周岁以上人员，**一年内二次以上**违反治安管理的，也不再当然不执行。
:::

“不执行拘留”不等于“不予处罚”，更不等于没有违法记录。

## 3. 暂缓执行与临时出所

依法申请暂缓后，还要满足：

**不致发生社会危险＋合格担保人，或者按每日200元交保证金。**

- 担保人与保证金是选择关系，不必同时提供。
- 暂缓拘留不意味着并处的罚款也暂缓。
- 新法增加升学考试、子女出生、近亲属病危或死亡等特殊情形。
- 已在执行拘留的，可依法申请临时出所；**出所时间不计入拘留期限**。
- 提出复议、诉讼或申请，不等于自动停止执行。

## 课程复习清单

> 来源：2027 公专 P11 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 处罚前告知义务 | 作出处罚前必须先履行告知；载体是<strong>行政处罚告知笔录</strong>；原则上书面，只有快速办理和当场处罚可以口头。 |
| 治安处罚六个种类 | 警告、罚款、行政拘留、吊销公安机关发放的许可证、限期出境、驱逐出境；最爱考罚款和拘留；<strong>限期出境、驱逐出境只针对外国人</strong>。 |
| 警告属于精神罚 | 警告是精神罚，必须出具书面的行政处罚决定书；<strong>不是</strong>现场执法的口头警告、口头制止；此警告非彼警告。 |
| 罚款金额四个档次 | 当场收缴且无异议 200 元以下；当场处罚（简易程序）500 元以下；派出所最高 1000 元以下；<strong>派出所只有警告和 1000 元以下罚款</strong>两项权限。 |
| 听证的启动门槛 | 个人 4000 元以上、企业 1 万元、违反出入境管理 6000 元；<strong>不需任何审批</strong>，当事人申请即启动；系复述前集口诀，本集未重编。 |
| 治安罚款上限 | 治安管理处罚法领域对个人罚款最高 5000 元；<strong>不是听证的 4000，也不是出入境的 6000</strong>。 |
| 罚款合并执行 | 数个违法行为各有罚款，合并执行按各项数额<strong>简单相加</strong>；加多少都行，<strong>没有上限</strong>。 |
| 拘留合并执行上限 | 两种以上违法行为分别决定拘留，合并执行最长 20 日；<strong>不能简单相加</strong>，10 日加 15 日不等于 25 日。 |
| 行政拘留羁押场所 | 行政拘留送拘留所，刑事拘留送看守所；同院办公时称监管大队，<strong>左边治安、右边刑事</strong>。 |
| 同种行为多次违法 | 三次连续吸毒仍属一种违法行为，不适用 20 日合并；只能在 5 日以下、5 至 10 日、10 至 15 日幅度内裁量，<strong>最长 15 日</strong>。 |
| 执行中又发现违法行为 | 拘留执行完毕前发现另有违法行为需拘留，与正在执行的拘留合并；<strong>仍不超过 20 日</strong>，已执行 10 日再拘 15 日只再执行 10 日。 |
| 涉案财物四类措施 | 只有扣押、收缴、追缴、登记后立即返还四种；<strong>没有「没收」</strong>，没收是处罚种类；第三人的合法财物只能登记后立即返还，不得扣押、收缴、追缴。 |
| 决定书的救济途径 | 60 日内向同级政府申请行政复议，或 6 个月内向法院起诉；<strong>当场处罚决定书是复议前置</strong>，不服复议才能起诉。 |
| 措施与执行的分界 | 分水岭是行政处罚：强制措施在处罚前，约束、传唤、扣押都属措施；强制执行在处罚后，<strong>因当事人不履行处罚才启动</strong>。 |
| 催告书的载明事项 | 载明履行期限、方式、金额、给付方式和陈述申辩权；<strong>不载救济途径</strong>，因催告不是行政行为、不引起法定义务变更。 |
| 罚款缴纳与滞纳金 | 收到决定书 15 日内到指定银行或电子支付系统缴纳；逾期每日加处 3%，<strong>加处总额不超过本金</strong>。 |
| 当场收缴罚款情形 | ①200 元以下且无异议；②边远、水上、交通不便地区，到银行或电子支付确有困难并经当事人提出；③当地无固定住所、事后难以执行；须出具<strong>省级以上财政部门</strong>统一制发收据，否则有权拒缴。 |
| 吸毒的三级处置 | 第一次吸毒正常处罚；第二次认定成瘾，加社区戒毒 3 年；第三次加强制隔离戒毒 2 年，违规可延 1 年，最长 3 年。 |
| 拘留与强戒的衔接 | 拘留所有戒毒条件的，先执行拘留并作戒毒治疗，强戒期限连续计算，<strong>拘留天数折抵</strong>；无戒毒条件的直接送强戒所代为执行。 |
| 拘留期间的计算 | 送入拘留所当日不计入，<strong>次日为执行第一日</strong>；10 月 3 日送入、10 月 13 日出所；行政拘留自送所时起算，刑事拘留自宣布时起算。 |
| 拘留期限的折抵 | 处罚前限制人身自由的行政、刑事强制措施都折抵，一日折一日；<strong>已羁押超过拘留期限的不再执行</strong>；当场盘问、继续盘问不折抵。 |
| 暂缓行政拘留事由 | 不服拘留决定申请复议或诉讼；新法增列升学考试、子女出生、近亲属病危或死亡；可口头也可书面申请。 |
| 暂缓执行的条件 | 公安机关认为不致发生社会危险；提供担保人或按每日 200 元交保证金，拘 10 日即 2000 元；<strong>只暂缓拘留，罚款照常执行</strong>。 |
| 临时出所 | 参加考试、子女出生、近亲属病危或死亡；被拘留人或其近亲属均可申请；<strong>出所时间不计入拘留期限</strong>，办完须回所。 |
| 人大代表拘留许可 | 县级以上：开会经主席团许可、闭会经常委会许可；<strong>乡级只需立即报告</strong>，不需许可。 |
| 拘留通知家属 | <strong>立即通知</strong>，不是 24 小时之内；无法通知或不提供家属联系方式的，在附卷的决定书中注明。 |
| 不执行拘留的情形 | 已满 14 不满 16 周岁；已满 16 不满 18 周岁初次违反；70 周岁以上；怀孕或哺乳自己婴儿的妇女；<strong>仍作处罚决定、留案底</strong>，只是不投送执行；例外是前三类情节严重恶劣、一年内两次以上违反的照常送所，孕妇哺乳妇女仍不执行。 |
| 停止执行拘留 | 患精神病或传染病需隔离治疗、病情严重危及生命、生活不能自理；<strong>能治好回所继续执行，治不好不再执行</strong>。 |
| 初次违反的认定 | 指第一次被公安机关查处；曾被行政拘留（含不执行）、罚款、警告的都不算初次；曾违法但未被发现且已过 6 个月追诉时效的算初次，<strong>调解结案的也算初次</strong>。 |
| 吸毒人员风险分级 | 分高、中、低三级，只按具体情形认定，<strong>与复吸性、吸毒次数无关</strong>；高风险如拒绝社区戒毒、吞食异物自伤自残、精神异常行为失控、扬言报复社会，其余为低风险。 |
