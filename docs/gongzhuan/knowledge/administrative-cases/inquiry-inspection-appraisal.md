# 询问、勘验、检查、鉴定

## 1. 询问

- 询问违法嫌疑人、被侵害人、证人，均应**个别进行**。
- 对违法嫌疑人可以依法传唤；对被侵害人、证人用**通知**，不能传唤。
- 治安案件使用“询问”；刑事案件针对犯罪嫌疑人使用“讯问”。

**询问查证时间：8、12、24小时。**

从被传唤人**到案时**开始，到其可以自由离开询问地点时结束；醉酒约束时间不计入。

特殊对象：

| 对象 | 要求 |
|---|---|
| 不满18周岁的行为人 | 通知父母或其他监护人到场；不能到场的，可通知合适成年人 |
| 聋哑人员 | 有通晓手语等交流方式的人帮助 |
| 不通晓当地语言文字 | 配备翻译人员 |
| 没有阅读能力 | 向其宣读笔录 |

笔录交本人核对，可以补充、更正；确认无误后**签名、盖章或者按指印**。

## 2. 勘验、检查

- 检查人员一般不得少于**2名民警**，出示人民警察证。
- 对场所检查，原则上经县级以上公安机关负责人批准，使用检查证。
- 确有必要立即检查的一般场所，可出示警察证当场检查，并**全程同步录音录像**。
- **检查公民住所，应当出示检查证。**不能直接套用一般场所的紧急检查例外。
- 检查妇女身体，由**女性工作人员或者医师**进行。
- 到案安全检查与调查取证中的检查要区分，安全检查不需要开具检查证。

## 3. 鉴定

::: tip
**重点记忆：5日告知、3日申请、重新鉴定一次。**
:::

- 收到鉴定意见后，依法在5日内将复印件送达违法嫌疑人和被侵害人。
- 有异议的，依法在3日内申请重新鉴定。
- 重新鉴定须经县级以上公安机关批准，**另行指派或聘请鉴定人**。
- 同一行政案件的同一事项，重新鉴定以**一次**为限。
- 多名鉴定人意见不一致，应注明，不能简单“少数服从多数”。
- 鉴定解决专门性问题，不能代替公安机关决定如何适用法律。

## 课程复习清单

> 来源：2027 公专 P07 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 询问与讯问 | 治安案件<strong>不问角色一律叫询问</strong>；刑事案件只有对犯罪嫌疑人叫<strong>讯问</strong>，证人、被害人仍是询问。题干出现「讯问」就是在暗示按刑事规则做 |
| 询问主体 | 原则上<strong>两名以上人民警察</strong>；一警可干是给基层减负的特例，且必须在规范设置、严格管理的执法办案场所 |
| 嫌疑人询问地点 | 执法办案场所询问室、住处、单位、<strong>所在市县的指定地点</strong>（村委会、居委会都算，正确）；<strong>带到民警办公室问不行</strong> |
| 证人被害人地点 | 现场、单位、学校、住处、村委会居委会、<strong>其本人提出的地点</strong>都行，必要时书面或电话通知到公安机关；<strong>公安提出的非公安场所不行</strong>。选地点的总原则是<strong>方便原则</strong> |
| 询问室设置 | 询问室、讯问室都设<strong>一楼</strong>，远离门窗；被询问人安排在远离门窗的位置并采取安全防范措施。二楼出过坠楼事故，办案人员一撸到底 |
| 时间与变相拘禁 | 时间与传唤同一套：8／12／24，起算于到案、终止于可自由离开；<strong>不得以连续传唤变相拘禁</strong>；醉酒约束时间不计入 |
| 四类特殊对象 | 聋哑人<strong>应当</strong>通知通晓手语的人；不通晓当地语言的<strong>应当</strong>配备翻译；没有阅读能力的<strong>应当</strong>向其宣读；未成年人<strong>应当</strong>通知监护人到场。全用「应当」，题干写「可以」就是错 |
| 未成年人到场顺序 | 监护人不能到场，依次找<strong>其他成年亲属</strong>（须成年，16 岁的姐姐不行）→ 学校或单位 → 居住地村委会居委会 → 未成年人保护组织或民政部门；确实无法通知的<strong>在笔录中注明</strong> |
| 未成年人是几岁 | 旧治安管理处罚法写 16 周岁、程序规定写 18 周岁，曾长期争议；新法统一为<strong>18 周岁以下</strong> |
| 安全检查 | 对查获或到案的违法嫌疑人进行安全检查，发现违禁品、管制器具、爆炸物、作案工具及证据应扣押。它是<strong>抓捕后顺带手的事</strong>，<strong>没有安全检查证</strong>，事后也不补证 |
| 自行书写 | 嫌疑人、被侵害人、证人请求自行书写的应当准许，民警也可以要求其自行书写；尾部<strong>签名或按手印</strong>，取其一即可 |
| 打印材料 | 打印的书面材料应<strong>逐页</strong>签名或按手印；民警收下后在<strong>首页</strong>注明收到日期并签名，这份材料叫<strong>亲笔陈述</strong> |
| 个别进行 | 询问应当<strong>个别进行</strong>：不得同时问两个证人（会互相干扰改口），也不得同时问两个嫌疑人（会串供使眼色） |
| 候问室 | 等候询问的场所，铁栅栏加软包或玻璃幕墙。治安案件里从头到尾只有「询问」，没有「讯问」 |
| 笔录怎么签 | 被询问人<strong>逐页</strong>签名<strong>或</strong>按指印；<strong>民警只在末页签名</strong>，不用逐页签。治安案件用「或」，刑事案件要求<strong>既签名又按手印</strong> |
| 笔录确认 | 新法：签名、盖章<strong>或</strong>按手印，三者取其一（多取不限）；拒绝的由办案民警在笔录中注明，<strong>不能代签</strong> |
| 勘验与检查 | <strong>勘验</strong>针对场所与痕迹物证，<strong>检查</strong>针对人身与场所；主体都是两名以上人民警察 |
| 检查证 | 原则上要县级以上公安机关开具的<strong>检查证＋人民警察证</strong>；<strong>检查住所必须双证齐全</strong>，没有例外可免；除住所以外确有必要的可当场检查，事后不补证 |
| 住所紧急检查 | 只有三种情形可只凭警察证进入住所：正在发生危害公共安全或人身安全的事件、存放危险物质、不立即检查可能造成重大危害。<strong>家里吸毒、嫖娼、赌博都不符合</strong> |
| 检查证一次有效 | 一次检查一次证，不能拿一张检查证跑张三李四两家 |
| 检查妇女身体 | 由<strong>女性工作人员</strong>或医师进行。依全国人大常委会法工委释义，「女性工作人员」指<strong>女民警</strong>；医师一般为女性，没有女性医师时男医师亦可 |
| 检查笔录签名 | 需检查人、被检查人、见证人签名。新法用「和」、程序规定用「或」、公安部最新文书又用「或」，<strong>三处打架</strong>；答题按新法，被检查人不在场或拒签的注明 |
| 见证人资格 | 不能是公安机关聘用人员，民警、辅警、门卫、食堂人员一律不行，也不能是与本案有牵连的人（同伙、嫌疑人的儿子） |
| 应当鉴定的情形 | 可能构成<strong>轻伤以上</strong>；<strong>被侵害人要求</strong>鉴定；双方对伤情有争议。鉴定经办案部门负责人批准，制作鉴定聘请书 |
| 家属不能要求鉴定 | 被侵害人的家属、亲属提出鉴定要求的，<strong>不属于「应当鉴定」</strong>。家暴案件尤其要尊重被害人本人意愿，很多被害人不愿鉴定 |
| 价格鉴定 | 价值明显不够刑事立案标准，或购物发票足以认定价值的（刚买的手机有发票），<strong>可以不作价格鉴定</strong> |
| 吸毒检测 | 对涉嫌吸毒人员应检测；拒绝检测的，经县级以上公安机关或其派出机构负责人批准可强制检测，<strong>属行政强制措施</strong>；<strong>大队长不能批</strong>；对女性检测应由女性工作人员进行 |
| 鉴定意见与送达 | 多人鉴定意见不同的<strong>应当注明</strong>，不是少数服从多数；收到鉴定意见<strong>五日内</strong>将复印件送达被侵害人与违法嫌疑人，有异议的<strong>三日内</strong>申请重新鉴定 |
| 重新鉴定 | 申请主体只有<strong>违法嫌疑人和被侵害人本人</strong>，家属不行；须经<strong>县级以上</strong>公安机关批准（动钱的事办案部门定不了）；<strong>另行指派或聘请</strong>鉴定人，不能还是原来那位；期间<strong>不停止办案</strong> |
| 鉴定次数与费用 | 同一事项<strong>鉴定最多两次</strong>（普通一次＋重新一次）；单问<strong>重新鉴定最多一次</strong>；费用由<strong>公安机关</strong>承担，当事人自己找第三方做的只能作参考 |

## 课程口诀

::: tip
**口诀（一警可干（复述第 5 集））：「闻辩解压，一警可干。」**

本集开头讲者回扣第 5 集的口诀，用来对比「两名以上民警询问」这条一般规定：闻＝询问、辩＝辨认、解＝调解、压＝扣押，前提是在规范设置、严格管理的执法办案场所。

课程位置：03:30。
:::

## 待核对事项

::: danger
**以下为来源文件保留的疑点，复习时需结合原课或正式规定核对。**

- 05:00：「询问须两名以上民警」与「执法办案场所内一警可询问」并存，讲者称后者是减负特例、前者是一般规定；程序规定修改后此冲突可能被消除。
- 45:00：检查妇女身体的「女性工作人员」存两版释义：法工委版指女民警，公安大学版含女辅警。讲者取前者，此点各机构讲义不一致。
- 52:30：检查笔录签名，新法用「和」、程序规定用「或」、公安部最新文书又用「或」，三处冲突，讲者建议按新法且认为命题会回避，需留意真题。
- 59:00：「家属无权要求伤情鉴定」出自 2025 年国考卷的考法，法律未正面规定家属权利，按尊重被害人意愿理解。
- 62:30：强制吸毒检测的批准主体为「县级以上公安机关负责人或其派出机构负责人」，讲者明确大队长不行，与 2026 年公安院校联考的考法一致，但条文表述需核对。
- 37:30：具体违法行为的处罚幅度讲者建议不死记，仅在判断「能否达到拘留」时才需要（如饲养动物、制造噪音两类）。
:::
