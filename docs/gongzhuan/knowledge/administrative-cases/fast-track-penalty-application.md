# 快速办理、行政处罚的适用

## 1. 快速办理

适用于**不适用简易程序**，但事实清楚、本人自愿认错认罚，对违法事实和法律适用无异议的行政案件。

办理前要**书面告知、征得同意、签名确认**。

以下情形不适用：

- 盲、聋、哑人员，未成年人或疑似精神病人；
- 应当适用听证程序；
- 可能作出**10日以上行政拘留**；
- 其他不宜快速办理的情形。

“10日以上”包含10日，看的是依法可能适用的处罚幅度，不能只看最后准备罚几天。

**到案后48小时内办理完毕，重点是作出处理决定，不等于执行完毕或结案。**

## 2. 处罚适用

- **一事不二罚款**：同一违法行为，不得给予两次以上罚款。
- 不满14周岁：不予行政处罚，责令监护人严加管教。
- 已满14、不满18周岁：从轻或减轻处罚。
- 醉酒违法：应当处罚，醉酒不是免责理由。
- 盲人或者又聋又哑的人：可以从轻、减轻或不予处罚。
- 精神障碍人员是否处罚，要看行为时的辨认、控制能力。

## 3. 从轻、减轻、不予处罚

新法重点：

- 情节轻微；
- 主动消除或减轻违法后果；
- 取得被侵害人谅解；
- 受他人胁迫或诱骗；
- 主动投案并如实陈述；
- 有立功表现。

**消除、减轻后果与取得谅解，已分成独立情形，不要求必须同时具备。**

## 4. 从重与追究时效

从重重点：较严重后果；教唆、胁迫、诱骗他人；打击报复；**一年内曾受治安管理处罚**。

::: danger
不要和追究时效混淆：

- 治安违法一般是**6个月内未被发现，不再处罚**。
- 从重处罚中的前次受罚期限，新法是**1年**。

:::

| --- | --- |
| 快速办理的定位 | 实务中几乎没人用，纯理论考点。它的减负点在<strong>取证环节</strong>；当场处罚的减负点在<strong>处罚程序</strong>。两者是完全独立的两套制度，别混 |
| 适用四要件 | 不适用简易程序；事实清楚；<strong>自愿认错认罚</strong>；对违法事实和法律适用<strong>没有异议</strong>。四条同时满足才可快速办理 |
| 不得适用 | 嫌疑人系<strong>盲、聋、哑、未成年人或精神病人</strong>（有其一即可）；可能适用听证程序的；可能作出 <strong>10 日以上拘留处罚幅度</strong>的 |
| 主体陷阱 | 「盲聋哑未成年精神病」说的是<strong>违法嫌疑人</strong>，不是被侵害人。被侵害人是盲人，案件照样可以快速办理 |
| 10 日以上指什么 | 指<strong>处罚幅度</strong>，不是最终结果。卖淫嫖娼、吸毒一般为 10—15 日 → 原则上不能快速办理；情节较轻降到 5 日以下，就可以 |
| 告知的书面与口头 | 快速办理的<strong>相关规定</strong>必须<strong>书面</strong>告知并征得同意、签名确认；<strong>处罚前告知义务可以口头</strong>。别记成「书面对规定、口头对义务」 |
| 启动与审批 | 不是嫌疑人申请就启动，而是公安认为适合后<strong>征求意见</strong>，嫌疑人不同意就走一般程序；审批由专（兼）职法制员或办案部门负责人审核，报<strong>公安机关负责人</strong>批准 |
| 48 小时 | 到案后 <strong>48 小时</strong>内办结；起点是到案，终点是<strong>作出处理决定</strong>—— 不是结案，也不是执行完毕 |
| 减负三招 | 使用简明扼要格式的询问笔录；提供样式让被询问人<strong>自行书写</strong>；<strong>全程录音录像可以代替</strong>书面询问笔录 |
| 程序转换 | 办到一半发现不能快速办理，转一般程序，<strong>之前收集的证据仍然有效</strong>（治安转治安，不是行政转刑事） |
| 结案的五种情形 | 不予处罚；调解达成协议并已履行；作出处理决定<strong>且已执行</strong>；涉嫌犯罪转刑事（原案结案）；作出决定前当事人死亡 |
| 追责时效 | 违反治安管理行为 <strong>6 个月</strong>内未被发现不再处罚；其他违法行为 <strong>2 年</strong>；涉及公民生命健康安全、金融安全且有危害后果的 <strong>5 年</strong> |
| 时效怎么算 | 从违法行为发生之日起算；有连续、继续或持续状态的，从<strong>行为终了之日</strong>起算 |
| 时效的三个例外 | ①公安机关<strong>已立案</strong>后嫌疑人逃跑的，不受 6 个月限制 ②被侵害人在时效内控告、应当受理而未受理的，不受限制 ③超过时效不处罚，但查获的<strong>违禁品仍应收缴</strong> |
| 一事不再罚 | 同一违法行为不得给予<strong>两次以上罚款</strong>；但一个罚款加一个拘留可以并存 —— 禁的是同类重复，不是不同种类并用 |
| 责任年龄 | 不满 <strong>14 周岁</strong>不予处罚，责令监护人<strong>严加管教</strong>并在不予处罚决定书中写明；已满 14 不满 18 <strong>应当</strong>从轻或减轻。年龄自<strong>生日次日</strong>起算，差一天都不行 |
| 精神病人 | 完全不能辨认或控制自己行为时违法的不予处罚；<strong>间歇性</strong>的看<strong>违法行为当时</strong>的精神状态；尚未完全丧失辨认控制能力的应当处罚，但<strong>可以</strong>从轻减轻 |
| 盲聋哑与醉酒 | <strong>盲人</strong>或<strong>又聋又哑</strong>的人，<strong>可以</strong>从轻、减轻或不予处罚（只聋或只哑不行）；<strong>生理性醉酒应当处罚</strong>，病理性醉酒按精神病人处理 |
| 应当从轻减轻 | 情节轻微；主动消除或减轻危害后果（新法把「取得被害人谅解」单独拆出）；被胁迫或诱骗（<strong>没有被教唆</strong>）；主动投案；有立功表现 |
| 应当从重 | 有严重后果；教唆、胁迫、诱骗他人；对报案人、控告人、举报人、证人<strong>打击报复</strong>；<strong>一年内</strong>曾受过治安处罚；阻碍民警执行职务；冒充军警招摇撞骗；刑罚执行完毕 3 年内或缓刑期间违法 |
| 一人多行为与一案多人 | 一人有两种以上违法行为：<strong>分别决定、合并执行</strong>（拘 10 天＋拘 5 天＝15 天，写在一份决定书上）；一案多人：分别决定，可<strong>一事多份</strong>，一人一份 |
| 办案期限 | 一般 <strong>30 日</strong>；重大复杂经上一级批准延长 30 日；<strong>最多延长两次</strong>，最长 <strong>90 日</strong>。派出所办的案件要延长，由<strong>分局</strong>批准 |
| 不计入期限 | 治安案件的<strong>鉴定、听证</strong>时间不计入办案期限；刑事案件的鉴定计入，<strong>精神病鉴定除外</strong> |
| 突破 90 日与身份不明 | 嫌疑人身份不明或逃跑等客观原因导致无法处理的，继续调查取证并及时处理，<strong>不受 90 日限制</strong>；身份不明但事实清楚、证据充分的，按其<strong>自报姓名</strong>（附照片）处罚并在文书中注明 |

## 课程口诀

::: tip
**口诀（可以快速办理）：「不简易，还认错，无异议，可快速办理。」**

讲者原话「总结一个口诀」。不简易＝不适用简易程序；还认错＝自愿认错认罚；无异议＝对违法事实与法律适用没有异议（另加事实清楚）。语音识别写作「不解译／无意义」，已按讲解改回。

课程位置：02:30。
:::

::: tip
**口诀（不得快速办理）：「盲聋哑精神病，听证拘留未成年，不可快速办理。」**

讲者原话「那咱们编个口诀吧」。盲聋哑未成年精神病有其一即不可；听证＝可能适用听证程序；拘留＝拘留处罚幅度可能达到 10 日以上。

课程位置：07:00。
:::

::: tip
**口诀（申请法律援助（刑事，本集预告））：「盲聋哑精神病，无期死刑未成年，外加缺席判。」**

讲者顺带编的刑事口诀，与上一条结构相似，放到这里便于对照记忆；正式内容在刑事程序与律师参与部分再讲。

课程位置：08:30。
:::
