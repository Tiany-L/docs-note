# 《治安管理处罚法》新旧对比①

本集重点是**总则、处罚适用，以及具体违法行为的新增和修改**。

## 1. 总则变化

- 明确立法依据为宪法。
- 明确治安管理坚持党的领导、综合治理。
- 强调教育与处罚结合、释法说理。
- 本法没有规定的程序，衔接行政处罚法、行政强制法。

## 2. 制止不法侵害

新增明确规则：

- 为免受正在进行的不法侵害而采取制止行为，造成损害的，不属于治安违法，不受处罚。
- 明显超过必要限度并造成较大损害的，依法处罚，但**应当减轻**；情节较轻的，不予处罚。

判断时不能仅看到“双方都有伤”就认定互殴。

## 3. 从宽处理与处罚适用变化

| 旧规定或旧记忆 | 新法重点 |
|---|---|
| “情节特别轻微” | 调整为“情节轻微” |
| 消除、减轻后果并取得谅解 | 分列为独立情形 |
| 6个月内曾受治安处罚，从重 | 改为1年内 |
| 某些年龄人员一律不执行拘留 | 增加严重恶劣、反复违法等例外 |

新增认错认罚从宽：自愿如实陈述、承认违法事实、愿意接受处罚的，**可以依法从宽处理**，不是自动免罚。

## 4. 具体行为的修订重点

本集后半段需关注：

- 扰乱国家考试秩序的作弊行为；
- 干扰公共交通工具正常驾驶；
- 组织、胁迫未成年人从事有偿陪侍；
- 侵犯个人信息；
- 非法安装、使用、提供窃听窃照专用器材；
- 旅馆、出租房屋及相关行业的信息登记、报告义务。

复习时先识别**行为构成、加重情形和与犯罪的界限**，不要只背提高后的罚款数字。

| 总则新增条文 | 新增「根据宪法」「坚持中国共产党领导」，凡新修订法律都有、正确选项恒定；新增各级政府加强社会治安综合治理；新增预防化解社会矛盾纠纷，<strong>是为分则治安调解铺垫</strong> |
| 刑行民责任独立 | 新增：构成犯罪依法追刑责，<strong>尚不构成刑事处罚的</strong>才由公安机关治安处罚；不得以治安处罚代替刑事处罚；治安、刑事、民事三条线互不影响，赔钱不能顶处罚 |
| 治安调解的适用前提 | 限于民间纠纷引起的<strong>轻微治安案件</strong>；做题第一步先判断是不是治安案件（标志是有违法行为）；黄赌毒、卖淫嫖娼、赌博、吸毒等<strong>无违法嫌疑人</strong>的不能调解；原则合法、公正、自愿、及时（自程序规定移入） |
| 调解后「处罚」改「处理」 | 旧法未达成协议或不履行的「<strong>作出处罚</strong>」→ 新法「<strong>作出处理</strong>」；处理含批评教育、不予处罚、警告、罚款、拘留，<strong>范围更广</strong>；立法考虑是防止被侵害人把调解当索要高额赔偿的工具 |
| 调解主体与介入时点 | 旧法只有民警主持 → 新法<strong>主体多元化</strong>：当事人自行和解、人民调解委员会调解、民警主持；介入时间限于<strong>处理决定作出之前</strong>，拍板结案后不能再和解 |
| 调解协议生效条件 | 须达成协议<strong>并已履行</strong>，再<strong>书面</strong>向公安机关申请，经公安机关<strong>认可</strong>才不予处罚；只申请未获认可的，不能直接不予处罚 |
| 听证金额 | 旧法个人 2000 元、企业 1 万元 → 新法个人听证门槛调为 <strong>4000 元</strong>；新法未规定企业罚款数额，1 万元出自程序规定，<strong>改不改未定</strong> |
| 派出所罚款上限 | 派出所可作出的治安处罚：旧法警告 + <strong>500 元</strong>以下罚款 → 新法警告 + <strong>1000 元</strong>以下罚款 |
| 当场处罚与当场收缴 | 当场处罚（简易程序）罚款上限旧 <strong>200</strong> → 新 <strong>500</strong>；当场收缴罚款旧 <strong>50</strong> → 新 <strong>200</strong> |
| 拘留适用面扩大 | 新法约<strong>三分之二</strong>的违法行为可直接拘留；旧法先罚款挡一道、情节较重才拘留并罚款；立法理由是罚款挡不住，<strong>权力扩张体现在拘留而非罚款额</strong> |
| 精神与智力障碍主体 | 不能辨认或控制自己行为时违法的<strong>不予处罚</strong>，责令监护人看管治疗；<strong>新增智力残疾人</strong>（含老年痴呆）为主体；尚未完全丧失辨认控制能力的应当处罚、可从轻或减轻；间歇性以<strong>行为时</strong>状态判断 |
| 正当防卫下放治安 | 旧法全文无「正当防卫」，治安还手即互殴、双方都拘 → 新法：为免受正在进行的不法侵害而制止、造成损害的不属违反治安管理行为；<strong>明显超过必要限度造成较大损害</strong>的处罚但应减轻，情节较轻不予处罚；必要限度标准待公安部释义 |
| 从轻减轻情形修改 | 新增「<strong>从轻</strong>」（旧法只有减轻、不予处罚）；「情节特别轻微」删「特别」改为情节轻微；「主动消除后果<strong>并</strong>取得谅解」改为「<strong>或</strong>」，一条变两条（参照 2021 年行政处罚法） |
| 认罪认罚从宽 | 自刑诉法下放：自愿如实陈述、承认违法事实、<strong>愿意接受处罚</strong>三者缺一不可；是「<strong>可以</strong>」从宽不是应当；只认罪不认罚不能从宽 |
| 从重处罚的期限 | 旧法<strong>6 个月</strong>内曾受治安处罚 → 新法<strong>1 年</strong>内；旧口径另有「1 年内同类违法被处罚两次以上」（出自程序规定），新法只写 1 年内曾受治安处罚，<strong>按新法这一句记</strong> |
| 拘留不执行的例外 | 旧法 14–16 岁、16–18 岁初次、70 岁以上、怀孕或哺乳不满 1 岁婴儿的妇女<strong>一律不执行</strong> → 新法前三类<strong>情节恶劣</strong>仍执行、<strong>1 年内两次以上</strong>违反治安管理的仍执行；<strong>孕妇、哺乳妇女仍不执行</strong>；不执行的未成年人依预防未成年人犯罪法送专门学校（原工读学校） |
| 考试作弊 | 新增，限<strong>法律规定的国家考试</strong>（国考、考研、法考、四六级等，校内期末考不算）；四类：组织作弊、提供器材或其他帮助、非法出售试题答案、代替他人或让他人代替自己；<strong>只记行为不记处罚幅度</strong> |
| 场馆禁入令 | 新增<strong>文艺演出</strong>（旧法只有体育比赛）；被拘留的可同时责令 <strong>6 个月至 1 年</strong>内不得进入场馆观看<strong>同类</strong>比赛演出（旧 12 个月）；须<strong>与拘留捆绑</strong>；违反进入的，旧法仅强行带离 → 新法可并拘留或罚款 |
| 计算机违法扩大 | 旧法侵入须造成危害后果 → 新法只要侵入、获取存储数据即违法；旧法须致系统不能正常运行 → 新法有行为即违法（行为犯）；新增提供侵入、非法控制程序工具，<strong>打破「技术无罪论」</strong>，易与 AI 结合考 |
| 传销处罚主体 | 新增：只罚组织者、领导者及<strong>胁迫诱骗</strong>他人参加者；<strong>不罚</strong>被诱骗、被胁迫或自愿参加的一般参加人 |
| 英烈与公祭保护 | 新增五类：管控区域<strong>故意</strong>从事违背活动主题行为且<strong>不听劝阻</strong>；纪念设施内损害纪念氛围不听劝阻或侵占破坏设施；侮辱诽谤损害英烈姓名肖像名誉荣誉（<strong>无「不听劝阻」要件</strong>）；亵渎否定英烈事迹、宣扬美化侵略战争；穿戴宣扬侵略战争服饰标志不听劝阻 |
| 妨害安全驾驶 | 新增：抢控驾驶操纵装置、拉扯殴打驾驶人等干扰公共交通工具正常行驶；对应刑事<strong>妨害安全驾驶罪</strong>（旧罪名是以危险方法危害公共安全罪）；刑事含<strong>司机打乘客</strong>，治安只管<strong>乘客打司机</strong> |
| 大型活动禁止令 | 有发生事故危险、责令改正拒不改正或无法改正的，责令停止活动并立即疏散；罚<strong>直接负责的主管人员和其他直接责任人员</strong>，不罚普通员工；可同时责令 <strong>6 个月至 1 年</strong>内不得举办，是「可以」且<strong>没有「同类」限定</strong> |
| 旅馆业三违 | 新增：不登记（含为身份不明、拒绝登记身份信息的人提供住宿）、不制止（带危险物质进入不制止）、不报告（发现犯罪嫌疑人、被通缉人员或他人利用旅馆犯罪不报告）；罚直接负责的主管人员和其他责任人员 |
| 办案期限延长 | 治安案件办案期限旧 <strong>60 日</strong> → 新 <strong>90 日</strong>；与行政处罚法的 90 日对标 |
| 殴打他人与故意伤害 | 治安领域是两种行为：殴打他人＝拳打脚踢（<strong>持械殴打仍属殴打他人</strong>、从重）；故意伤害＝其他方法（放狗咬、开水烫）；刑事轻伤以上即故意伤害罪；殴打伤害残疾人、孕妇、不满 14 周岁、<strong>70 周岁以上老人</strong>（旧 60 周岁）均处 10 日以上、不适用快速办理 |
| 故意损毁财物单列 | 旧法在 49 条与盗窃、诈骗、哄抢、抢夺、敲诈勒索并列，处 5–10 日拘留或 2000 元罚款 → 新法单列，处 <strong>5 日以下</strong>拘留，<strong>处罚变轻</strong>；因 80% 发生在邻里熟人之间 |
| 校园霸凌双向处罚 | 对学生：以殴打侮辱恐吓等方式实施霸凌，治安处罚<strong>加矫治教育</strong>；对学校：明知严重欺凌不报告不处置的责令改正，公安只有<strong>建议</strong>有关部门处分之权（初稿曾拟直接处罚校长，被驳回） |
