# 辨认、办案协作、处罚告知、听证

## 1. 辨认

::: tip
**口诀：人照物七十五，尸体辨认不受限。**
:::

| 辨认对象 | 数量要求 |
|---|---:|
| 人员 | 不少于7人 |
| 人员照片 | 不少于10人的照片 |
| 物品 | 混杂的同类物品不少于5件 |
| 尸体 | 无上述数量限制 |

::: danger
注意：

- 数量**包含被辨认对象本身**。
- 多名辨认人应分别辨认，不能大家一起讨论着认。
- 办案民警可以依法自行组织辨认，无须另行审批。
- 一般由2名以上民警主持；新法规定的规范办案场所内辨认，有1名民警并全程同步录音录像的例外。
:::

## 2. 办案协作

::: tip
**口诀：三证齐全——传唤证＋办案协作函件＋人民警察证。**
:::

协作地帮助将人传唤至其所在市、县内的指定地点，或到其住处、单位询问。

协作地依法履行协作职责所产生的法律责任，由**办案地公安机关**承担。

## 3. 处罚前告知与法制审核

处罚前告知：**拟处罚内容、事实、理由、依据，以及依法享有的权利**。

- 必须听取陈述、申辩，不能因申辩而加重处罚。
- 行为人不满18周岁的，还应告知其父母或其他监护人并听取意见。

::: tip
**口诀：重大疑难经听证，需要法制去把关。**
:::

对应需法制审核的情形：

- 涉及重大公共利益；
- 直接关系当事人或第三人重大权益，且经过听证；
- 案件疑难复杂，涉及多个法律关系。

## 4. 听证

重点范围：

- 吊销许可证件；
- **4000元以上**治安罚款；
- 责令停业整顿；
- 新法特殊情形下，可能执行行政拘留的未成年人案件。

未成年人案件的听证**不公开举行**。

期限按课件记：**5日内申请，收到申请后2日内决定，举行前7日通知**。

听证由法制部门组织，不向当事人收费，也不能因要求听证而加重处罚。

## 课程复习清单

> 来源：2027 公专 P08 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 谁辨认谁 | 被侵害人、证人辨认<strong>违法嫌疑人</strong>；<strong>嫌疑人也可以辨认嫌疑人</strong>（同伙、临时搭伙的）；但<strong>没有让嫌疑人去辨认被害人</strong>这回事 |
| 辨认的主持 | 两名以上办案民警组织；特例是在规范设置、严格管理的执法办案场所，<strong>一名民警可以组织辨认</strong>（「闻辩解压」里的那个「辩」） |
| 辨认不需审批 | 不需要任何领导审批，办案民警自行组织。全课程只有辨认和听证是「无需审批」启动的 |
| 必须个别进行 | 多名辨认人对同一对象、或一名辨认人对多名对象，都应<strong>分别进行</strong>；可以一对多，<strong>不能多对多，也不能多对一</strong>（会互相干扰） |
| 混杂的数量 | 人不少于 <strong>7 人</strong>、照片不少于 <strong>10 张</strong>、物品不少于 <strong>5 个</strong>、<strong>尸体辨认不受数量限制</strong>；这些数字里<strong>包含真嫌疑人本人</strong> |
| 陪衬要类似 | 陪衬对象要与嫌疑人体貌特征相仿，同年龄段、同性别；知道嫌疑人是 40 岁男性，就不能塞女人、小孩、老人进去 |
| 辨认笔录 | 制作辨认笔录，由<strong>办案民警和辨认人</strong>签名或按手印；必要时对辨认过程录音录像 |
| 办案协作函 | 异地办案要制作《办案协作函》，写明前往何地、办什么任务、请求协助什么 |
| 异地传唤 | 三证齐全：<strong>传唤证、办案协作函、人民警察证</strong>；只能传唤到<strong>当地</strong>指定地点、住处或单位询问，<strong>把人带回原地属重大程序违法</strong> |
| 异地拘留 | 与传唤相反：<strong>可以带回原地执行，也可以在异地执行</strong>（须经异地拘留所主管公安机关批准），两种都行 |
| 远程取证只认两项 | 远程视频方式<strong>只有询问和处罚前告知</strong>具备效力；远程辨认、远程勘验检查、远程鉴定一律不行 —— 题干前面铺垫再长也是干扰 |
| 远程询问流程 | ①协作地先核实被询问人身份（防止问错人）②<strong>办案地</strong>民警负责询问并制作笔录、传输给协作地 ③协作地让被询问人逐页签名按手印，协作人员签名盖章 ④原件或电子签名笔录回传。最终<strong>三方签名</strong> |
| 委托取证 | 可委托协作地：代为询问、调取电子数据、接收材料、辨认、处罚前告知、送达文书；<strong>唯独不能代为处罚</strong>；出问题法律责任由<strong>办案地</strong>承担 |
| 处罚前告知 | 作出处罚决定前告知拟处罚的<strong>内容、事实、理由、依据</strong>，并告知陈述申辩权。题干出现「拟」字，对应的文书就是行政处罚告知笔录 |
| 未成年人告知 | 违法行为人<strong>不满 18 周岁</strong>的，还应当告知其父母或其他监护人并<strong>充分听取意见</strong>（新法新增，旧法不通知家属） |
| 告知阶段不能复议诉讼 | 告知程序中对处罚决定不服，<strong>不能申请行政复议、不能提起行政诉讼</strong>—— 还没罚你，无可诉对象；只能陈述申辩，等决定作出后再救济 |
| 法制审核 | 三种情形须经法制部门审核，未经审核或审核未通过<strong>不得作出处罚决定</strong>：涉及当事人或第三人重大利益、经过听证、疑难复杂涉及多个法律关系。<strong>初次</strong>从事法制审核的应通过法律职业资格考试 |
| 听证事项 | 吊销公安机关发放的许可证；违反治安管理<strong>罚款 4000 元以上</strong>；责令停产停业；未成年人可能被行政拘留的，<strong>本人和监护人都有权</strong>申请听证 |
| 听证的金额口径 | 治安 4000；《程序规定》另加<strong>单位 1 万元</strong>、<strong>违反出入境管理 6000 元</strong>；4000 指<strong>单个违法行为</strong>的罚款额，几个违法行为累加够 4000 不算 |
| 听证的组织 | 由<strong>法制部门</strong>组织；<strong>本案调查人员不得担任</strong>主持人、听证员、记录员；当事人可委托 1–2 名代理人；主持人只能提出处理意见和建议，<strong>无权作出处罚决定</strong> |
| 听证的启动与撤回 | 基于当事人申请<strong>自动启动，无需审批</strong>；放弃或撤回后，只要处罚决定未作出、仍在申请有效期内，<strong>又重新提出应当允许</strong> |
| 听证的四个期限 | 违法嫌疑人应在被告知后 <strong>5 日内</strong>提出申请（旧法 3 日，新法改 5 日）；听证机关收到申请 <strong>2 日内</strong>决定并通知；举行听证 <strong>7 日前</strong>送达通知书；公安机关收到申请 <strong>10 日内</strong>举行 |
| 合并与一并 | 两名以上嫌疑人就<strong>同一案件</strong>分别申请听证，可以<strong>合并举行</strong>；部分人申请听证的，应在听证后<strong>一并作出</strong>处理决定，其余人得等着。拘留并处罚款超 4000 的，<strong>对全案主持听证</strong> |
| 未成年人听证 | 为保护未成年人身心健康，涉及未成年人的听证<strong>不公开举行</strong> |

## 课程口诀

::: tip
**口诀（混杂辨认的数量）：「人照物七十五，尸体辨认不受限。」**

讲者原话「总结一下口诀」。人＝辨认对象不少于 7 人、照＝照片不少于 10 张、物＝物品不少于 5 个，尸体辨认不受数量限制。数字里都含真嫌疑人本人。

课程位置：07:00。
:::

::: tip
**口诀（可以申请听证的事项）：「畏惧调挺大，要听证。」**

讲者原话「给大家编个口诀吧」，并说明今年新法修改后由旧版「调挺浪，要听证」更新而来。畏＝未成年人可能被行政拘留（本人与监护人都有权）、调＝吊销公安机关发放的许可证、挺＝责令停产停业、大＝较大数额罚款。

课程位置：48:00。
:::

::: tip
**口诀（听证的四个期限）：「我爱吃屎。」**

讲者原话「所以说这个口诀叫我爱吃屎」，用谐音记 5／2／7／10：我＝5 日内提出申请、爱＝2 日内决定并通知、吃＝7 日前送达通知书、屎＝10 日内举行。

课程位置：59:00。
:::
