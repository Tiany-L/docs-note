# 传唤、行政强制措施

## 一、传唤

### 口头传唤与书面传唤

**口头传唤**：现场发现违法嫌疑人 出示人民警察证，口头传唤 民警在询问笔录中注明到案经过、到案及离开时间

**书面传唤**：需要传唤违法嫌疑人接受调查 传唤证 **被传唤人**在传唤证上填写到案及结束时间并签名；拒签的，由民警注明

::: tip
**口诀：口头传唤不补证。**
:::

::: danger
**注意两点：**

- 口头传唤与书面传唤具有**相同法律效力**。
- “现场发现”不限于违法行为发生现场，也包括在其他地点发现违法嫌疑人。
:::

书面传唤的批准人：**公安派出所、县级以上公安机关办案部门，或者出入境边防检查机关的负责人。**

### 强制传唤

经过合法传唤，违反治安管理嫌疑人**无正当理由拒不接受，或者逃避传唤**，可以强制传唤。

- **县级以上公安机关办案部门负责人批准**。
- 可以依法使用**手铐、警绳**等约束性警械。
- 到案后已服从、配合调查的，不能继续使用警械。
- 紧急情况下现场实施，**返回单位后立即报告，并补办批准手续**。

### 告知程序

- **本人**：传唤的原因、依据。
- **家属**：传唤的原因、处所。
- 无法通知家属的，在询问笔录中注明。

### 异地传唤

**“三证” 办案协作函、人民警察证、相关法律文书。**

## 二、传唤时间【新法重点】

| 情形 | 最长时间 |
| --- | --- |
| 8小时  | 一般情况 |
| 12小时 | 涉案人数众多，或者行为人身份不明 | 
| 24小时 | 情况复杂，依法可能适用行政拘留处罚 |

::: warning
【新法速递】新版《治安管理处罚法》第八十九条 饲养动物，干扰他人正常生活的，处警告；警告
后不改正的，或者放任动物恐吓他人的，处一千元以下罚款。
泩意；
①此种违法行为因达不到拘留程度，所以违法嫌疑人适用传唤/询问查证最长时间为8小时，不得延长至
24小时
②还有一个违法行为 **“制造噪音干扰他人正常生活”** 旧法适用①规则，但是新法修改后最大处罚可拘
留，所以传唤或询问查证时间最长可能会达到24小时。
:::

::: danger
**易错点：**

- 12小时的两种情况，课上强调是**“或”**的关系。
- 24小时需要同时满足**情况复杂＋可能行政拘留**。
- “可能拘留”不等于最终一定作出拘留处罚。
- 在执法办案场所询问违反治安管理行为人，应当**全程同步录音录像**。
:::

## 二、行政强制措施

对物：**情况复杂，且依法可能适用行政拘留处罚扣押、扣留、临时查封、查封、先行登记保存、抽样取证等**
对人：**保护性约束、继续盘问、强制传唤、强制检测、拘留审查、限制活动范围等**

**强制隔离戒毒** 属于行政强制措施

具体要求：

- 原则上实施前，向**公安机关负责人**报告并经批准。
- 告知理由、依据、权利及救济途径。
- 当事人不到场的，邀请见证人到场，并在笔录中注明。
- **听取当事人的陈述与申辩**
- 制作现场笔录笔录由当事人和办案民警签名或盖章；拒签的注明；当事人不到场的，由见证人和民警签名或盖章。

::: danger
**审批人要分清：强制传唤有办案部门负责人等审批的具体规定；行政强制措施的一般规则是公安机关负责人批准。**
:::

### 紧急实施后的报告期限

| 情形 | 报告要求 |
| --- | --- |
| 紧急当场实施行政强制措施 | 实施后24小时内报告，补办手续 |
| **限制公民人身自由的措施** | 返回单位后**立即报告**，补办手续 |

限制人身自由时，还应依法通知家属：**实施机关、理由、地点、期限**。

### 笔录与录像

- 勘验、检查时实施强制措施，已经制作勘验、检查笔录的，**不再重复制作现场笔录**。
- 全程录音录像具备规定的实质内容，可以代替书面现场笔录，但要对关键内容和对应时段作文字说明。

## 课程复习清单

> 来源：2027 公专 P06 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 传唤对象 | 只能针对<strong>违法嫌疑人</strong>；被害人、证人不能传唤，让他们到案叫<strong>通知</strong>，不叫传唤 |
| 书面与口头 | 书面传唤用<strong>传唤证</strong>；口头传唤只针对<strong>现场发现</strong>的违法嫌疑人，现场出示人民警察证即可，回单位不补证 |
| 传唤证审批 | 由派出所负责人、县级以上公安机关<strong>办案部门</strong>负责人（如治安大队长）、出入境边防检查机关负责人批准 |
| 到案与离开时间 | 必须体现到案时间和离开时间：<strong>书面在传唤证上由被传唤人填写</strong>；<strong>口头在询问笔录中由民警注明</strong> |
| 谁签名 | 只有<strong>治安案件的口头传唤由民警签</strong>，其余三种（治安书面、刑事书面、刑事口头）都由嫌疑人签。这条考过北京卷、广东卷 |
| 「现场发现」的范围 | 既包括案发现场，也包括案发现场以外发现嫌疑人的地点；实施违法行为时未被查获、事后工作中发现的，<strong>也可以口头传唤</strong> |
| 强制传唤 | 无正当理由不接受或逃避传唤的，经派出所、办案部门或边检负责人批准可强制传唤；它属于<strong>限制人身自由的行政强制措施</strong> |
| 紧急先实施 | 现场情况紧急可先实施，回单位后<strong>立即</strong>报告并补办批准手续 —— <strong>不是 24 小时内</strong>；补办的是批准手续，<strong>没有「强制传唤证」</strong>这个东西 |
| 强制传唤三条件 | 对象是违反治安管理的嫌疑人；<strong>已经合法传唤在先</strong>（口头或书面）；无正当理由不接受或逃避。跳过传唤直接强制，属程序违法 |
| 告知与通知 | 对本人：告知传唤的<strong>原因和依据</strong>；通知家属：告知<strong>原因和处所</strong>。两者不一样，题干常把「依据」塞进通知家属的选项里 |
| 询问查证时间 | 原则上 <strong>8 小时</strong>；涉案人数众多<strong>或</strong>行为人身份不明的，不超过 <strong>12 小时</strong>（择一即可）；情况复杂、<strong>可能适用行政拘留</strong>的，不超过 <strong>24 小时</strong> |
| 24 小时的拘留前提 | 违法行为本身<strong>够不上拘留，就绝对到不了 24 小时</strong>。如饲养动物干扰他人生活只有警告、1000 元以下罚款，最长 8 小时（至多 12 小时） |
| 两个常考违法行为 | <strong>饲养动物干扰他人生活</strong>：警告、警告不改或放任恐吓罚 1000 元以下，无拘留 → 到不了 24 小时；<strong>制造噪音干扰他人生活</strong>：新法改为先由村委会、物业劝阻，不听可直接拘留 → 可到 24 小时 |
| 异地传唤 | 三证齐全：<strong>办案协作函、人民警察证、传唤证</strong>；到当地后只能在<strong>指定地点、住处或单位</strong>询问，<strong>不得把人押回原地</strong>，否则是重大程序违法 |
| 治安与刑事之别 | 传唤时间：治安 <strong>8／12／24</strong>，刑事 <strong>12／24</strong>；刑事没有「强制传唤」这个词，对应的是<strong>拘传</strong>（刑事强制措施）；<strong>拘传必有证，不能补证也不能补手续</strong> |
| 行政强制措施清单 | 对物：扣押、扣留、临时查封、查封、先行登记保存、抽样取证；对人：保护性约束、继续盘问、强制传唤、拘留审查、限制活动范围 |
| 拘留罚款不是强措 | <strong>行政拘留、罚款都是行政处罚</strong>，不在强制措施之列。强制措施是「先控制住你，再取证，取证完才处罚」 |
| 强措一般程序 | 实施前向公安机关负责人报告并获批准；紧急可先实施、<strong>24 小时内</strong>报告；当事人不到场应<strong>邀请见证人</strong>；必须听取陈述申辩；制作现场笔录并签名，<strong>拒签只注明、不代签</strong> |
| 勘验检查的特例 | 实施强制措施时做了<strong>勘验检查笔录</strong>，就不再另做现场笔录；全程录音录像，且录像中含告知依据与听取申辩的，可代替书面笔录，但要作文字说明 |
| 拘留审查 | 对象是<strong>三非外国人</strong>（非法入境、非法居留、非法就业）加危害国家安全和秩序；期限 <strong>30 日</strong>，案情复杂经上一级公安机关或边检批准<strong>延长至 60 日</strong> |
| 拘留审查的救济 | 放在拘留所但<strong>不是行政处罚</strong>；对外国人只给<strong>复议</strong>，<strong>不给诉讼</strong>。近年国考、省考反复考这个冷门点 |
| 限制活动范围 | 不适用拘留审查的特殊群体改限制活动范围：<strong>老幼病运</strong>，期限同样<strong>不超过 60 日</strong> |

- 67:30：「录音录像具备告知与申辩要素即可代替书面现场笔录」为讲者概括，需核对条文原文的限定条件。
