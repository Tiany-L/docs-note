# 传唤、行政强制措施

## 一、传唤

### 口头传唤与书面传唤

**口头传唤**：现场发现违法嫌疑人 出示人民警察证，口头传唤 民警在询问笔录中注明到案经过、到案及离开时间

**书面传唤**：需要传唤违法嫌疑人接受调查 传唤证 **被传唤人**在传唤证上填写到案及结束时间并签名；拒签的，由民警注明

::: tip
**口诀：口头传唤不补证。**
:::

::: danger
**注意两点：**

- 口头传唤与书面传唤具有**相同法律效力**。
- “现场发现”不限于违法行为发生现场，也包括在其他地点发现违法嫌疑人。
:::

书面传唤的批准人：**公安派出所、县级以上公安机关办案部门，或者出入境边防检查机关的负责人。**

### 强制传唤

经过合法传唤，违反治安管理嫌疑人**无正当理由拒不接受，或者逃避传唤**，可以强制传唤。

- **县级以上公安机关办案部门负责人批准**。
- 可以依法使用**手铐、警绳**等约束性警械。
- 到案后已服从、配合调查的，不能继续使用警械。
- 紧急情况下现场实施，**返回单位后立即报告，并补办批准手续**。

### 告知程序

- **本人**：传唤的原因、依据。
- **家属**：传唤的原因、处所。
- 无法通知家属的，在询问笔录中注明。

### 异地传唤

**“三证” 办案协作函、人民警察证、相关法律文书。**

## 二、传唤时间【新法重点】

| 情形 | 最长时间 |
| --- | --- |
| 8小时  | 一般情况 |
| 12小时 | 涉案人数众多，或者行为人身份不明 | 
| 24小时 | 情况复杂，依法可能适用行政拘留处罚 |

::: warning
【新法速递】新版《治安管理处罚法》第八十九条 饲养动物，干扰他人正常生活的，处警告；警告
后不改正的，或者放任动物恐吓他人的，处一千元以下罚款。
泩意；
①此种违法行为因达不到拘留程度，所以违法嫌疑人适用传唤/询问查证最长时间为8小时，不得延长至
24小时
②还有一个违法行为 **“制造噪音干扰他人正常生活”** 旧法适用①规则，但是新法修改后最大处罚可拘
留，所以传唤或询问查证时间最长可能会达到24小时。
:::

::: danger
**易错点：**

- 12小时的两种情况，课上强调是**“或”**的关系。
- 24小时需要同时满足**情况复杂＋可能行政拘留**。
- “可能拘留”不等于最终一定作出拘留处罚。
- 在执法办案场所询问违反治安管理行为人，应当**全程同步录音录像**。
:::

## 二、行政强制措施

对物：**情况复杂，且依法可能适用行政拘留处罚扣押、扣留、临时查封、查封、先行登记保存、抽样取证等**
对人：**保护性约束、继续盘问、强制传唤、强制检测、拘留审查、限制活动范围等**

**强制隔离戒毒** 属于行政强制措施

具体要求：

- 原则上实施前，向**公安机关负责人**报告并经批准。
- 告知理由、依据、权利及救济途径。
- 当事人不到场的，邀请见证人到场，并在笔录中注明。
- **听取当事人的陈述与申辩**
- 制作现场笔录笔录由当事人和办案民警签名或盖章；拒签的注明；当事人不到场的，由见证人和民警签名或盖章。

::: danger
**审批人要分清：强制传唤有办案部门负责人等审批的具体规定；行政强制措施的一般规则是公安机关负责人批准。**
:::

### 紧急实施后的报告期限

| 情形 | 报告要求 |
| --- | --- |
| 紧急当场实施行政强制措施 | 实施后24小时内报告，补办手续 |
| **限制公民人身自由的措施** | 返回单位后**立即报告**，补办手续 |

限制人身自由时，还应依法通知家属：**实施机关、理由、地点、期限**。

### 笔录与录像

- 勘验、检查时实施强制措施，已经制作勘验、检查笔录的，**不再重复制作现场笔录**。
- 全程录音录像具备规定的实质内容，可以代替书面现场笔录，但要对关键内容和对应时段作文字说明。
