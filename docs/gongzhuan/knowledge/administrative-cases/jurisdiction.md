# 管辖

## 一、地域管辖

- **原则：违法行为地公安机关管辖。**
- 违法行为地包括行为发生地、结果发生地，如实施地、销赃地等。
- 由违法行为人居住地管辖更适宜的，**可以**由居住地公安机关管辖。
- 居住地包括户籍所在地、经常居住地。

::: tip
<p class="mnemonic-lines"><strong class="mnemonic-label">口诀：</strong><strong>行为地为主，居住地为辅；<br>黄赌毒看行为地。黄赌毒行为地管辖且不适用于简易程序（不可快速办理）。</strong></p>
:::

## 二、共同管辖

- 原则：由**最初受理**的公安机关管辖。
- 必要时：可以由**主要违法行为地**公安机关管辖。

::: tip
**口诀：先受理的管，必要时主要违法地管。**
:::

## 三、指定管辖

- 管辖权发生争议，报请**共同的上级公安机关**指定管辖。
- 重大、复杂案件，上级公安机关可以**直接办理或指定管辖**。

::: danger
**易错点：“共同上级”不一定是双方各自的直接上级。**
:::

## 四、特殊场景

| 场景 | 管辖规则 |
| --- | --- |
| 行驶中的客车上发生行政案件 | 原则上由**案发后最初停靠地**管辖；必要时始发地、途经地、到达地也可管 |
| 列车上、火车站工作区域等 | 按规定由**铁路公安机关**管辖 |
| 倒卖、伪造、变造火车票 | 最初受理的**铁路或地方公安机关**管辖；必要时可移送主要违法行为发生地 |
| 网络违法 | 服务器所在地、网络接入地、被侵害时所在地、财产损失地等法定关联地点可以管辖 |

::: tip
**口诀：网络违法沾边就能管原则。**
:::

## 课程复习清单

> 来源：2027 公专 P03 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 管辖总原则 | 以<strong>违法行为地</strong>管辖为主、<strong>居住地</strong>管辖为辅。违法行为地含实施地、结果发生地、销赃地；大白话就是「在哪个地方犯的事，就由哪个地方公安管」 |
| 居住地管辖 | 最典型的代表是<strong>信访案件</strong>，图示题里问「谁管辖最合适」，答案就是居住地公安机关，别去找途经地 |
| 经常居住地 | 居住地 = 户籍地 + 经常居住地。经常居住地指<strong>离开户籍地后最后连续居住一年以上</strong>的地方，不是身份证地址 |
| 黄赌毒 | <strong>只能是违法行为地管辖</strong>，居住地不行、其他地方也不行。黄专指<strong>卖淫嫖娼</strong>，<strong>不包括传播淫秽信息</strong> |
| 当场处罚＝简易程序 | 两个名字说的是同一件事；题干把「当场处罚」换成「简易程序」要能认出来。黄赌毒案件<strong>不适用当场处罚</strong> |
| 吸毒的持续性 | 吸毒是<strong>持续的违法行为</strong>，吸完毒之后经过的每一地都算行为地，全都有管辖权；走路、开车、坐飞机都一样，途经地都管 |
| 两种问法 | 「谁有管辖权」可以有多家；「最终由谁来管」只有一家。看错问法就白做，这是本集最常设的坑 |
| 管辖顺序 | 先看地域管辖（大王），再看共同管辖（小王）。<strong>不是违法行为地的抓获地，第一关就被刷掉</strong>，轮不到「谁先抓到」这条规则 |
| 共同管辖 | 对同一案件都有管辖权时，由<strong>最初受理地</strong>管辖；应试口径是<strong>谁先抓到谁先管</strong>（学理口径为谁先制作立案登记表） |
| 抓获地的价值 | 单纯只是抓获地的<strong>最不值钱</strong>，抓到人也得拱手移交；既是抓获地又是违法行为地，才由它管 |
| 立案在先 | 乙地抓获、但甲地<strong>已立案</strong> → 移交甲地；两地同时立案的情形不存在，网上立案全国联网 |
| 第三方抓获 | 甲乙两地都是行为地但都没立案、由丁地抓获 → <strong>丁地无管辖权</strong>，由丁决定移交给甲或乙；甲乙争执则报共同上级 |
| 上级四种处理 | 指定其中一方管辖、指定双方<strong>共同管辖</strong>、指定第三方管辖、重大复杂案件<strong>上级直接办理</strong> |
| 级别管辖 | 治安案件处罚由<strong>分局</strong>决定；法条里的「县级」就是分局。注意<strong>以上以下含本级</strong>：县级以上含县级、两日以上含两日、24 小时以内含 24 小时 |
| 派出所权限 | 只能作出<strong>警告 + 1000 元以下罚款</strong>，超出这个范围一律归分局 |
| 专门管辖 | <strong>铁</strong>（铁路）、<strong>交</strong>（航运、港航公安）、<strong>民</strong>（民航空警）、<strong>林</strong>（森林）、<strong>海</strong>（海关缉私） |
| 客车案件 | 以<strong>案发后客车最初停靠地</strong>管辖为主；必要时始发地、途经地、到达地也可以管。问「谁有管辖权」则 ABCDE 全都有，问「由谁管」只答最初停靠地 |
| 火车案件 | 铁路公安<strong>专属管辖</strong>；唯一例外是<strong>倒卖、变造、伪造火车票</strong>案件，铁路和地方都能管。判断只看一件事：是不是票的事，霸座不是票的事 |
| 网络与境外赌博 | 网络违法<strong>沾边就能管</strong>（服务器所在地、网络接入地、被害人所在地、网络运营者所在地）；境外赌博由<strong>违法行为人所在地</strong>管，中国公民赴境外赌博、<strong>输赢结算地在国内</strong>的由结算地管 |

## 课程口诀

::: tip
**口诀（黄赌毒管辖）：「黄赌毒行为地管辖，且不适用于当场处罚。」**

讲者原话「来记一个口诀叫什么呢」，并强调「打一百个重点符号都不为过」。当场处罚也可换成「简易程序」，两种说法同一条口诀。

课程位置：08:00。
:::
