# 管辖

## 一、地域管辖

- **原则：违法行为地公安机关管辖。**
- 违法行为地包括行为发生地、结果发生地，如实施地、销赃地等。
- 由违法行为人居住地管辖更适宜的，**可以**由居住地公安机关管辖。
- 居住地包括户籍所在地、经常居住地。

::: tip
<p class="mnemonic-lines"><strong class="mnemonic-label">口诀：</strong><strong>行为地为主，居住地为辅；<br>黄赌毒看行为地。黄赌毒行为地管辖且不适用于简易程序（不可快速办理）。</strong></p>
:::

## 二、共同管辖

- 原则：由**最初受理**的公安机关管辖。
- 必要时：可以由**主要违法行为地**公安机关管辖。

::: tip
**口诀：先受理的管，必要时主要违法地管。**
:::

## 三、指定管辖

- 管辖权发生争议，报请**共同的上级公安机关**指定管辖。
- 重大、复杂案件，上级公安机关可以**直接办理或指定管辖**。

::: danger
**易错点：“共同上级”不一定是双方各自的直接上级。**
:::

## 四、特殊场景

| 场景 | 管辖规则 |
| --- | --- |
| 行驶中的客车上发生行政案件 | 原则上由**案发后最初停靠地**管辖；必要时始发地、途经地、到达地也可管 |
| 列车上、火车站工作区域等 | 按规定由**铁路公安机关**管辖 |
| 倒卖、伪造、变造火车票 | 最初受理的**铁路或地方公安机关**管辖；必要时可移送主要违法行为发生地 |
| 网络违法 | 服务器所在地、网络接入地、被侵害时所在地、财产损失地等法定关联地点可以管辖 |

::: tip
**口诀：网络违法沾边就能管原则。**
:::
