# 证据、继续盘问、约束

### ① 调查取证

::: tip
**口诀：2警检验人文墙。**
:::

对应：**检查、勘验、辨认、询问、行政强制措施**。

一般要求：**民警不得少于2人，并表明执法身份。**


### ② 调查辅助工作

::: tip
**口诀：2姐等信送调解。**
:::

| 口诀 | 对应工作 |
| --- | --- |
| 2姐＝两个“接” | 接报案、接受证据 |
| 等 | 受案登记 |
| 信 | 信息采集 |
| 送 | 送达文书 |
| 调解 | 调解 |

这些工作可由**1名民警带领警务辅助人员**开展，但要**全程录音录像**。

::: danger
**注意：不是让辅警独立办案。**
:::

### ③ 一个民警可干

::: tip
**口诀：“闻便解压” 一警可干。**
:::

对应：**询问、扣押、辨认，调解**。

::: danger
**注意：还要结合本课讲的新法例外。**

- 在**规范设置、严格管理的执法办案场所**进行询问、扣押、辨认，或者进行调解，可以由**1名民警**进行。
- 必须**全程同步录音录像**。
- 未按规定录制，或录音录像损毁、丢失，相关证据不能作为处罚依据。
:::


## 二、证据部分

### 1. 基本要求

证据必须**查证属实**，才能作为定案依据。

证人具有**不可替代性**。判断能否作证，重点看能否辨别是非、正确表达，不能仅凭年龄小或存在身体缺陷就否定。

### 2. 取证文书

| 情况 | 行政案件对应文书 |
| --- | --- |
| 公安主动调取 | 《调取证据通知书》＋《调取证据清单》 |
| 当事人主动提交 | 《接受证据清单》 |
| 扣押、证据保全 | 《证据保全决定书》＋《证据保全清单》 |

### 3. 调取证据

- 一般向**单位或个人**调取，经**办案部门负责人批准**。
- 紧急调取的特殊方式：本课强调**行政案件、向单位调取**；可先电话告知身份，再通过传真、互联网通信工具等发送相关文书和警察证复印件。
- 物证、书证原则上收集**原物、原件**；使用照片、复制件等，要附相关说明。
- 电子数据能扣押原始存储介质的，应当扣押；不能扣押的，再依法提取、固定。

## 三、继续盘问【重点】

### 1. 适用前提

**先当场盘问、检查，仍不能排除违法犯罪嫌疑，且符合法定条件，才能带回继续盘问。**

本课列出的四种情形：

- 被指控有犯罪行为；
- 有现场作案嫌疑；
- 有作案嫌疑且身份不明；
- 携带物品可能是赃物。

### 2. 时间和批准人

| 时限 | 条件 | 批准人 |
| --- | --- | --- |
| 一般12小时 | 符合继续盘问条件 | 派出所负责人 |
| 延长至24小时 | 12小时内仍难以证实或排除嫌疑 | 县记以上公安机关的值班负责人 |
| 延长至48小时 | 不讲真实姓名、住址、身份，且24小时内仍不能证实或排除嫌疑 | 上述公安机关的主管负责人 |

::: danger
**易错点：**

- 从**带至公安机关之时**起算。
- 24、48小时是延长后的**总时限**。
- **不能从12小时直接延长到48小时。**
:::

### 3. 以下人员必须4小时内盘问完毕

- **怀孕的妇女**；
- **正在哺乳自己不满1周岁婴儿的妇女**；
- **不满16周岁**的未成年人；
- **已满70周岁**的老人。

这些人员**不得送入候问室**。

### 4. 八种不得继续盘问情形

1. 未经当场盘问、检查。
2. 已排除违法犯罪嫌疑。
3. 所涉行为的法定最高处罚只是警告、罚款等不限制人身自由的行政处罚。
4. 已投案自首。
5. 已知案件已作为治安案件受理，或已刑事立案。
6. 不属于公安机关管辖。
7. 患精神病、急性传染病或其他严重疾病。
8. 从住处、工作地点抓获，或依法应直接适用传唤、拘传。

::: tip
**口诀： 未盘查排嫌疑 最高罚金币 自首立案不管病 抓传到位不盘问。**
:::


::: danger
**实施完继续盘问一小时内，报本级警务督察部门备案**
:::

## 四、约束

对象包括：符合条件的**精神病人、醉酒人员、恐怖活动嫌疑人**。

- 对行为失控的醉酒人，可使用**约束带、警绳**等；保护性约束时不得使用**手铐、脚镣**。
- **酒醒立即解除约束，再进行询问。**
- **约束时间不计入询问查证时间。**

::: danger
**注意：不是“醉酒的人一律不能上手铐”：如果发生袭警、行凶等危险行为，符合条件时，可依法使用警械制止；危险行为受控后，再按保护性约束规则处理。**
:::
