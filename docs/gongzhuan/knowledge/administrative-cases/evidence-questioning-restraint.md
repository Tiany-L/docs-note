# 证据、继续盘问、约束

### ① 调查取证

::: tip
**口诀：2警检验人文墙。**
:::

对应：**检查、勘验、辨认、询问、行政强制措施**。

一般要求：**民警不得少于2人，并表明执法身份。**


### ② 调查辅助工作

::: tip
**口诀：2姐等信送调解。**
:::

| 口诀 | 对应工作 |
| --- | --- |
| 2姐＝两个“接” | 接报案、接受证据 |
| 等 | 受案登记 |
| 信 | 信息采集 |
| 送 | 送达文书 |
| 调解 | 调解 |

这些工作可由**1名民警带领警务辅助人员**开展，但要**全程录音录像**。

::: danger
**注意：不是让辅警独立办案。**
:::

### ③ 一个民警可干

::: tip
**口诀：“闻便解压” 一警可干。**
:::

对应：**询问、扣押、辨认，调解**。

::: danger
**注意：还要结合本课讲的新法例外。**

- 在**规范设置、严格管理的执法办案场所**进行询问、扣押、辨认，或者进行调解，可以由**1名民警**进行。
- 必须**全程同步录音录像**。
- 未按规定录制，或录音录像损毁、丢失，相关证据不能作为处罚依据。
:::


## 二、证据部分

### 1. 基本要求

证据必须**查证属实**，才能作为定案依据。

证人具有**不可替代性**。判断能否作证，重点看能否辨别是非、正确表达，不能仅凭年龄小或存在身体缺陷就否定。

### 2. 取证文书

| 情况 | 行政案件对应文书 |
| --- | --- |
| 公安主动调取 | 《调取证据通知书》＋《调取证据清单》 |
| 当事人主动提交 | 《接受证据清单》 |
| 扣押、证据保全 | 《证据保全决定书》＋《证据保全清单》 |

### 3. 调取证据

- 一般向**单位或个人**调取，经**办案部门负责人批准**。
- 紧急调取的特殊方式：本课强调**行政案件、向单位调取**；可先电话告知身份，再通过传真、互联网通信工具等发送相关文书和警察证复印件。
- 物证、书证原则上收集**原物、原件**；使用照片、复制件等，要附相关说明。
- 电子数据能扣押原始存储介质的，应当扣押；不能扣押的，再依法提取、固定。

## 三、继续盘问【重点】

### 1. 适用前提

**先当场盘问、检查，仍不能排除违法犯罪嫌疑，且符合法定条件，才能带回继续盘问。**

本课列出的四种情形：

- 被指控有犯罪行为；
- 有现场作案嫌疑；
- 有作案嫌疑且身份不明；
- 携带物品可能是赃物。

### 2. 时间和批准人

| 时限 | 条件 | 批准人 |
| --- | --- | --- |
| 一般12小时 | 符合继续盘问条件 | 派出所负责人 |
| 延长至24小时 | 12小时内仍难以证实或排除嫌疑 | 县记以上公安机关的值班负责人 |
| 延长至48小时 | 不讲真实姓名、住址、身份，且24小时内仍不能证实或排除嫌疑 | 上述公安机关的主管负责人 |

::: danger
**易错点：**

- 从**带至公安机关之时**起算。
- 24、48小时是延长后的**总时限**。
- **不能从12小时直接延长到48小时。**
:::

### 3. 以下人员必须4小时内盘问完毕

- **怀孕的妇女**；
- **正在哺乳自己不满1周岁婴儿的妇女**；
- **不满16周岁**的未成年人；
- **已满70周岁**的老人。

这些人员**不得送入候问室**。

### 4. 八种不得继续盘问情形

1. 未经当场盘问、检查。
2. 已排除违法犯罪嫌疑。
3. 所涉行为的法定最高处罚只是警告、罚款等不限制人身自由的行政处罚。
4. 已投案自首。
5. 已知案件已作为治安案件受理，或已刑事立案。
6. 不属于公安机关管辖。
7. 患精神病、急性传染病或其他严重疾病。
8. 从住处、工作地点抓获，或依法应直接适用传唤、拘传。

::: tip
**口诀： 未盘查排嫌疑 最高罚金币 自首立案不管病 抓传到位不盘问。**
:::


::: danger
**实施完继续盘问一小时内，报本级警务督察部门备案**
:::

## 四、约束

对象包括：符合条件的**精神病人、醉酒人员、恐怖活动嫌疑人**。

- 对行为失控的醉酒人，可使用**约束带、警绳**等；保护性约束时不得使用**手铐、脚镣**。
- **酒醒立即解除约束，再进行询问。**
- **约束时间不计入询问查证时间。**

::: danger
**注意：不是“醉酒的人一律不能上手铐”：如果发生袭警、行凶等危险行为，符合条件时，可依法使用警械制止；危险行为受控后，再按保护性约束规则处理。**
:::

## 课程复习清单

> 来源：2027 公专 P05 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 必须两名民警 | 询问、辨认、<strong>勘验</strong>、检查、行政强制措施，六项工作<strong>不得少于两名人民警察</strong>；这是旧程序规定里最常考的一条 |
| 一警带辅警可干 | 接报案、接受证据、立案（受案）登记、信息采集、调解、送达文书，可由<strong>一名民警带辅警</strong>完成，辅警人数不限，但<strong>应当全程录音录像</strong> |
| 新法一警可干 | 2026 年新《治安管理处罚法》加了一条：在<strong>规范设置、严格管理的执法办案场所</strong>内，询问、扣押、辨认、调解可由一名民警进行。前提是场所，题干没给场所就用不了这条 |
| 录音录像门槛 | 一警办的上述事项，若未全程录音录像，或音像资料损毁、丢失，所取得的询问笔录、扣押、辨认、调解材料<strong>不能作为处罚的根据</strong> |
| 治安三种取证文书 | 主动调取：《调取证据通知书》＋《调取证据清单》；当事人主动交：《接收证据清单》；现场扣押：《证据保全决定书》＋《证据保全清单》 |
| 扣押与收缴追缴 | <strong>扣押是收缴、追缴的前置程序</strong>：现场把物证带回公安局是扣押，作出处罚决定时才谈收缴追缴；第三人合法财物<strong>登记后立即返还</strong> |
| 保存地点不载明 | 原则上证据保全决定书与清单上<strong>不写</strong>保存地点，默认放在物品管理处；只有不能存放于物品管理处的特殊物证才特别注明（依《行政处罚法》第 56 条） |
| 场所地址指什么 | 清单上的「场所地址」不是物品存放地，而是<strong>整个场所本身就是证据</strong>时（如查封卖淫宾馆）填的地址 |
| 刑事取证文书 | 调取：《调取证据通知书》＋清单；接收：《接收证据材料清单》；强制：《查封／扣押决定书》＋清单。<strong>扣押针对动产、查封针对不动产</strong> |
| 原件优先 | 能原件就原件，不能原件用复印件，不能复印就拍照录像；<strong>只要不是原件，一律附文字说明</strong>。电子数据先扣原始介质，不能扣则提取并制作笔录附清单 |
| 紧急调证 | <strong>仅限治安案件、仅限向单位</strong>调取，向个人不行；刑事案件没有紧急调证。刑事异地调取要<strong>办案协作函＋调取证据通知书＋警察证复印件</strong> |
| 证人不可替代 | 证人具有不可替代性：民警、辅警<strong>可以当证人</strong>，但一旦成为证人，就不能再当本案办案人员，其他角色都得给证人让路 |
| 见证人 | 见证人是防止民警执法时搞破坏的第三方，<strong>与公安有一点关系都不行</strong>：民警、辅警、门卫、食堂师傅都不能当见证人 |
| 谁不能作证 | 生理上、精神上有缺陷或年幼，<strong>不能辨别是非、不能正确表达</strong>的人不能作证；<strong>盲人可以</strong>（能听）、<strong>聋哑人可以</strong>（能看能写） |
| 继续盘问的定位 | 经当场盘问、检查后<strong>不能排除违法嫌疑</strong>的，可带回公安机关，经<strong>派出所负责人批准</strong>继续盘问；从现场带回这一步<strong>不需要审批</strong> |
| 传唤与盘问之别 | <strong>传唤＝已百分百确定违法；继续盘问＝可能违法、有嫌疑</strong>。现场能确定违法就直接传唤，确定不了才带回去盘问 |
| 巡逻民警不能离场 | 巡逻中发现可疑人，<strong>不得擅自离开巡逻现场</strong>把人押回所里，应向<strong>情报指挥中心</strong>报告，由指挥中心调度派出所来人 |
| 12/24/48 | 原则上 <strong>12 小时</strong>，难以确定可延至 <strong>24 小时</strong>，仍不能确定且身份不明可延至 <strong>48 小时</strong>；<strong>必须一级一级升</strong>，不能从 12 直接跳 48。起算点是<strong>带至公安机关之时</strong> |
| 三级审批 | 12 小时由<strong>派出所负责人</strong>批；24 小时由<strong>分局值班负责人</strong>批；48 小时由<strong>分局主管负责人</strong>批 |
| 立法冲突 | 《人民警察法》写 24／48，《办理行政案件程序规定》与《继续盘问规定》写 12／24／48；<strong>按命题口径用 12／24／48</strong> |
| 适用四情形 | 被指控有犯罪行为；有现场作案嫌疑；有作案嫌疑且<strong>身份不明</strong>；<strong>携带物品可能是赃物</strong> |
| 不得适用八情形 | 未经当场盘问检查；已排除嫌疑；最高只能警告、罚款；已自首；已作治安案件受理或已刑事立案；不属公安管辖；患精神病、急性传染病等严重疾病；从住处工作地点抓获或直接传唤、拘传 |
| 双备案 | 审批表复印件传报县市公安局或分局主管派出所的部门备案；实施完毕后<strong>一小时内报本级督察部门</strong>备案（出自《公安机关执法细则》） |
| 约束的对象与方法 | 对象是武疯子（有暴力危害的精神病人）、<strong>醉酒</strong>的人、恐怖活动嫌疑人；方法用<strong>警绳、约束带</strong>，<strong>不得使用手铐、脚镣</strong>；但袭击警察、逃脱、行凶、自杀自残时，可依法使用警械武器 |
| 约束时间 | 约束至酒醒，<strong>不计入询问查证时间</strong>；地点一般在公安机关内，可通知家属亲友领回，必要时送医院醒酒 |
| 家属照顾属依法行为 | 被盘问人家属属老弱病残幼、无独立生活能力而无人照顾的，公安机关应通知亲友照顾或妥善安排——这是<strong>依法行为</strong>，不是帮助行为 |

## 课程口诀

::: tip
**口诀（两名民警干的事）：「二警检验人文强。」**

讲者原话「同哥给大家编个口诀吧」。二警＝不少于两名民警；检＝检查、验＝勘验、人＝辨认、文＝询问、强＝行政强制措施。

课程位置：04:00。
:::

::: tip
**口诀（一警带辅警干的事）：「二姐等信送调解。」**

两个「接／接」：接报案、接受证据；等＝立案（受案）登记、信＝信息采集、送＝送达文书、调解＝调解。讲者连说三遍，是三条口诀里最容易被想不起来的一条。

课程位置：05:30。
:::

::: tip
**口诀（新法一警可干）：「闻辩解压，一警可干。」**

讲者现场用「养狗闻一闻」的段子编的：闻＝询问、辩＝辨认、解＝调解、压＝扣押。语音识别写作「闻辩解压／意境可干」，已按讲解改回。前提是执法办案场所，没有场所这个前提就用不了。

课程位置：08:30。
:::

::: tip
**口诀（四小时特例）：「老人儿童和孕妇，不禁后问四小时。」**

「后问」指候问室：怀孕或哺乳自己不满一周岁婴儿的妇女、不满十六周岁的人、满七十周岁的人，不得送入候问室，四小时内问完。

课程位置：64:00。
:::

::: tip
**口诀（不得继续盘问的八种情形）：「未盘查，排嫌疑，最高罚金币，自首立案不管病，抓传到位不盘问。」**

讲者原话「编口诀吧」。未盘查＝未经当场盘问检查；排嫌疑＝已排除违法嫌疑；最高罚金币＝最高只能警告、罚款；自首；立案＝已作治安案件受理或已刑事立案；不管＝不属公安管辖；病＝精神病、急性传染病等严重疾病；抓传到位＝从住处工作地点抓获或直接传唤、拘传。

课程位置：67:30。
:::
