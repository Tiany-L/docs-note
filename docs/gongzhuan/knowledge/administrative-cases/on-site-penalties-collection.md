# 当场处罚、当场收缴

## 1. 当场处罚＝简易程序

治安案件事实清楚、证据确凿，处：

**警告，或者500元以下罚款**，可以当场处罚。

- 黄、赌、毒案件不适用当场处罚。
- 新法规定：本人对拟处罚内容及事实、理由、依据无异议，可以由**1名民警**作出决定，并全程同步录音录像。
- 当场交付处罚决定书，经办民警在**24小时内备案**。

程序不能省略：

**表明身份 → 收集证据 → 告知 → 听取陈述申辩 → 作出并交付决定。**

## 2. 当场收缴罚款

::: danger
**能当场处罚，不等于一定能当场收钱。**
:::

一般应在收到处罚决定书后**15日内**，到指定银行或通过电子支付系统缴纳。

可以当场收缴的三类情形：

1. **200元以下，且本人对罚款无异议。**
2. 在边远、水上、交通不便地区、旅客列车或口岸，缴纳确有困难，且**由本人提出**。
3. 当地没有固定住所，不当场收缴事后难以执行。

后两项不能机械套用200元限制。

## 3. 收钱后的手续

- 必须出具省级以上财政部门统一制发的专用票据；不出具，本人有权拒缴。
- 民警收款后**2日内交所属公安机关**。
- 公安机关收到后**2日内缴付指定银行**。
- 水上、列车上收取的，按抵岸或到站后的法定期限办理。

## 课程复习清单

> 来源：2027 公专 P09 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 当场处罚＝简易程序 | 同一件事的两个名字。<strong>一名以上人民警察</strong>即可作出；这个人数改过三次：一人 → 两人（2021—2025）→ 2026 新法改回<strong>一人</strong> |
| 适用金额 | 对个人：警告或 <strong>500 元以下</strong>罚款；对法人或其他组织：警告或 <strong>3000 元以下</strong>罚款（后者源自行政处罚法） |
| 边检的当场处罚权 | 出入境边防检查机关对违反出入境管理的行为人，500 元以下罚款或警告可当场处罚；<strong>分局出入境管理大队没有这个权力</strong> |
| 现场对应扣押（原则） | 题干出现「当场」「现场处置」「现场处理」，原则上对应<strong>扣押</strong>，文书是《证据保全决定书》 |
| 唯一例外：当场收缴 | 以<strong>当场处罚为前提</strong>＋<strong>有违禁品为条件</strong>，才导得出当场收缴。例：当场罚 200 元，身上有管制刀具 → 刀具当场收缴，不走扣押 |
| 当场处罚的流程 | 表明身份 → 收集证据 → <strong>口头告知</strong>（事实、理由、依据、陈述申辩权、拟处罚内容）→ 听取陈述申辩 → 当场填写并交付处罚决定书 → 当场收钱的填罚款收据 → 备案 |
| 告知可以口头 | 处罚前告知原则书面，<strong>只有当场处罚和快速办理可以口头</strong>；口头告知也<strong>不必提听证</strong>，因为 500 元的处罚永远够不上 4000 元的门槛 |
| 备案时限 | 作出决定后 <strong>24 小时内</strong>报所属公安机关备案；<strong>交警两日内</strong>备案（贴单量太大）；旅客列车、民航、水上作出的，返回机关后 24 小时内报 |
| 复议前置 | 当场处罚不服，<strong>只能先向同级人民政府申请复议</strong>，对复议结果不服再诉讼。旧文书还写「或向法院起诉」，<strong>新文书已删</strong>，这是文书挑错的好出题点 |
| 文书公开 | 生效的处罚决定、复议结果要逐步向社会公开，姓名与身份证号隐去；<strong>简易程序的处罚决定可以不公开</strong>（量太大、事太小） |
| 缴纳与滞纳金 | 收到决定书 <strong>15 日内</strong>到指定银行或电子支付系统缴纳；逾期每日加处 <strong>3%</strong> 滞纳金，<strong>加处总额不超过本金</strong> |
| 当场收缴三情形 | ①罚款 <strong>200 元以下</strong>且无异议（旧法为 50 元，新法调至 200）②边远、水上、交通不便地区或旅客列车、口岸，缴款确有困难并<strong>主动提出</strong>（无金额限制）③在当地<strong>没有固定住所</strong>、事后难以执行（无金额限制） |
| 票据 | 必须出具<strong>省级以上人民政府财政部门统一制发的专用票据</strong>；不给票据、私设罚款项目的，依纪律条令<strong>予以开除</strong> |
| 两日原则 | 当场收缴的罚款 <strong>2 日内</strong>交所属公安机关，公安机关 <strong>2 日内</strong>交指定银行；列车上收的，返回后交。别和备案的 24 小时混 |
| 当场处罚 vs 当场收缴 | 区别不在「当场」，而在<strong>钱拿不拿走</strong>：当场处罚只当场作决定、钱 15 日内进银行；当场收缴当场收钱。两者<strong>不是互斥</strong>：罚 100 元正好落在 200 元以内，可以当场收钱并开收据 |
| 三种「收缴」别混 | ①当场收缴违禁品（须以当场处罚为前提）②当场收缴罚款（三情形）③普通程序中的收缴（先扣押带回，再决定收缴还是追缴） |
| 黄赌毒没有当场收缴 | 黄赌毒不适用当场处罚，<strong>前提不成立就导不出当场收缴</strong>；但冰壶、赌资这些物<strong>可以先扣押</strong>，回去再走普通收缴程序 |
| 做题提示 | 看到「黄赌毒」先想「不适用当场处罚」；再看题干问的是<strong>情形</strong>还是<strong>主体</strong> —— 情形对、主体错，问情形就仍算适用，别答非所问 |

## 课程口诀

::: tip
**口诀（黄赌毒不适用当场处罚（复述第 3 集））：「黄赌毒行为地管辖，且不适用于当场处罚。」**

本集开头讲者回扣第 3 集的口诀，用来界定当场处罚的排除范围。当场处罚＝简易程序，题干换成「简易程序」也要认出来。

课程位置：01:00。
:::

::: tip
**口诀（听证事项（复述第 8 集））：「畏惧调挺大，要听证。」**

讲者回顾第 8 集的口诀，用于解释为什么当场处罚的口头告知不必提听证：500 元的罚款够不上「大」的门槛（个人 4000）。

课程位置：13:30。
:::
