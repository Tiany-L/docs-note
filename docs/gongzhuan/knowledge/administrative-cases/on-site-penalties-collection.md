# 当场处罚、当场收缴

## 1. 当场处罚＝简易程序

治安案件事实清楚、证据确凿，处：

**警告，或者500元以下罚款**，可以当场处罚。

- 黄、赌、毒案件不适用当场处罚。
- 新法规定：本人对拟处罚内容及事实、理由、依据无异议，可以由**1名民警**作出决定，并全程同步录音录像。
- 当场交付处罚决定书，经办民警在**24小时内备案**。

程序不能省略：

**表明身份 → 收集证据 → 告知 → 听取陈述申辩 → 作出并交付决定。**

## 2. 当场收缴罚款

::: danger
**能当场处罚，不等于一定能当场收钱。**
:::

一般应在收到处罚决定书后**15日内**，到指定银行或通过电子支付系统缴纳。

可以当场收缴的三类情形：

1. **200元以下，且本人对罚款无异议。**
2. 在边远、水上、交通不便地区、旅客列车或口岸，缴纳确有困难，且**由本人提出**。
3. 当地没有固定住所，不当场收缴事后难以执行。

后两项不能机械套用200元限制。

## 3. 收钱后的手续

- 必须出具省级以上财政部门统一制发的专用票据；不出具，本人有权拒缴。
- 民警收款后**2日内交所属公安机关**。
- 公安机关收到后**2日内缴付指定银行**。
- 水上、列车上收取的，按抵岸或到站后的法定期限办理。
