# 立案

## 一、案件分类

- **行政案件包含治安案件**，还包括交通管理、出入境管理等。
- 构成犯罪的，按刑事案件处理；符合治安违法规定、尚不够刑事处罚的，按治安案件处理。
- 暂时无法确定案件性质的，可以先按行政程序办理；发现涉嫌犯罪，再转刑事程序。

## 二、接报案的三种处理

| 情况 | 处理 |
| --- | --- |
| 本单位管辖 | 依法立案、调查处理 |
| 公安机关管，但本单位不管 | **24小时内移送**有管辖权的单位，并告知 |
| 不属于公安机关职责 | 告知向其他主管机关报案，按规定口头或书面告知 |

**不得推诿、拒接，不得要求群众自行寻找有管辖权的公安单位。**

## 三、“三个当场”

1. 当场进行网上接报案登记。
2. 当场接受证据材料。
3. 当场出具回执，并告知查询进展、投诉监督的方式。

::: tip
**口诀：登记、接证、给回执。**
:::

## 四、审查期限

| 类型 | 课件中的期限 |
| --- | --- |
| 行政案件一般情况 | 原则上不超过 **24小时** |
| 行政案件疑难复杂情况 | 不超过 **3日** |
| 刑事案件一般情况 | 原则上不超过 **3日** |
| 刑事线索需要查证 | 不超过 **7日** |
| 刑事案件重大疑难复杂情况 | 经批准可延长至 **30日** |

::: danger
**注意：以上是审查期限，不是办案期限。新《治安管理处罚法》要求有关治安案件立即立案调查，不能理解为可以一律等待24小时。**
:::

## 五、案件转换

- **行政转刑事：原行政案件结案。**
- **刑事转治安：原刑事案件撤案。**
- 证据转换要区分方向和种类，不能一律照搬。
- 重点记忆：依法收集的**物证、书证、视听资料、电子数据等**，可按规定衔接使用；行政转刑事时，言词证据一般需要依法重新收集。

::: tip
**口诀：刑事转治安证据都可转，原刑事撤案；治安转刑事证据部分转，原治安结案。**
:::

## 六、易错点

- **接报案登记 ≠ 立案 ≠ 办结。**
- 接报案回执不等于立案回执。
- “24小时移送”与“24小时审查”是两项不同规则。
- 不能因损失小、后果轻就拒绝接报案。
- 重复报案且案件正在办理或已办结的，应解释，不再重复登记。

| 考点 | 记忆点 |
| --- | --- |
| 三部法律 | 《治安管理处罚法》<strong>2026-01-01 新法</strong>已实施；《公安机关办理行政案件程序规定》<strong>尚未出台新法</strong>，一律按现行版；《行政处罚法》打辅助 |
| 行政与治安 | 圈的大小：治安案件只是行政案件的一支（另有交通管理、出入境）；题干说「公安机关办理的行政案件」，可直接按治安案件处理 |
| 先判性质 | 同一名词两套规则。传唤：治安 <strong>8 / 12 / 24 小时</strong>，刑事 <strong>12 / 24 小时</strong>；性质判错，后面全用错规则 |
| 六种判断法 | 字眼 → 三观 → 伤情 → 场所 → 唯一 → 数额；前四步能秒杀，第五靠背，第六靠积累 |
| 伤情 | <strong>轻微伤 = 治安；轻伤、重伤 = 刑事</strong>。纯殴打类只看伤情，别用「三观」感觉代替；题干会把鉴定结论直接给你 |
| 数额与情形 | 普通盗窃数额小 = 治安，数额大 = 刑事；<strong>入户盗窃一分钱也是刑事</strong>；数额标准各省自定（辽宁 2000 元） |
| 危险自招 | 明知危险仍自愿介入的，可能<strong>不构成任何案件</strong>；有人死 ≠ 有人要担责，别从结果反推 |
| 派出所 | 在治安案件里算「公安机关」，但只有 <strong>警告 + 1000 元以下罚款</strong>；拘留、2000 元罚款、<strong>刑事立案</strong>都归分局 → 分辨看盖章 |
| 强制隔离戒毒 | 既是<strong>最终处理决定</strong>，也是<strong>行政强制措施</strong>，两者不互斥；命题只认后者 |
| 报案三种处理 | 属本单位管辖 → 调查处理；属公安职责、不属本单位 → <strong>24 小时内移送</strong>；不属公安职责 → <strong>口头或书面</strong>告知 |
| 两份文书 | <strong>立案登记表附卷、不给当事人</strong>；<strong>立案回执一式两份、交当事人</strong>。例外：当场处罚（如贴违停单）不立案、不出回执 |
| 移送 | 《移送案件通知书》<strong>一式三份</strong>；移送后<strong>询问查证与扣押期限重新计算</strong>；不得让报案人自己跑去另一家 |
| 不予调查 | 离婚、欠债、消费纠纷去法院；能当场判断的<strong>口头</strong>告知，有异议或判断不了的<strong>书面</strong>告知；不出立案登记表 |
| 立案审查期限 | 行政：接到报案起 <strong>24 小时</strong>，疑难复杂 <strong>3 日</strong>；刑事：<strong>受案</strong>起 <strong>3 / 7 / 30 日</strong> |
| 网上接报案 | 所有报案都要登记（这是<strong>接报案</strong>，不是立案）；两种不登：涉<strong>国家秘密</strong>、<strong>重复报案</strong>／在办／已办结 |
| 案件转化 | 行政转刑事 → 原案<strong>结案</strong>；刑事转行政 → 原案<strong>撤案</strong> |
| 证据转化 | 刑事转行政<strong>都能转</strong>；行政转刑事<strong>实物类可转、言词类不转、鉴定意见除外</strong> |
| 三个当场 | 当场网上接报案登记、当场接受证据材料、当场出<strong>受案回执</strong>并告知查询进展与投诉举报途径 |

## 课程口诀

::: tip
**口诀（案件转化）：「治安转刑事，原治安结案；刑事转治安，原刑事撤案。」**

讲者连说两遍「再说一遍」，是本集最容易记反的一组。

课程位置：86:30。
:::

::: tip
**口诀（证据转化）：「刑事转治安，证据都可转；治安转刑事，实物类可转、言辞类不可转、鉴定意见除外。」**

讲者原话称「先记得一口诀」，是本集唯一由讲者自命名的口诀。

课程位置：87:30。
:::
