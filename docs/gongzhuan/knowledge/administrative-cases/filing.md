# 立案

## 一、案件分类

- **行政案件包含治安案件**，还包括交通管理、出入境管理等。
- 构成犯罪的，按刑事案件处理；符合治安违法规定、尚不够刑事处罚的，按治安案件处理。
- 暂时无法确定案件性质的，可以先按行政程序办理；发现涉嫌犯罪，再转刑事程序。

## 二、接报案的三种处理

| 情况 | 处理 |
| --- | --- |
| 本单位管辖 | 依法立案、调查处理 |
| 公安机关管，但本单位不管 | **24小时内移送**有管辖权的单位，并告知 |
| 不属于公安机关职责 | 告知向其他主管机关报案，按规定口头或书面告知 |

**不得推诿、拒接，不得要求群众自行寻找有管辖权的公安单位。**

## 三、“三个当场”

1. 当场进行网上接报案登记。
2. 当场接受证据材料。
3. 当场出具回执，并告知查询进展、投诉监督的方式。

::: tip
**口诀：登记、接证、给回执。**
:::

## 四、审查期限

| 类型 | 课件中的期限 |
| --- | --- |
| 行政案件一般情况 | 原则上不超过 **24小时** |
| 行政案件疑难复杂情况 | 不超过 **3日** |
| 刑事案件一般情况 | 原则上不超过 **3日** |
| 刑事线索需要查证 | 不超过 **7日** |
| 刑事案件重大疑难复杂情况 | 经批准可延长至 **30日** |

::: danger
**注意：以上是审查期限，不是办案期限。新《治安管理处罚法》要求有关治安案件立即立案调查，不能理解为可以一律等待24小时。**
:::

## 五、案件转换

- **行政转刑事：原行政案件结案。**
- **刑事转治安：原刑事案件撤案。**
- 证据转换要区分方向和种类，不能一律照搬。
- 重点记忆：依法收集的**物证、书证、视听资料、电子数据等**，可按规定衔接使用；行政转刑事时，言词证据一般需要依法重新收集。

::: tip
**口诀：刑事转治安证据都可转，原刑事撤案；治安转刑事证据部分转，原治安结案。**
:::

## 六、易错点

- **接报案登记 ≠ 立案 ≠ 办结。**
- 接报案回执不等于立案回执。
- “24小时移送”与“24小时审查”是两项不同规则。
- 不能因损失小、后果轻就拒绝接报案。
- 重复报案且案件正在办理或已办结的，应解释，不再重复登记。
