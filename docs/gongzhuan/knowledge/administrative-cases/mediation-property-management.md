# 治安调解、涉案财物管理

## 1. 治安调解的前提

抓住四点：

**民间纠纷引起＋属于治安案件＋情节较轻＋当事人自愿。**

单纯民事纠纷，不要直接套用治安调解程序。

可以涉及殴打、故意伤害、侮辱、诽谤、损毁财物、干扰正常生活等，但仍须满足上述条件。

## 2. 不适用调解的情形

- 雇凶伤害；
- 结伙斗殴或其他寻衅滋事；
- 多次实施违反治安管理行为；
- 当事人明确不愿调解；
- 调解中再次侵害对方；
- 调解中违法嫌疑人逃跑。

## 3. 调解结果与时间

- **达成协议并履行：不再处罚。**
- 未达成，或达成后不履行：对违法行为依法作出处理；民事赔偿争议可依法起诉。
- 一般调解一次，按规定在3个工作日内进行；需要再次调解的，在第一次调解后7个工作日内完成。
- 调解不成或达成后不履行，依法开始计算相应办案期限。

新法增加：属于治安调解范围的案件，在公安机关作出处理决定前，**自行和解或经人民调解达成协议并履行，书面申请且获公安机关认可，可以不予处罚**。

## 4. 涉案财物：分清三个动作

| 处理方式 | 重点对象或用途 |
|---|---|
| 扣押 | 为调查、鉴定、固定证据而暂时控制相关物品 |
| 收缴 | 违禁品、赌具赌资、吸毒用具，以及直接用于违法的本人所有工具等 |
| 追缴 | 违法所得 |

::: danger
易错点：

- 作案工具注意**“本人所有、直接用于实施违法”**，不是相关物品都收缴。
- 违法所得能明确被侵害人的，应依法退还。
- 被侵害人、善意第三人合法占有的财产，原则上登记；确需鉴定的，可依法扣押，鉴定后立即解除。
- 不能把治安案件中的收缴、追缴随意写成“没收”。

:::

## 课程复习清单

> 来源：2027 公专 P12 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 调解须由民警主持 | 主持人必须是民警，<strong>辅警、律师都不能主持</strong>；辅警可以参与调解；可邀请当事人居住地村委会和双方熟悉的人协助 |
| 组织调解的民警人数 | 无任何前提时须<strong>两人以上（含两人）</strong>；前提是规范设置、严格管理的执法办案场所，一名民警即可组织；本集复述前集口诀「闻便解压，一警可干」 |
| 未成年人调解通知监护人 | 应当通知父母或其他监护人到场；已满 16 周岁、以自己劳动收入为主要生活来源、本人同意的，<strong>不予通知</strong> |
| 被侵害人可委托他人 | 被侵害人可委托他人参加调解，须向公安机关递交委托书；<strong>违法嫌疑人不得委托</strong>，须本人到场 |
| 调解的四项原则 | 合法、公正、自愿、及时；最爱考<strong>自愿</strong>；自愿指矛盾双方主体自愿，第三人（亲属、朋友）说愿意无效 |
| 民间纠纷类适用情形 | 因民间纠纷引起的殴打他人、故意伤害、侮辱诽谤、诬告陷害、故意毁财、侵入他人住宅等，且<strong>情节较轻</strong>；多发生在亲友、邻里、同事、在校学生之间 |
| 被侵害人事前过错 | 侵害行为由被侵害人<strong>事前过错</strong>引起的可以调解，如被侵害人先辱骂、挑衅 |
| 其他适宜调解情形 | 无亲友邻里关系但更易化解矛盾的（如店主与顾客争执）也可调解；体现<strong>调解优先</strong> |
| 治安案件是调解前提 | 前提是本案本身属治安案件；<strong>过失</strong>（不小心）毁坏财物不是治安案件，只能走民事赔偿、到法院起诉 |
| 现场调解与协议省略 | 事实清楚、因果关系明确、不涉医药费与物品损失或双方赔偿无争议，可当场调解；<strong>不用立案、不做笔录</strong>；协议书一般当场制作，全程录音录像已载明当事人情况、主要事实、协议内容的可省略 |
| 调解的两种结果 | 达成协议并履行的，不再处罚；未达成协议或达成后不履行的，依法给予处理 |
| 协议履行后不得反悔 | 协议书近似合同，履行后<strong>不得重新组织调解</strong>；不服不能复议、不能行政诉讼；事后伤情加重也只告知提起民事诉讼 |
| 治安转刑事的处理 | 履行协议后发现伤情为轻伤（如肋骨骨折 5 根），属案件事实重大变化，公安机关<strong>主动确认调解协议无效</strong>，重新立为刑事案件 |
| 互殴双方均受处理 | 互为协议人又互为违法行为人时一方不履行，对<strong>双方</strong>都依法处理，不是只处理不履行的一方 |
| 治安案件和解的条件 | 须在作出处理决定前；自行和解或经人民调解委员会调解达成协议并履行；<strong>必须书面申请</strong>并经公安机关认可，口头不行，才不予处罚 |
| 调解次数与期限 | 原则上一次；第一次 3 个工作日，第二次 7 个工作日，<strong>最多两次</strong>；不含伤情鉴定时间，从鉴定结束起算 |
| 禁止调解：雇凶与结伙 | 雇凶伤害他人的；结伙斗殴或寻衅滋事的 —— 结伙指一方<strong>两人以上</strong>，一对一叫互殴 |
| 禁止调解：多次与拒调 | 多次违反治安管理的（3 次以上、屡教不改）；当事人<strong>明确表示不愿调解</strong>的 |
| 禁止调解：调解中再生事 | 调解中又对对方实施违反治安管理行为的；一方逃跑的；<strong>无被侵害人</strong>的违法行为（黄赌毒、卖淫嫖娼、赌博、吸毒） |
| 办案期限的起算 | 从调解未达成或达成后不履行之日起算，<strong>当日即起算、不是次日</strong>；其余期间通用规则是当日不计入、次日起算 |
| 刑事公诉案件和解 | 条件：民间纠纷引起、可能判 3 年以下刑罚；或除渎职犯罪外可能判 7 年以下有期徒刑的过失犯罪。从宽：公安<strong>不能撤案</strong>，检察院可不起诉，公安、检察院逐级递交从宽处理意见，法院最终判决；强奸等故意犯罪不适用 |
| 涉案财物24小时移交 | 提取后 24 小时内移交涉案财物管理人员；需鉴定、辨认、检验、检查的，经办案部门负责人批准，工作完成后 24 小时内移交；<strong>严禁办案人员自行保管</strong>，办管分离 |
| 现场扣押与证据保全 | 现场带回即扣押，直到作出行政处罚决定书才转为收缴或追缴；治安案件扣押文书是<strong>证据保全决定书</strong>及清单，没有扣押决定书；扣押期限 30 日加 30 日；唯一例外是当场处罚加违禁品，可当场收缴 |
| 收缴的对象 | 毒品、淫秽物品、赌具赌资、吸毒用具、伪造变造证件票证、倒卖的车票演出票、<strong>本人所有</strong>的作案工具、毒资 |
| 收缴的决定权限 | 原则上分局以上决定；违禁品、管制器具、注射吸毒用具及<strong>500 元以下</strong>且当事人无异议的，派出所可以收缴 |
| 追缴的对象与返还 | 追缴针对违法所得（如盗窃所得），分局以上决定；追缴财物应当<strong>退还被侵害人</strong>；嫖资按公安部法制局口径归追缴 |
| 第三人财物只登记 | 第三人合法占有的财物不扣押、不收缴、不追缴，<strong>登记后立即返还</strong>；确需鉴定的可以依法扣押，结束后立即解除 |
| 涉案财物无没收 | 涉案财物管理中没有「没收」这一措施，选项出现没收多为错；没收是行政处罚的种类 |
| 结案与终止调查 | 结案：不予处罚、达成并履行协议、处理决定已执行、治安转刑事、刑事转治安、被执行人死亡；终止调查：无违法事实、已过追究时效、<strong>处罚决定前</strong>嫌疑人死亡 |
| 送达方式与留置 | 直接送达；拒收可留置，邀邻居或见证人在场说明情况、可录音录像，文书留在送达处并在附卷文书注明；代收人须成年家属、单位负责人或村委会；可委托送达、邮寄用 EMS；<strong>公告送达兜底，不少于 60 日</strong> |

## 课程口诀

::: tip
**口诀（调解履行的后果）：「履行协议不处罚结案，不履行协议处理，民事诉讼」**

讲者原话「咱们编个口诀」。履行了就结案不罚；不履行就依法处理，损害赔偿告知当事人提起民事诉讼。语音识别写作「明日诉讼」，按讲解改回。

课程位置：29:30。
:::

::: tip
**口诀（收缴的范围）：「黄赌毒、作案工具、伪造变造证件票证等非法财物应收缴」**

讲者原话「我给大家编着口诀叫什么呢叫……」。作案工具限于违法行为人本人所有，第三人所有只能登记后返还。

课程位置：77:30。
:::
