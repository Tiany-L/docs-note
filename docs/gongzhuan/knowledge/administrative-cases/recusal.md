# 回避

::: tip
**可能影响公正就回避。**
:::

## 一、哪些人需要回避

适用人员：**公安机关负责人、办案民警、鉴定人、翻译人员。**

三种情形：

- **身份关系**：本人是本案当事人，或者是当事人的近亲属。
- **利害关系**：本人或其近亲属与本案有利害关系。
- **其他关系**：与当事人有其他关系，可能影响案件公正处理。

::: danger
**注意：证人不适用回避制度。证人具有不可替代性**
:::

## 二、回避怎么提出

| 方式 | 重点 |
| --- | --- |
| **自行回避** | 符合条件的人员主动申请，并说明理由 |
| **申请回避** | 当事人及其法定代理人提出，并说明理由 |
| **指令回避** | 应回避却未自行申请，也未被申请回避，由有权机关指令回避 |

口头提出回避申请的，应当在**询问笔录**中记明。

回避前已经开展的工作，并非一律无效，由**作出回避决定的机关**判断其效力。

## 三、由谁决定【重点区分】

### 行政案件

| 需要回避的人 | 决定机关 |
| --- | --- |
| 办案民警 | **所属公安机关** |
| 公安机关负责人 | **上一级公安机关** |
| 鉴定人、翻译人员 | **指派或聘请他们的公安机关** |

例：

- 派出所民警 → **所属派出所**决定。
- 派出所所长 → **县级公安机关**决定。
- 分局治安大队、网安大队等民警 → **所属分局**决定，不能直接写“大队决定”。

::: danger
**注意：行政案件的回避决定主体写的是“机关”。**
:::

### 刑事案件

| 需要回避的人 | 决定主体 |
| --- | --- |
| 侦查人员 | 县级以上公安机关负责人 |
| 县级以上公安机关负责人 | 同级人民检察院检察委员会 |

::: danger
易错点：检察委员会出现在这里的**刑事案件**规则中，不要套到行政案件。
:::

## 四、期限和效力

行政案件中：

- **申请后**：收到回避申请之日起 **2日内** 作出决定，并通知申请人。
- **决定前**：办案民警**不得停止调查**。
- **决定后**：被决定回避的人不得再参与该案的**调查、审核、审批**。
- **此前工作**：不是自动无效，仍按“谁决定回避，谁决定证据效力”判断。
