# 回避

::: tip
**可能影响公正就回避。**
:::

## 一、哪些人需要回避

适用人员：**公安机关负责人、办案民警、鉴定人、翻译人员。**

三种情形：

- **身份关系**：本人是本案当事人，或者是当事人的近亲属。
- **利害关系**：本人或其近亲属与本案有利害关系。
- **其他关系**：与当事人有其他关系，可能影响案件公正处理。

::: danger
**注意：证人不适用回避制度。证人具有不可替代性**
:::

## 二、回避怎么提出

| 方式 | 重点 |
| --- | --- |
| **自行回避** | 符合条件的人员主动申请，并说明理由 |
| **申请回避** | 当事人及其法定代理人提出，并说明理由 |
| **指令回避** | 应回避却未自行申请，也未被申请回避，由有权机关指令回避 |

口头提出回避申请的，应当在**询问笔录**中记明。

回避前已经开展的工作，并非一律无效，由**作出回避决定的机关**判断其效力。

## 三、由谁决定【重点区分】

### 行政案件

| 需要回避的人 | 决定机关 |
| --- | --- |
| 办案民警 | **所属公安机关** |
| 公安机关负责人 | **上一级公安机关** |
| 鉴定人、翻译人员 | **指派或聘请他们的公安机关** |

例：

- 派出所民警 → **所属派出所**决定。
- 派出所所长 → **县级公安机关**决定。
- 分局治安大队、网安大队等民警 → **所属分局**决定，不能直接写“大队决定”。

::: danger
**注意：行政案件的回避决定主体写的是“机关”。**
:::

### 刑事案件

| 需要回避的人 | 决定主体 |
| --- | --- |
| 侦查人员 | 县级以上公安机关负责人 |
| 县级以上公安机关负责人 | 同级人民检察院检察委员会 |

::: danger
易错点：检察委员会出现在这里的**刑事案件**规则中，不要套到行政案件。
:::

## 四、期限和效力

行政案件中：

- **申请后**：收到回避申请之日起 **2日内** 作出决定，并通知申请人。
- **决定前**：办案民警**不得停止调查**。
- **决定后**：被决定回避的人不得再参与该案的**调查、审核、审批**。
- **此前工作**：不是自动无效，仍按“谁决定回避，谁决定证据效力”判断。

## 课程复习清单

> 来源：2027 公专 P04 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 回避情形 | 本案当事人或当事人近亲属；本人或其近亲属与本案<strong>有利害关系</strong>；与当事人有其他关系<strong>可能影响公正处理</strong>。判断就一句：可能影响公正就回避 |
| 怎么判 | 情形不用背，用「三观」过一遍即可；题目常在四个选项里留两个都像该回避的，考的是<strong>择优</strong>——哪个更影响公正 |
| 自行回避 | 民警自己觉得不合适，<strong>主动向组织提出</strong>；法条未写口头还是书面，所以不考这个细节 |
| 申请回避 | 当事人及其法定代理人提出，<strong>可口头可书面</strong>；口头提出的应在<strong>询问笔录中注明</strong> |
| 指令回避 | 应当回避却没回避、也没被申请的，由<strong>有权决定的公安机关</strong>直接指令回避 |
| 决定期限 | 收到申请之日起<strong>两日内</strong>作出决定并通知申请人。注意 <strong>「48 小时」不等于「两日」</strong>，选项把两日换成 48 小时就是错的 |
| 不停止调查 | 申请期间<strong>调查不停止</strong>；只有作出回避决定之后，才不得参与该案的调查、侦查、审批工作 |
| 证据效力 | 回避前收集的证据<strong>效力待定</strong>，由<strong>作出回避决定的机关</strong>决定是否有效，不是当然有效也不是当然无效 |
| 治安·民警回避 | 由<strong>所属公安机关</strong>决定：派出所民警→派出所；治安、网安、刑侦等<strong>大队</strong>民警→所在分局 |
| 大队不是机关 | 治安案件里能称「公安机关」的只有<strong>派出所和分局</strong>；什么大队只能叫<strong>办案部门</strong>，所以大队无权决定回避 |
| 治安·负责人回避 | 所长、教导员属正职，副所长属副职，<strong>都算公安机关负责人</strong>，回避由县级以上公安机关决定，即<strong>分局</strong> |
| 刑事·侦查人员 | 回避由<strong>县级以上公安机关负责人</strong>决定 —— 落在「负责人」这个人身上，不是机关 |
| 刑事·负责人 | 局长、政委、副局长的回避由<strong>同级人民检察院检察委员会</strong>决定；<strong>只有刑事案件</strong>才牵涉检察院 |
| 治安与刑事之别 | 治安回避由<strong>机关（组织）</strong>决定，刑事回避由<strong>负责人（个人）</strong>决定。一字之差，考的就是这里 |
| 鉴定人翻译人 | 由<strong>指派或聘请</strong>他们的公安机关决定是否回避 |
| 证人 | <strong>证人没有回避制度</strong>，因为证人具有<strong>不可替代性</strong>；即使明知可能偏向，也只能靠询问手段解决，不能换人 |
| 一处争议 | 副所长、教导员是否属「公安机关负责人」各机构有分歧（约七三分）。依《公安机关执法细则》第四版，副职负责人也算，回避由分局决定 |

## 课程口诀

::: tip
**口诀（回避与证据效力）：「谁决定回避，谁决定证据效力。」**

讲者原话「你看我总结这口诀叫谁决定回避谁决定证据效力」。落在「效力待定」四个字上：回避前收集的证据不当然有效、也不当然无效，由作出回避决定的机关定。

课程位置：12:00。
:::
