# 《治安管理处罚法》新旧对比②

本集承接具体违法行为，重点转向**调查、决定、执行和执法监督**。

## 1. 行为规定变化

- 社会生活噪声：依法劝阻、调解、处理仍未制止，继续干扰生活、工作、学习的，可以依法拘留或罚款；不能简单记成“噪声只能罚款”。
- 动物管理：区分一般扰民、危险动物管理、未采取安全措施致伤、驱使动物伤人。
- 淫秽物品或淫秽信息涉及未成年人的，依法从重处罚。
- 涉毒行为增加相关限制性措施，注意法定条件和期限。

## 2. 数字变化对照表【重点背】

| 考点 | 旧法 | 新法 |
|---|---:|---:|
| 派出所可决定的罚款 | 500元以下 | **1000元以下** |
| 当场处罚罚款额度 | 200元以下 | **500元以下** |
| 当场收缴且无异议的额度 | 50元以下 | **200元以下** |
| 治安罚款听证门槛 | 2000元以上 | **4000元以上** |
| 一般办案期限及延长 | 30日＋30日 | **30日＋30日＋30日** |
| 传唤后询问查证 | 8、24小时 | **8、12、24小时** |
| 曾受治安处罚而从重的期限 | 6个月 | **1年** |
| 询问时通知监护人的年龄范围 | 不满16周岁 | **不满18周岁** |

::: danger
注意：听证门槛是**4000元以上**；“以上、以下”一般都包含本数。
:::

## 3. 调查与决定程序

- 新法明确治安案件的立案调查要求。
- 办案期限从**立案之日**起算；重大复杂案件依法批准，最多延长两次。
- 鉴定期间、听证期间不计入办案期限，不能机械认为所有案件都必须90个自然日内结束。
- 规范办案场所内询问、扣押、辨认，或者进行调解，符合条件可由1名民警办理，但必须全程同步录音录像。
- 未依法录制，或录像损毁、丢失，相关证据不能作为处罚依据。
- 对不满18周岁的行为人，处罚前还应告知监护人并听取意见。
- 特殊情形下可能执行拘留的未成年人，有要求听证的权利；未成年人听证不公开。

## 4. 执行与记录封存

- 新增暂缓拘留、临时出所的有关特殊情形。
- 治安违法记录应当封存，不得随意提供或公开。
- 国家机关办案需要，或者有关单位依据国家规定查询的，属于例外；查询单位负有保密义务。

::: danger
**封存不等于删除，不等于撤销处罚，也不等于从未违法。**
:::

## 课程复习清单

> 来源：2027 公专 P14 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 违反法院禁止令 | 旧法治安领域与法院毫无关系、没有处罚依据；新法第73条：违反人民法院刑事判决中的禁止令、职业禁止令可以治安处罚。这是治安领域第一次与法院挂钩；<strong>禁止令</strong>随管制、缓刑宣告，<strong>职业禁止令</strong>针对利用特定职业实施的犯罪 |
| 违反家暴告诫书 | 旧法告诫书不是处罚、连警告都不算，只是震慑，违反了也没有后果；新法：拒不执行公安机关依反家庭暴力法、妇女权益保障法制发的<strong>家暴告诫书、性骚扰告诫书</strong>可以处罚 |
| 违反禁止接触措施 | 新增第73条：违反监察机关在监察工作中、司法机关在刑事诉讼中采取的禁止接触证人、鉴定人、被害人及其近亲属的保护措施，可以处罚。幅度为<strong>警告或 1000 元以下</strong>罚款，情节较重 5 日以上 10 日以下拘留、可并处 1000 元以下罚款 |
| 被关押人脱逃 | 旧法没有规定，属立法漏洞，只有刑法上的脱逃罪；新法：依法被关押的违法行为人脱逃，可以治安处罚，条文是模仿脱逃罪设置的 |
| 偷开机动车非盗窃 | 第79条；<strong>开走又开回来</strong>、没有非法占有目的，是一个独立的违法行为；与盗窃的主观心态不同，<strong>不算盗窃</strong> |
| 容留卖淫的认定 | 扩大解释：不只提供场所，还包括<strong>为他人卖淫提供便利条件</strong>（代买避孕套、门口望风），场所不限车、船、出租屋、帐篷；容留<strong>不以营利为目的</strong>也要罚，但卖淫本身必须以营利为目的；组织卖淫、强迫卖淫仍是刑事案件 |
| 种植罂粟的处理 | 不满 <strong>500 株</strong>是治安案件，500 株以上构成非法种植毒品原植物罪。不予处罚要三个前提同时具备：500 株以下、<strong>成熟前</strong>、<strong>自行铲除</strong>（不是公安机关铲除） |
| 吸毒类新增强迫 | 第85条：引诱、教唆、欺骗、<strong>强迫</strong>他人吸毒，其中强迫为新增；容留他人吸毒、强迫他人吸毒不再是刑法的专属，治安也可以罚 |
| 通风报信新增条件 | 第87条：在公安机关查处吸毒、嫖娼、赌博案件时为行为人通风报信要处罚，新增<strong>提供条件</strong>也一并要罚 |
| 噪声扰民先劝后罚 | 旧法制造噪声干扰他人正常生活上来就警告；新法先由村委会、居委会、业主委员会、物业人员劝阻调解，<strong>未能制止</strong>才处罚，且不再先警告，直接可拘留或 <strong>1000 元以下</strong>罚款 |
| 养犬分级处罚 | 违规出售、饲养<strong>烈性犬、大型犬</strong>：警告，警告不改或致动物伤人的可拘留并处 1000 元以下罚款；未对动物采取安全措施（如不牵绳）致伤人的：1000 元以下罚款，情节较重拘留；一般性干扰他人生活仍为警告、警告不改 1000 元以下罚款 |
| 受案改立案 | 旧法一直叫「受案」，只是公安部下发通知、无法条支撑；新法与行政处罚法衔接，统一改为<strong>立案</strong>，解决长期没有依据的问题 |
| 程序冲突从新法 | 《公安机关办理行政案件程序规定》是治安法第四章的扩展（30 余条扩成 200 余条）；两法冲突时<strong>以治安管理处罚法为准</strong>，不能依程序规定，程序规定尚未改完 |
| 刑事转治安证据 | 第92条新增：公安机关有权向有关单位和个人收集调取证据、应当如实提供，伪证要担责；刑事办案及其他执法机关移送前收集的<strong>物证、书证、视听资料、电子数据</strong>可作治安案件证据。复述前集口诀：<strong>刑事转治安证据都可转，治安转刑事实物类可转、言辞类不可转、鉴定意见除外</strong> |
| 传唤与强制传唤 | 工作证改为<strong>人民警察证</strong>；告知被传唤人传唤的<strong>原因和依据</strong>，通知家属的是原因和处所；无正当理由不接受或逃避传唤可强制传唤，由<strong>办案部门负责人</strong>批准 |
| 询问查证8与12 | 由 8 小时、24 小时改为 <strong>8 小时、12 小时</strong>；涉案人数众多<strong>或</strong>身份不明（顿号是「或」的关系）可延长到 12 小时；期间全程录音录像，并保证饮食和休息 |
| 询问未成年人18岁 | 旧法是 16 周岁，新法吸收程序规定、统一为<strong>18 周岁</strong>；父母或监护人不能到场的，通知其他亲属、学校、单位、居住地基层组织或未成年人保护组织，<strong>必须有人到场</strong> |
| 异地询问两方式 | 第100条新增：一是委托异地公安机关代为询问（实务中多不愿接），二是通过公安机关视频系统远程询问；<strong>远程笔录是宣读</strong>，不让本人看、不让本人签字，由民警在笔录中注明，宣读与询问全程录音录像 |
| 人身检查与采集 | 第102条：经公安机关负责人批准；已经采集的<strong>不得重复采集</strong>；提取或采集<strong>被侵害人</strong>信息、样本，必须经本人或其监护人同意 |
| 检查程序要求 | 人身、物品检查：出示人民警察证且不少于两人（<strong>双人双证</strong>），不需审批；场所检查：<strong>县级以上</strong>公安机关负责人批准并使用检查证，确有必要立即检查的出示警察证可当场检查、全程录音录像；检查妇女身体由女性工作人员<strong>或医师</strong>进行（旧法行政案件只有女性工作人员） |
| 扣押与当场扣押 | 第105条：与案件有关、必须鉴定的物品可以扣押，鉴定后立即解除；<strong>第三方合法财产不得扣押</strong>，应当登记。扣押是行政强制措施，须<strong>公安机关负责人</strong>批准（含派出所所长，不含治安大队长）；情况紧急或价值不大可当场扣押，<strong>24 小时</strong>内补办手续 |
| 一人执法四类 | 第108条：在执法办案场所询问、扣押、辨认、调解，全程录音录像，<strong>一名警察</strong>即可（为基层减负）；条文<strong>没有「等」字</strong>，只有这四类。复述前集口诀「二警检验人文强」＝询问、辨认、检查、看验、强制措施 |
| 派出所权限1000 | 派出所的处罚权限由警告和 <strong>500 元</strong>罚款，提高到警告和 <strong>1000 元</strong>罚款 |
| 法制审核前置 | 未经法制审核或审核不通过，<strong>不得作出</strong>处罚决定；三类必审：重大公共利益、直接关系当事人或第三方重大权益<strong>且</strong>经过听证、特别复杂；<strong>初次</strong>从事治安处罚法制审核的人员必须通过法考 |
| 听证4000与未成年 | 范围仍是吊销许可证、责令停业整顿、较大数额罚款；个人罚款标准由 <strong>2000 元改为 4000 元</strong>（企业、出入境的标准在程序规定里，未定）；新增<strong>未成年人行政拘留</strong>可要求听证且不公开举行；末项为公安机关认为必要的兜底。复述旧口诀「吊停大要听证」，其中「大」已由 2000 变 4000 |
| 办案期限90 | 由 30 日加 30 日改为 <strong>30 加 30 加 30</strong>，最长 <strong>90 日</strong>，与行政处罚法对齐；<strong>鉴定、听证期间</strong>都不计入办案期限（旧法只排除鉴定） |
| 当场处罚与收缴 | 当场处罚由警告或 <strong>200 元</strong>改为警告或 <strong>500 元</strong>；当场收缴由 50 元提到 <strong>200 元</strong>；新增电子支付方式；当场处罚可<strong>一名民警</strong>作出决定并全程录音录像 |
| 异地执行拘留 | 被拘留人在异地被抓获或需在异地执行的，经<strong>异地拘留所主管公安机关</strong>批准即可，<strong>不需要</strong>办案地公安机关同意；目的是省押解经费 |
| 暂缓执行拘留 | 新增升学考试、子女出生、近亲属病危或死亡可申请暂缓；须在处罚决定送达后、<strong>交付执行前</strong>提出；提供担保人或<strong>每日 200 元</strong>保证金；已在执行中的由公安机关参照办理 |
| 违法记录封存 | 第136条首次建立封存制度，<strong>所有</strong>治安违法记录一律封存，不得向单位个人提供或公开，办案需要或依国家规定查询除外；刑事封存的条件是<strong>犯罪时不满 18 周岁且被判处 5 年以下</strong>有期徒刑 |
