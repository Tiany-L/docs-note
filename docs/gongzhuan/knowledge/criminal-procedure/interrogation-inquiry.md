# 刑事讯问、询问

## 知识点速记

> 来源：2027 公专 P25 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 讯问主体与人数 | 由人民检察院或公安机关的侦查人员负责；不得少于两人；刑事案件没有辅警，必须是<strong>两名以上在编在职民警</strong>。 |
| 个别讯问与轮换主体 | 讯问应当个别进行，防串供；只要求每次两名在编民警，不要求同一批人；多次讯问<strong>轮换侦查人员不算程序违法</strong>。 |
| 讯问地点与讯问室设置 | 原则上在执法办案场所的讯问室；已羁押的到看守所讯问；讯问室<strong>不得设在二楼</strong>，并与公共场所分离。 |
| 讯问地点的方便原则 | 按方便侦查取证选地点；现场、医院、住处、拘留所、戒毒所、监狱就近问；<strong>押解途中容易出事</strong>，所以羁押中的一般不提回办案中心。 |
| 指居讯问的住讯分离 | 指定居所监视居住是唯一不符合方便原则的例外；<strong>住讯分离</strong>，须提至执法办案中心的讯问室问，不在指居处问。 |
| 传唤的批准与证件 | 对不需要逮捕、拘留的嫌疑人；经办案部门负责人批准；可传唤到指定地点或住处；须出示<strong>传唤证和人民警察证</strong>。 |
| 传唤时限 12 与 24 | 原则上不超过 <strong>12 小时</strong>；案情特别重大复杂、需采取拘留逮捕措施的，经办案部门负责人批准不超过 <strong>24 小时</strong>。 |
| 办案部门与县级以上负责人 | 办案部门负责人指刑侦、治安、网安等大队长；县级以上公安机关负责人指主管副局长、局长、政委；批传唤延长的是前者。 |
| 传唤证时间填写主体 | 到案时间、结束时间都由<strong>嫌疑人</strong>填写；嫌疑人拒绝签名的，由侦查人员在传唤证上注明，不得代为签名。 |
| 治安与刑事传唤对比 | 治安传唤 8／12／24，刑事传唤 12／24；二者都可口头可书面；<strong>治安多出 8 小时一档</strong>。 |
| 到案离开时间的签字主体 | 只有<strong>治安案件的口头传唤</strong>，到案时间和离开时间由民警在询问笔录中签；治安书面、刑事口头、刑事书面一律由嫌疑人签。 |
| 未成年人法定代理人到场 | 讯问、询问未成年人<strong>应当</strong>通知法定代理人到场，不是「可以」；未成年人无父母等监护人的，再找其他合适成年人。 |
| 女性未成年嫌疑人在场规则 | 讯问<strong>女性未成年</strong>犯罪嫌疑人应当有女性工作人员在场；女性成年人无此要求，男民警也可以问。 |
| 聋哑人与语言不通的保障 | 聋哑犯罪嫌疑人应有通晓聋哑手势的人参加；不通晓当地语言文字的配翻译人员；以上同样适用于证人和被害人。 |
| 律师介入侦查的节点 | 第一次讯问或采取强制措施之日起；侦查阶段<strong>只有律师</strong>能以辩护人身份介入；首次讯问应告知有权委托律师（复述）。 |
| 录音录像的可以与应当 | 讯问普通嫌疑人<strong>可以</strong>全程录音录像；可能判无期、死刑或其他重大案件的<strong>应当</strong>录；立法本意主要是防刑讯逼供。 |
| 指居讯问的录音录像 | 2025 年 6 月 30 日最高检、公安部规定；在讯问室讯问被指居的嫌疑人<strong>应当全程录音录像</strong>，不看罪名和刑期。 |
| 自行书写供述 | 嫌疑人要求自行书写<strong>应当准许</strong>；无需审批，普通侦查人员即可决定；该规则同样适用于证人和被害人。 |
| 笔录核对与逐页签认 | 交其核对，阅读有困难的向其宣读；可补充、可修改；确认无误逐页签名；刑事是签名<strong>并</strong>按手印，治安是签名<strong>或</strong>按手印；末页写「以上笔录我看过，和我说的相符」。 |
| 拒签笔录的证据效力 | 嫌疑人拒签的，由侦查人员注明；<strong>不影响笔录作为合法证据</strong>；不得代签，写明何人拒绝签名。 |
| 询问证人被害人的地点 | 现场、单位、住处、其提出的地点、公安机关都可以；现场出示<strong>人民警察证</strong>，其他地点还要办案部门批准的询问通知书。 |
| 询问证人被害人的时限 | 与讯问一致：不超过 <strong>12 小时</strong>；情况重大复杂的不超过 <strong>24 小时</strong>。 |
| 禁止诱供的发问方式 | 不得先说出罪名再让其确认，属<strong>诱供</strong>；应问「知道为什么找你」，让其自行供述，否则只认警方已知的那一件事。 |
| 同案犯分别讯问 | 讯问同案犯应当<strong>分别进行</strong>；可以两名以上侦查人员问一个嫌疑人，但不能同时问多个嫌疑人。 |

## 课程口诀

::: tip
**口诀（讯问录音录像的可以与应当）：「公安问可以录，指居无死中应当录」**

公安讯问原则上可以录；被指定居所监视居住的，以及可能判无期、死刑或其他重大案件的嫌疑人，应当全程录音录像

课程位置：28:00。
:::
