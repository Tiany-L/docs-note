# 立案、移送案件

## 知识点速记

> 来源：2027 公专 P23 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 治安受案与刑事立案 | 治安领域已取消<strong>受案</strong>，统一并入立案；刑事领域仍是先受案、后立案，两套并存。 |
| 刑事案件来源 | 主动投案、报警、110 指挥中心指令、上级及市局交办、民警工作中偶然发现、其他行政机关移交。 |
| 无管辖权案件移送 | 不属本机关管辖的，<strong>24 小时</strong>内移送有管辖权部门；需采取紧急措施（如保护现场）的，先采取措施再移送。 |
| 立案审查期限三七三十 | 受案到立案之间称<strong>调查核实</strong>（原称初查）；一般 3 日，犯罪线索需查证不超 7 日，重大疑难经县级以上公安机关负责人批准延至 30 日。 |
| 未成年人被性侵案件 | 立即立案侦查；重大疑难复杂的不超 7 日，不再适用 30 日。 |
| 经济犯罪案件期限 | 原则 7 日内决定；重大疑难经县级以上公安机关批准延至 30 日；特别重大或跨区域线索经<strong>上一级</strong>公安机关批准再延 30 日，共 60 日。 |
| 安全生产案件依据 | 依应急管理部、公安部、最高法、最高检衔接办法，立案审查同样是 3 日、7 日、30 日；依据不在刑诉法。 |
| 安全生产案件抄告 | 移送、退回、立案、不立案、撤案，每个动作都要<strong>书面抄告同级人民检察院</strong>。 |
| 调查核实可采取措施 | 可询问、查询、勘验、鉴定、调取证据材料；共同点是不限制被调查人人身权、财产权。 |
| 调查核实禁止措施 | 不得查封、扣押、冻结财产；不得技术侦查；不得拘传、取保、监视居住、拘留、逮捕。<strong>搜查</strong>法条未列，但属侦查措施，同样不得。 |
| 报案与举报 | 报案是被害人不知嫌疑人是谁时报警；举报是<strong>非当事人</strong>（如路人）告发，可知也可不知嫌疑人。 |
| 控告与移送 | 控告是<strong>被害人</strong>已知侵害人是谁；移送是公安机关接到不属本单位管辖的案件，先行处理完毕后移交有管辖权机关。 |
| 刑事诉讼开始标志 | 以<strong>立案</strong>为开始标志，不是受案。 |
| 立案三条件 | 有犯罪事实；需要追究刑事责任；属于本单位管辖。三条缺一不立。 |
| 其他应当立案情形 | 检察院通知立案；法院受理案件认为证据不足或可能判三年以上刑罚移送立案；上级公安机关指定管辖或书面通知立案。 |
| 派出所办案权限 | 派出所可受理刑事案件，但立案决定书、立案告知书盖<strong>分局</strong>章；实务多由刑侦大队驻所中队办理。 |
| 立案审批与文书 | 制作呈请立案报告书，报<strong>县级以上</strong>公安机关负责人批准；再制作立案决定书、立案告知书。 |
| 立案可不告知情形 | 涉及国家秘密、共同犯罪、集团犯罪、黑社会性质组织犯罪，可不予告知。 |
| 不立案通知 | 情形为无犯罪事实、显著轻微、过时效、特赦、告诉才处理、死亡（复述口诀「显时特告死」）；程序同立案，经县级以上负责人审批；不予立案通知书 <strong>3 日</strong>内告知控告人；行政机关移送的须说明理由并送达通知书及材料。 |
| 三联审批文书 | 办案部门负责人→法制大队长→<strong>主管刑侦副局长</strong>；实务走线上电子签。 |
| 不立案救济 | 控告人先向作出决定的公安机关申请复议（同级）；不服再向<strong>上一级</strong>公安机关申请复核。 |
| 救济仅限刑事案件 | 复议加复核只存在于刑事案件；治安案件只有行政复议，没有复核这一道。 |
| 应立不立监督 | 检察院要求说明理由的 7 日内说明；理由不成立通知立案，公安机关 <strong>15 日</strong>内必须立案。 |
| 不应立而立监督 | 检察院通知撤案即立即撤案；认为通知有误可要求同级检察院复议，不服提请上级检察院复核。 |
| 移送材料补正 | 材料不全的，受案 <strong>24 小时</strong>内书面告知移送机关，移送机关 3 日内补正；缺啥补啥，不得整卷退回。 |
| 移送文书内容 | 注明移送机关名称、涉嫌罪名、主办人及联系电话；案件移送书附清单并<strong>加盖公章</strong>。 |
| 移送案件审查期限 | 公安机关受案之日起 3 日内决定立案与否，书面通知移送机关；不立案书面说明理由并退回材料。 |
| 行政处罚不代替移送 | 移送前已作行政处罚的，处罚照旧执行，<strong>移送与处罚并行</strong>，不得以罚代送。 |

## 课程口诀

::: tip
**口诀（立案监督救济）：「同级复议，上级复核，先复议后复核」**

仅刑事案件适用；治安案件只走行政复议，无复核

课程位置：43:30。
:::
