# 刑事强制措施

## 知识点速记

> 来源：2027 公专 P28 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 刑事强制措施的种类 | 拘传、取保候审、监视居住、刑事拘留、逮捕五类，由轻到重排列；<strong>只限制人身自由、防止逃跑，不是刑罚</strong>；刑罚是主刑加附加刑，由法院宣判后惩戒。 |
| 拘传的决定与执行 | 公检法三家都能决定、都能执行；<strong>谁决定谁执行</strong>；公安决定的公安执行，检察院决定的检察院执行，法院决定的法院执行。 |
| 拘传的适用对象 | 只适用于<strong>犯罪嫌疑人</strong>；被害人、证人用询问通知书；须是未被羁押的嫌疑人。 |
| 拘传与强制传唤 | 刑案没有「强制传唤」这一说；治安案件须先口头或书面传唤、不听才能强制传唤，刑案<strong>可以直接拘传</strong>；<strong>传唤不是拘传的必经途径</strong>。 |
| 拘传审批与拘传证 | 办案单位制作呈请拘传报告书，报<strong>县级以上公安机关负责人</strong>审批，副局长、局长均可；拘传必有证，<strong>不得先拘传后补证</strong>，事后补证属重大程序违法。 |
| 拘传时间与讯问 | 一般不超过 <strong>12 小时</strong>；需拘留、逮捕的经县级以上负责人批准不超过 24 小时，不需拘留逮捕的到不了 24 小时；到案后<strong>立即讯问</strong>；两次拘传间隔不少于 12 小时，否则属变相拘禁。 |
| 拘传与传唤的区别 | 审批不同：拘传由县级以上审批，传唤由办案部门负责人审批；拘传必有证，传唤可口头；拘传<strong>可以上铐、使用警械</strong>，传唤须符合警械武器条例。 |
| 传唤、提讯、传讯辨析 | 传唤对未被羁押的嫌疑人；提讯对在押人员，用提讯提解证；传讯对取保候审、监视居住的人，用传讯通知书；<strong>三者都不通知家属</strong>。 |
| 取保候审的决定与执行 | 公检法都能决定，<strong>只有公安执行</strong>；保证方式为人保或金保，二者选一；<strong>不能同时要求保证人加保证金</strong>。 |
| 取保候审的适用条件 | 可能判管制、拘役或独立适用附加刑；可能判有期徒刑以上但不致发生社会危险性；患病、怀孕哺乳；<strong>羁押期限届满案件未办结</strong>。 |
| 取保候审的禁止情形 | 累犯、犯罪集团主犯、自伤自残逃避侦查、严重暴力犯罪，<strong>不得取保</strong>。 |
| 保证金数额与形式 | 起点 <strong>1000 元</strong>，未成年人 500 元；上限法律不设，由省级公安机关按本地经济情况规定；<strong>只能是人民币</strong>，外币、实物、虚拟货币都不行。 |
| 保证金缴纳与保管 | 一次性缴纳，<strong>不得分期、不得拖欠</strong>；存入公安机关指定<strong>银行专户</strong>；民警不得代收现金、不得打白条；账户情况报上一级公安机关备案。 |
| 保证人的条件 | 无牵连、有能力、有政治权利、<strong>有固定住处和固定收入</strong>；不要求有稳定工作；保证人 1 至 2 名。 |
| 保证人的责任 | 未履行义务罚款 <strong>1000 元以上 2 万元以下</strong>，由公安执行；协助逃跑、隐匿构成犯罪追刑责；<strong>没有行政拘留、没有民事责任</strong>。 |
| 未成年人保证方式 | 原规定只有未成年人取保优先适用保证人保证；<strong>2025 年 11 月 29 日新规</strong>扩至所有符合条件的人，原则上优先保证人保证。 |
| 取保候审的法定义务 | 未经<strong>执行机关</strong>批准不得离开所居住的市县；住址、单位、联系方式变动 24 小时内报告；传讯及时到案；不干扰作证、不毁灭伪造证据。 |
| 取保候审的酌定义务 | 不得进入特定场所、不得会见特定的人或通信、不得从事特定活动；上交<strong>出入境证件、驾驶证</strong>；<strong>不收身份证</strong>。 |
| 违反取保候审的处理 | 金保没收<strong>部分或全部</strong>保证金，责令悔过、重新缴纳或重提保证人；情节严重需逮捕的<strong>可先行拘留</strong>。 |
| 没收保证金的两种情形 | 自杀逃跑、毁灭伪造证据、干扰作证、打击报复证人等<strong>严重影响诉讼</strong>的，没收全部；未经批准离开、传讯不到等原则上<strong>不超过一半</strong>，两次违反可没收一半以上至全部。 |
| 监视居住的性质与期限 | 是逮捕、取保的<strong>替代手段</strong>；公检法决定、公安执行，由住处或指定居所的<strong>派出所</strong>执行；期限 6 个月，取保候审 12 个月。 |
| 监视居住的适用条件 | 符合逮捕条件但患病、怀孕哺乳、系唯一扶养人、案件特殊需要、期限届满的；取保不成（<strong>没人又没钱</strong>）的也变更监视居住。 |
| 指定居所监视居住条件 | 无固定住处，或在案发地没有固定住处；国恐案件在住处执行<strong>有碍侦查</strong>，经<strong>上一级公安机关</strong>批准；<strong>只有国恐，没有黑、毒</strong>。 |
| 指定居所的执行与通知 | 不得在羁押场所、专门办案场所、办公场所执行；费用由<strong>公安机关</strong>承担；执行后 24 小时内通知家属和<strong>辩护律师</strong>；讯问在办案场所讯问室，办案人员不得进入指定居所。 |
| 监视居住的义务 | 全是应当，<strong>没有酌定义务</strong>；未经批准不得离开住处、不得会见他人，共同居住人和律师除外；上交身份证、出入境证件、驾驶证。 |
| 指定居所的刑期折抵 | 判管制一日折一日；判拘役、有期徒刑<strong>两日折一日</strong>；<strong>只有指定居所</strong>才折抵，普通监视居住不折抵。 |
| 刑事拘留的决定执行 | <strong>公检决定、公安执行</strong>，法院不能决定刑拘；先行拘留可有证可无证，<strong>执行拘留必须出示拘留证</strong>；拘留证不给嫌疑人，给嫌疑人和家属的是拘留通知书。 |
| 先行拘留的七种情形 | 预备或正在犯罪、被指认、身边住处有证据、企图自杀逃跑、有毁证串供可能、身份不明、流窜多次结伙作案；另含<strong>违反取保、监视居住需逮捕</strong>的。 |
| 刑拘后 24 小时三件事 | 送看守所、通知家属、讯问，<strong>同时进行</strong>，没有先后顺序；异地抓人 24 小时内送不回的，就地投送当地看守所，路途时间计入拘留时间。 |
| 刑拘的起算与期限 | 以<strong>宣布拘留</strong>时间起算，宣布当天不计、从次日起算第一天；身份不明的<strong>查清身份后</strong>起算；期限 3+7、7+14、30+37，无多次结伙流窜要素最长 14 日。 |
| 逮捕的决定与条件 | 检察院批准或决定、法院决定，<strong>公安执行</strong>；应当逮捕须证据、徒刑以上、有社会危险性<strong>三合一</strong>；24 小时内通知家属、讯问，<strong>立即送看守所</strong>；只有先行拘留，<strong>没有先行逮捕</strong>。 |
| 人大代表的许可与报告 | 县级以上代表：开会报<strong>主席团</strong>、闭会报<strong>常委会</strong>许可；现行犯被拘留立即报告，不需许可；乡级代表执行后报<strong>乡人大</strong>即可。 |
| 补充侦查的两个阶段 | 报捕阶段退回补侦<strong>无次数、无时间限制</strong>；审查起诉阶段最多两次、每次一个月；两次补侦仍证据不足应当不起诉。 |
| 不起诉的四种类型 | 绝对不起诉——没有犯罪事实；相对不起诉——情节轻微不需判刑或免刑；存疑不起诉——两次补侦证据仍不足；附条件不起诉——未成年人。 |
| 附条件不起诉 | 限未成年人、可能判一年以下、侵犯人身财产权利或妨害社会管理秩序的犯罪、<strong>有悔罪表现</strong>；考验期 6 个月以上 1 年以下；<strong>悔罪不等于和解</strong>。 |
| 复议复核 | 先复议后复核，<strong>同级复议、上级复核</strong>；保证人罚款、没收保证金、不予立案、不批捕等适用；<strong>只存在于刑事领域</strong>，行政案件没有复核。 |

## 课程口诀

::: tip
**口诀（取保候审适用条件）：「管制拘役附加刑，有期病孕无危险，期限届满未办结」**

管制拘役或独立适用附加刑；有期徒刑以上但不致发生社会危险性，及患病、怀孕哺乳；羁押期满案件未结。

课程位置：28:00。
:::

::: tip
**口诀（取保候审禁止情形）：「残暴伤累主」**

残、伤指自伤自残，暴指严重暴力犯罪，累指累犯，主指犯罪集团主犯。

课程位置：31:00。
:::

::: tip
**口诀（保证人条件）：「无牵连、有能力、有权、有房、有钱」**

有政治权利、有固定住处、有固定收入，不要求稳定工作。

课程位置：46:00。
:::

::: tip
**口诀（取保候审法定义务）：「取保禁住便要告，不扰证据传即到」**

禁住为不得离开所居住市县；便要告为住址单位联系方式变动 24 小时内报告；传即到为传讯及时到案。

课程位置：52:00。
:::

::: tip
**口诀（取保候审酌定义务）：「上交证件禁止令，办案机关酌情考」**

上交出入境证件、驾驶证；三个禁止令；酌定即可以，不是应当。

课程位置：55:00。
:::

::: tip
**口诀（监视居住适用条件）：「没钱又没人，居满病孕特情为扶养」**

取保不成即无人又无钱；居满为羁押期限届满案未结；病孕为患病、怀孕哺乳，特情为案件特殊需要，为扶养指唯一扶养人。

课程位置：81:30。
:::

::: tip
**口诀（指定居所监视居住）：「国恐真批三合一」**

国恐案件、在住处执行有碍侦查、经上一级公安机关批准，三个条件缺一不可。

课程位置：86:00。
:::

::: tip
**口诀（指定居所监视居住）：「有家在家，没家指家」**

指定居所监视居住的执行地：有固定住处的在住处执行，无固定住处的在指定居所执行；须同时满足国恐、有碍侦查、上一级批准三个条件

课程位置：89:00。
:::

::: tip
**口诀（先行拘留情形）：「东窗事发，指认是他，证据在旁，逃跑自杀，毁证串供，身份虚假，重大流窜，拘留合法」**

七种情形加兜底，具备其一先行拘留即合法。

课程位置：108:00。
:::

## 待核对事项

::: danger
**以下为来源文件保留的疑点，复习时需结合原课或正式规定核对。**

- 81:30：监视居住条件口诀中「为扶养」一处语音作「为衣服」「为一辅」，是否指生活不能自理者的唯一扶养人，逐字口径待核。

:::
