# 刑事证据

## 知识点速记

> 来源：2027 公专 P27 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 证据概念与三特征 | 能证明案件事实的材料都是证据；<strong>证据不等于定案依据</strong>，要核实真假、关联才能定案；三特征为客观性、关联性、合法性，关联性最常见是因果关系，还包括时间、空间、条件、方法手段。 |
| 八大法定证据 | 物证、书证、证人证言、被害人陈述、供述和辩解、鉴定意见、笔录、视听资料与电子数据；<strong>国家只承认这八种</strong>；测谎结论、警犬辨认报告、心理测试结论都不属证据。 |
| 物证及其照片 | 按物质属性、外部特征、存在状态发挥证明力；作案工具、赃款赃物、指纹脚印均属物证；<strong>给物证拍的照片仍是物证</strong>，照片只是载体和媒介。 |
| 书证 | 以记载的内容和反映的思想证明；文字、表格、符号均可；八大证据中<strong>书证最爱考</strong>。 |
| 一书可兼物证书证 | 淫秽书刊作为走私物品是物证，认定是否淫秽要看内容思想，又是书证；地上三滴血可验 DNA 是物证，传递信息又是书证；<strong>书证不限于白纸黑字</strong>，写在墙上、地上、身体上均可。 |
| 笔录不归书证 | 讯问犯罪嫌疑人笔录属供述和辩解；询问证人笔录属证人证言；询问被害人笔录属被害人陈述；<strong>都写下来但都不是书证</strong>。 |
| 书证形成时间 | 案发前、案发中、案发后均可形成；<strong>不产生于诉讼活动中</strong>；杀人计划与踩点地形图在案发前，墙上留字在案发中，杀人日记在案发后。 |
| 现场材料定性 | 侦查人员拍的现场照片、制作的物品清单属<strong>勘验检查笔录</strong>，因已进入诉讼活动；对物证拍照仍属物证；当事人自交的证据目录、清单不属八大证据，只作参考材料。 |
| 书证与电子数据 | 不看初端也不看末端，<strong>只看递交到警方手里的状态</strong>；纸质为书证，硬盘、U 盘为电子数据；打印的微信截图是书证，拷进 U 盘的是电子数据。 |
| 话单三情形 | 硬盘拷贝回所再打印→电子数据；移动公司当场打印纸质→书证；纸质再扫描上传→仍书证；<strong>通话记录客观形成于案发前中后</strong>，事后调取不改变性质。 |
| 证人证言界限 | 证人推测、猜测、推断出来的内容不能作为证言；只能就其感知的事实陈述。 |
| 讯问录像定性 | 录的是供述、辩解内容→供述和辩解；录到侦查人员打人、刑讯逼供→<strong>视听资料</strong>；按录像所证明的对象定性质。 |
| 口供补强规则 | 只有被告人供述、无其他证据，<strong>不能认定有罪</strong>，防止替罪羊；没有供述但其他证据确实充分，仍可定罪。 |
| 鉴定意见 | 补充鉴定、重新鉴定的情形是主要考法；鉴定专业性强，<strong>一出错即排除</strong>，不能补正也不能合理解释。 |
| 视听资料与电子数据 | 磁带、胶片等磁介质为载体→视听资料；芯片等硅介质存储→电子数据；原则上不要求区分，只在选项明显对立时才分。 |
| 其他证据材料 | 到案经过、抓获经过、取证合法性说明、有专门知识的人的意见、自首坦白立功材料、累犯再犯可能性材料；属刑诉解释的补充，了解即可。 |
| 原始与传来证据 | 原始是一手，传来是二手；现场带血刀、亲耳听到、技术提取指纹属原始；转述、复制粘贴、技术提取音视频电子数据属传来。 |
| 直接与间接证据 | 直接证据单独即可证明是否犯罪，间接证据须与其他证据相佐证；直接证据分肯定性（有人有事）与否定性（否人否事），监控证明电线短路属否定性直接证据。 |
| 物证只能间接 | 带血匕首、检出指纹的铁锤都不能单独定案；<strong>物证不可能是直接证据</strong>，只能与其他证据结合使用。 |
| 言词与实物证据 | 证言、陈述、供述、鉴定意见在表达观点→言词证据；物证、书证按原样记录→实物证据；一般视听资料属实物，讯问录像属言词。 |
| 非法证据移送 | 检察院审查认定并排除的非法证据<strong>应随案移送法院</strong>；侦查机关自己发现排除的不移送；量刑证据仍要随案移送。 |
| 不合法证据三分 | 合法证据直接用；不合法分非法证据（排除）与瑕疵证据（可补正）；非法证据再分故意非法与过失非法，<strong>两者都排除</strong>。 |
| 供述·暴力威胁 | 暴力加痛苦、威胁加痛苦均排除；暴力情形题干可不提痛苦，<strong>威胁情形必须明确写出痛苦</strong>；只有威胁而无痛苦不排除。 |
| 供述·非法拘禁 | 在法定羁押场所以外讯问取得的供述即排除；<strong>不要求暴力、威胁、痛苦</strong>；立法者认为非法拘禁本身已足够恶劣。 |
| 重复性供述 | 刑讯逼供后作出相同供述，原则排除；<strong>换讯问人、换阶段</strong>（到检察、审判环节）并告知权利义务与认罪后果后，可不排除。 |
| 证人被害人陈述排除 | 只要暴力、威胁、非法限制人身自由即排除；<strong>不看是否痛苦、且无例外</strong>；因证人、被害人本身无辜。 |
| 物证书证排除 | 违反法定程序、严重影响司法公正、不能补正或合理解释，<strong>三者同时具备</strong>才排除；未附笔录清单又不能证明来源的，直接排除，无补正余地。 |
| 证言陈述排除情形 | 询问未个别进行；书面证言未经核对；聋哑人未提供通晓手语的人；未提供方言翻译；四类均不得作为定案依据。 |
| 供述排除情形 | 笔录未经核对、未提供翻译、讯问未成年人法定代理人或合适成年人不在场、未全程录音录像、不能排除非法取证；<strong>供述不要求个别进行</strong>，为便于法院当庭对质。 |
| 未成年证人从宽 | 未成年证人、被害人询问时法定代理人不在场，可补正或合理解释后使用；<strong>不直接排除</strong>，与未成年被告人供述不同。 |
| 勘验检查与侦查实验 | 勘验检查明显违反法律法规但能作出合理解释的仍可用，因现场条件恶劣；侦查实验条件与发案时明显不符、或影响结论科学性，不得作为定案依据。 |
| 辨认笔录排除情形 | 非侦查人员主持、辨认前已见到对象、未个别进行、对象未混杂（人七、照片十、物五，尸体不限）、明显暗示或指认；讲者复述他人口诀「昏暗见个猪」。 |
| 电子数据改动 | 篡改（改姓名、改金额、改身份证号）<strong>必排除</strong>；修改（行高、字体、字号）看是否影响真实性，影响才排除。 |
| 瑕疵证据补正 | 非法证据之外的其他不合法情形；能补正或作出合理解释即可用，<strong>解释不了才排除</strong>；如询问证人只有一名侦查人员、辨认未邀见证人、电子数据未封存移送。 |
| 证人资格 | 证人不可替代、不适用回避；聋哑人、民警都能作证，<strong>民警兼证人时证人身份优先</strong>；生理精神有缺陷不能辨别是非、不能正确表达的人及幼年人不能作证。 |
| 证人保护 | 国恐黑毒案件证人需保护；公安机关可协调沟通，但<strong>不能直接「安排工作」</strong>，安排工作属政府有关部门职权，还需编制与财政审批。 |
| 证人作证费用 | 证人异地作证的交通、住宿、就餐费由公安机关补助，<strong>列入办案经费</strong>；民事案件证人没有补助。 |

## 课程口诀

::: tip
**口诀（犯罪嫌疑人、被告人供述）：「暴力胁迫好痛苦，不放不录凭供诉，没有爸妈核翻译，不让核对应排除」**

不放＝非法拘禁，不录＝未全程录音录像，凭供诉＝重复性供述，没有爸妈＝讯问未成年人无监护人在场

课程位置：136:30。
:::

::: tip
**口诀（证人证言、被害人陈述）：「暴力胁迫拘到哭，不分不合听不出，证人被害好无辜，无需痛苦也排除」**

拘＝非法拘禁；不分＝未分别（个别）进行，不合＝未经核对，听不出＝未提供翻译

课程位置：138:30。
:::

::: tip
**口诀（物证、书证）：「物证书证分情况，违反程序可补证，没有来源即排除」**

违反程序需三要件同时具备；无来源的直接排除，补不了证

课程位置：139:30。
:::

::: tip
**口诀（勘验检查笔录）：「勘验难度大，解释原谅他」**

勘验条件恶劣，明显违法但能作出合理解释的仍可用

课程位置：141:00。
:::

::: tip
**口诀（电子数据）：「数据修改可补救，若遭篡改必排除」**

看改动是否影响证据真实性

课程位置：142:00。
:::
