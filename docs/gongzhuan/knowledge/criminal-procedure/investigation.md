# 侦查活动

## 知识点速记

> 来源：2027 公专 P26 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 现场勘查主体 | 由刑事科学技术人员实施；须<strong>两名以上侦查人员</strong>持刑事案件现场勘查证；有尸体的现场<strong>必须有法医参加</strong> |
| 先固定后提取 | 总体原则是<strong>先拍照固定再提取</strong>；先固定是怕提取时毁坏检材，取坏了还有照片兜底；手印、足迹、工具及枪弹痕迹、弹孔等特殊痕迹均按此顺序 |
| 现场分类（变动与关联） | 按形成后至勘查前有无变动分<strong>原始现场</strong>与变动现场；按与实施主要犯罪行为的关系分主体现场与<strong>关联现场</strong> |
| 伪装与伪造现场 | 真实现场即未经伪装、破坏的现场；<strong>伪装现场确有犯罪发生</strong>，只是为逃避侦查而破坏现场；<strong>伪造现场并无犯罪发生</strong>，是虚构案情、有意布置的假现场 |
| 现场保护原则与时限 | 警戒线<strong>宁大勿小</strong>，先拉大再动态缩小；核实情况不得随意进入现场，确需进入须贴边走；保护自<strong>民警到达现场</strong>起至勘查活动结束后止 |
| 三层保护区 | 由外到内为一般保护区、区域保护区、核心保护区；<strong>新闻媒体可进一般保护区</strong>，不是只能待在区外；领导民警、警用车辆及 120、119 车辆、现场指挥部在区域保护区；<strong>核心区只许现场勘查人员</strong>进入 |
| 室外痕迹物证保护 | 生物检材怕氧化，怕雨淋、暴晒；下雨可<strong>扣盆扣碗</strong>并在旁挖排水槽排水；再以塑胶布遮阳遮盖 |
| 浸泡尸体打捞 | 禁用铁钩等<strong>金属器具</strong>，既易破损又与皮肤起反应；改用竹竿或网兜；禁止抓尸体裸露部分 |
| 火场与悬挂尸体 | 火场尸体多已炭化，用<strong>担架或门板</strong>整体抬运；悬挂者需急救时剪断<strong>未打结处</strong>绳扣；已确定死亡的，不必急于卸下，按原状保护待勘查 |
| 三套一罩 | 勘查人员配头套、手套、鞋套加口罩；生物检材<strong>一律视为有传染性</strong>；体液沾污先用<strong>流动清水冲洗</strong>，再以肥皂水或酒精消毒 |
| 勘查见证人 | 应当邀请<strong>一至两名与案件无关的公民</strong>；因客观原因确无人见证的，在案卷材料中注明，并对勘查活动<strong>不间断录像</strong> |
| 勘查步骤与照相 | <strong>先静后动</strong>、先下后上、先重点后一般、先固定后提取；先地面再墙面再天花板，凶杀现场先看尸体；照相<strong>先外后里、先大后小、先远后近</strong>，先全貌后重点与细目 |
| 接触物证与行走 | 从一般人不习惯、不常接触的部位下手，如拿茶杯取<strong>两侧或棱角</strong>；翻转物体捏边缘；走楼梯贴边走，不走中间 |
| 现场记录命名 | 命名按<strong>时间、地点、人物、性质</strong>加平面示意图；笔录记明报案、现场保护、天气光线、指挥人员及笔录、制图、照相人 |
| 人身检查主体 | 由侦查人员进行；检查妇女身体由<strong>女性工作人员或医师</strong>进行，<strong>医师不分男女</strong> |
| 强制检查与适用对象 | 强制检查由<strong>办案部门负责人</strong>批准，且须<strong>先批准后检查</strong>，不得先查后补报；被害人须本人同意，不得强制检查；<strong>证人一律不得检查</strong> |
| 解剖尸体程序 | 死因不明需解剖，经<strong>县级以上公安机关负责人</strong>批准；通知家属在解剖通知书上签字，家属不同意不影响解剖；拒不到场或拒绝签名，侦查人员注明即可 |
| 复验复查 | 检察院要求复验复查的，公安机关<strong>应当</strong>进行；<strong>可以</strong>通知检察院派人参加，必要时检察人员也可自行复验复查 |
| 侦查实验程序 | 由侦查人员组织，可聘请或指派专业人员参加；制作笔录并由参加人签名，<strong>应当</strong>全程录音录像；禁止足以造成危险、侮辱人格或有伤风化的行为 |
| 搜查与检查区别 | 检查针对<strong>生理构造</strong>，搜查查随身携带何物；刑事搜查、检查中的女性工作人员<strong>包括女辅警</strong>，治安案件检查女性身体<strong>特指女民警</strong>；搜查妇女身体不含医师；只有刑事案件有搜查 |
| 搜查证与先行搜查 | 原则上经<strong>县级以上公安机关负责人</strong>批准并制作搜查证；仅在<strong>执行拘留、逮捕</strong>且情况紧急时可先行搜查，事后<strong>不补证</strong>；单纯为搜查，情况再紧急也要有证 |
| 强制搜查与搜查笔录 | 遇阻碍可强制搜查，<strong>不需审批</strong>；破坏性搜查如拆墙须<strong>办案部门负责人</strong>批准；笔录由侦查人员、被搜查人或其家属、邻居、见证人签名，至少得有一名外人 |
| 查封与扣押对象 | 刑事案件只有查封、扣押，<strong>无收缴、追缴、登记后返还</strong>（属治安案件）；查封针对不动产，扣押针对动产；与案件无关的已扣财物<strong>三日内解除</strong> |
| 查封扣押审批与清单 | 一般由<strong>办案部门负责人</strong>批准；勘验、搜查中发现的由现场指挥人员决定；价值较高、影响生产经营、涉个人信息及不动产、船舶航空器等由县级以上公安机关负责人批准；可搬走的一式三份，搬不走的一式两份；为嫌疑人及其抚养亲属保留必要生活费用和物品 |
| 查询冻结 | 经<strong>县级以上公安机关负责人</strong>批准，经侦大队长无权；冻结存款汇款<strong>六个月</strong>，债券、股票、基金份额<strong>两年</strong>；与案件无关的三日内解除 |
| 鉴定意见形式 | 必须<strong>书面</strong>并由鉴定人签名；只有盖章无签名或只有签名无盖章属<strong>程序违法</strong>，不能作为定案依据；多人意见不一致的客观记录，<strong>不少数服从多数</strong> |
| 补充与重新鉴定 | 补充鉴定针对<strong>有遗漏、新证物、新要求</strong>、不完整不充分；重新鉴定针对违法、无资质、弄虚作假、依据不足、被损坏；重新鉴定须<strong>另行指派</strong>，不得仍用原鉴定人 |
| 鉴定与办案期限 | 刑事案件<strong>精神病鉴定不计入</strong>办案期限，其他鉴定计入；治安案件所有鉴定及听证时间均不计入 |
| 辨认对象与规则 | 嫌疑人<strong>七人以上</strong>、照片<strong>十张以上</strong>、物品<strong>五件以上</strong>；尸体、场所不受数量限制；一对多单独辨认，不得多对一、多对多；对象体貌特征须相近 |
| 技术侦查 | 须<strong>立案后</strong>方可实施，受案至立案的调查核实阶段不得使用；主要针对国恐黑毒及其他严重暴力犯罪；由<strong>设区市级以上</strong>公安机关负责人批准；<strong>三个月</strong>内有效，疑难可延长，每次不超过三个月 |
| 技术侦查对象 | 仅限<strong>犯罪嫌疑人、被告人及直接关联人</strong>，其家属、上下线均属；不得对被害人、证人；所获证据<strong>可以作为证据使用</strong> |
| 通缉令 | <strong>县级以上</strong>公安机关可在本辖区内直接发布，超辖区报有权决定的上级发布；A 级由公安部认为重要、B 级由省厅认为重要请求发布，<strong>均由公安部发布</strong>；检察院、监察委可决定通缉，由公安机关执行 |
| 见证人 | 勘验、检查、搜查、扣押、查封、辨认<strong>应当有见证人</strong>；询问、查询、冻结、鉴定不需要；<strong>辅警、保安及与公安有关人员不能当</strong>；生理缺陷、与案有利害关系、办案人员、幼儿不能当 |
| 令状措施 | 拘传、书面传唤、拘留、逮捕、勘验、检查、搜查、通缉须有证；<strong>先行拘留、口头传唤</strong>不需证；执行拘留、逮捕遇紧急情况可先行搜查不补证；拘留后投送看守所时必须有证 |

课程位置：115:00。
:::
