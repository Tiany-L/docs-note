# 刑事管辖、回避

## 知识点速记

> 来源：2027 公专 P24 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 刑事与治安管辖之别 | 两套大体相同，都是行为（犯罪）地为主、居住地为辅；治安那句「黄祖独行为地管辖、不适用当场处罚」是本集<strong>复述</strong>，不是新考点。 |
| 犯罪地含行为地与结果地 | 犯罪地拆成行为地、结果地；两地公安都取得管辖权，<strong>有管辖权</strong>与<strong>最终由谁办</strong>是两个问题。 |
| 居住地的两项构成 | 居住地包括户籍所在地和经常居住地；户籍地即身份证上的地址。 |
| 经常居住地的认定 | 离开户籍地后<strong>连续居住一年以上</strong>的地方；在校大学生、外出务工者常落入此项。 |
| 经常居住地的例外 | 保外就医在医院居住的，不按经常居住地算。 |
| 公安阶段的称谓 | 讲义原写被告人、被告单位，公安阶段应改为<strong>犯罪嫌疑人</strong>、犯罪单位，组掉括注。 |
| 单位犯罪的居住地 | 原则上以登记住所地（营业执照地址）为居住地；与主要营业地、主要办事机构所在地不一致的，以后两者为居住地。 |
| 管辖竞合的先后 | 几个公安机关都有管辖权，谁先抓到谁先管；严格标准是<strong>谁先制作受案登记表</strong>，不是立案登记表。 |
| 管辖争议的解决 | 先由公安机关互相协商；协商不成的，报<strong>共同上一级公安机关指定管辖</strong>。 |
| 户籍地与居住地冲突 | 刑诉法与公安机关办理刑事案件程序规定只分犯罪地、居住地，未写户籍地与经常居住地谁优先，一般案件不作区分。 |
| 经济犯罪的居住地优先 | 户籍地与经常居住地不一致时，依最高检、公安部办理经济犯罪案件若干规定第八条，以<strong>经常居住地</strong>公安管辖为主。 |
| 计算机网络犯罪沾边管辖 | 服务器所在地、网络服务提供者所在地、被侵害的网络信息系统及管理地、嫌疑人被害人使用网络地，沾边就能管。 |
| 立案前的调查核实 | 立案前可询问、查询、勘验、检查、鉴定、调取证据材料；<strong>不得</strong>采取强制措施、查封扣押冻结财产、技术侦查。 |
| 远程询问与讯问 | 信息网络犯罪可远程在线制作笔录；<strong>应当</strong>全程录音录像，录音录像随案移送。 |
| 抽样取证 | 确因客观条件限制无法逐一收集的，按一定比例或数量选取；选取情况须<strong>说明和论证</strong>。 |
| 涉案金额的认定 | 按账户<strong>接收金额</strong>认定，不按余额；嫌疑人、被告人能作出合理说明的除外，案外人提出异议应依法审查。 |
| 并案侦查 | 大案套小案、证据与线索交叉的，可并案侦查，避免证据和线索资源浪费。 |
| 行驶中交通工具内犯罪 | 由最初停靠地公安管辖；必要时始发地、途经地、到达地也可管。 |
| 与监察委互涉案件 | 嫌疑人又涉监察机关管辖案件的，及时与同级监察机关协商；一般以<strong>监察机关调查为主</strong>，公安协助。 |
| 重大刑事案件的管辖 | 由<strong>设区的市级以上</strong>公安机关管辖，不含县级市；范围限危害国家安全、恐怖活动、涉外、经济、集团、跨区域六类。 |
| 移送管辖 | 上级认为必要时可侦查下级管辖的案件；下级认为重大可请求上级侦办。 |
| 倒卖火车票案件 | 倒卖、伪造、变造火车票的刑事案件，铁路与地方公安都能管；谁先抓到谁先管。 |
| 列车上犯罪的管辖 | 运输途中被抓获的，由<strong>前方停靠地</strong>铁路公安机关管辖；必要时始发地、终点地铁路公安也可管。 |
| 铁路施工工地案件 | 铁路建设施工工地发生的刑事案件，由<strong>地方</strong>公安机关管辖，不是铁路公安。 |
| 回避的适用主体 | 侦查人员、公安机关负责人、翻译人员、鉴定人适用回避；<strong>证人</strong>有不可替代性，不适用回避。 |
| 回避情形与类型 | 以可能影响案件公正处理为标准（如近亲属、利害关系）；分自行、申请、指定三类，可书面也可口头提出。 |
| 驳回回避的复议 | 收到驳回决定 <strong>5 日</strong>内申请复议，公安机关 <strong>5 日</strong>内作出复议决定并书面通知；复议期间不停止侦查，对复议决定不得再申请复核。 |
| 刑事回避的决定主体 | 侦查人员回避由<strong>县级以上公安机关负责人</strong>决定；公安机关负责人回避由<strong>同级检察委员会</strong>决定；决定前诉讼活动是否有效，由决定机关定。 |
| 治安与刑事回避之别 | 治安案件无论民警还是负责人，均由所属公安机关（组织）决定；回避能否复议，治安未规定，仅可依人民警察法保留意见但必须执行。 |
| 检察院自侦案件范围 | 非法拘禁、刑讯逼供、非法搜查、暴力取证、虐待被监管人等损害司法公正的职务犯罪归检察院；涉钱的贪污贿赂、渎职归监察委。 |

## 课程口诀

::: tip
**口诀（设区的市一级以上公安机关管辖的六类案件）：「外国惊恐预解」**

外＝涉外犯罪，国＝危害国家安全，惊（经）＝经济犯罪，恐＝恐怖活动犯罪，预＝跨区域犯罪，解＝集团犯罪；讲者按谐音串成一句，六类案件由设区的市一级以上公安机关管辖

课程位置：72:30。
:::

::: tip
**口诀（移送管辖）：「上可侦下，下可请上」**

上级认为必要时可侦办下级管辖的案件（上可侦下）；下级认为重大需上级侦办的，可请求上级侦办（下可请上）

课程位置：73:30。
:::
