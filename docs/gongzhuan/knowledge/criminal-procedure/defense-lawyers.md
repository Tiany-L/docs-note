# 律师参与刑诉

## 知识点速记

> 来源：2027 公专 P29 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 辩护人类型与主体 | 自行辩护、委托辩护、法律援助三类；律师只是辩护人中最常见的一种，<strong>律师不等于辩护人</strong>；人民团体或嫌疑人被告人所在单位推荐的人、监护人、亲友都能当 |
| 相对禁止当辩护人 | 公检法监现职人员、人民陪审员、与本案结果有利害关系的人、外国人或无国籍人、被开除公职或被吊销律师公证员执业证书的人、法官检察官离任后原单位案件；<strong>原则禁止，但系被告人监护人、近亲属并受其委托的可以</strong> |
| 近亲属的范围 | 以自己为中心：上父母、下子女、左配偶、右同胞兄弟姐妹；<strong>朋友不在其中</strong>，朋友之间只是道德义务 |
| 绝对禁止当辩护人 | 无行为能力或限制行为能力人；被剥夺、限制人身自由的人；正在执行刑罚或缓刑、假释考验期内的人；<strong>三类一律禁止，没有例外</strong> |
| 侦查阶段谁能介入 | 只有律师能以辩护人身份介入；节点为第一次讯问或采取强制措施之日；<strong>自诉案件随时可以介入</strong> |
| 侦查阶段律师权利 | 向公安机关了解涉嫌罪名和案件有关情况并提出意见；会见、通信向嫌疑人了解案情；提供法律帮助、代理申诉控告、申请变更强制措施 |
| 侦查阶段不能阅卷核实 | <strong>不能阅卷、不能核实证据</strong>；这两项要到审查起诉阶段才有 |
| 审查起诉阶段权利 | 可查阅、摘抄、复制本案案卷材料，可核实证据；<strong>国恐案件会见不再需许可</strong>，与侦查阶段相反 |
| 会见的三证与48小时 | 律师执业证、委托书或法律援助函；<strong>48 小时</strong>之内安排会见 |
| 会见时公安不在场 | 律师单独会见，公安不得派员在场、不得旁听；可以录像<strong>不能录音</strong>，录像防自残自杀和递物，不录音是保障人权；公安讯问时律师同样不在场 |
| 特定证据开示义务 | 不在场、未达刑事责任年龄、依法不负刑责的精神病人三种；<strong>应当及时通知公检</strong>，三种都指向无罪或不起诉 |
| 保密义务与例外 | 对委托人情况和信息原则保密；例外只限<strong>正在发生或即将发生</strong>的危害国家安全、公共安全、严重危害他人人身安全的犯罪；此处司法机关泛指公检法；已经实施完毕的犯罪不属例外，律师不告知 |
| 法律援助情形 | 盲、聋、哑、精神病、无期、死刑、未成年、缺席审判，<strong>具备其一即可</strong>；法律援助律师出庭辩护，且不收费 |
| 一名律师不得兼辩两人 | 一名辩护人不得同时为两名以上同案被告人辩护；<strong>两名辩护人可以同时为一名嫌疑人辩护</strong> |
| 值班律师的条件 | 看守所羁押、没有委托辩护人、没有指定辩护（法律援助）；三者同时具备才能约见，看守所应当告知其有权约见 |
| 值班律师的权利 | 可会见、提供法律咨询和释法、查阅卷宗了解案情、申请变更强制措施、申请法律援助；嫌疑人向看守所申请后，看守所<strong>24 小时</strong>内通知值班律师；<strong>不出庭辩护</strong>，与法律援助律师都不收费 |
| 值班律师会见不得旁听 | 民警不得旁听，除值班律师外不得有其他人在场；<strong>可以录像、不能录音</strong>，与辩护律师会见同一规则 |
| 值班律师阅卷新规 | 检察院阶段可查阅、复制、摘抄；<strong>法院阶段只能查阅，不能复制和摘抄</strong> |
| 见证认罪认罚 | 嫌疑人自愿认罪认罚就必须签具结书；值班律师<strong>无权阻止，只能见证</strong> |
| 值班律师的禁止事项 | 不能出庭、不能上门、不能取证、不能带助理、不能收财物；<strong>不得转为辩护律师，但可以转为法律援助辩护人</strong> |
| 结案的条件 | 事实清楚、证据确实充分、罪名认定正确、法律手续完备、应当追究刑事责任；<strong>罪名不要求与法院最终认定一致</strong> |
| 结案的审批 | 县级以上公安机关负责人批准；特别重大、复杂、疑难案件（运输假币、贩毒、恐怖活动）由党委集体讨论决定，不再一人拍板 |
| 起诉意见书与移送卷宗 | 共同犯罪分别写明每人在共犯中的地位作用、具体职责、具体罪责和认罪态度；附带民事诉讼在末页注明；移送检察院的是<strong>诉讼卷</strong>，侦查卷由公安留存；移送应通知嫌疑人及辩护律师 |
| 撤案情形（复述） | 显示特告死：情节显著轻微不认为是犯罪、特赦、告诉才处理而无告诉、犯罪嫌疑人死亡；另有无犯罪事实的情形 |
| 未成年记录封存 | 犯罪时未满 18 周岁、被判五年以下有期徒刑（含管制、拘役），<strong>应当封存</strong>，可开无犯罪记录证明；发现漏罪合并执行五年以上则解除封存 |
| 五种送达与转换 | 直接送达、留置送达、委托送达、邮寄送达、转交送达；五种可相互转换，<strong>不能说直接送达不成「应当」转邮寄</strong>；邮寄用 EMS，签收之日为送达日期 |
| 直接与留置送达 | 直接送达本人签收并注明日期，本人不在交<strong>成年家属</strong>或所在单位负责人员代收；留置送达需邀请见证人或拍照录像，文书留在住处，注明拒收事由和日期，由送达人、见证人签名盖章 |
| 送达回证 | 五种送达都必须有送达回证；写明送达机关、收件人姓名、文书名称、送达时间地点方式、签名盖章和签收日期；<strong>回执信息写在回证上，不写在送达文书上</strong> |

## 课程口诀

::: tip
**口诀（绝对禁止当辩护人）：「无限人无自由受刑罚」**

无行为能力或限制行为能力人、被剥夺限制人身自由的人、正在执行刑罚或缓刑假释考验期内的人

课程位置：08:00。
:::

::: tip
**口诀（相对禁止当辩护人）：「公检法监老外陪审利害，开除公职吊销证书」**

公检法监现职人员、人民陪审员、利害关系人、外国人无国籍人，再加被开除公职、被吊销执业证书两类

课程位置：09:00。
:::

::: tip
**口诀（特定证据开示）：「不在场不够大不正常」**

不在现场、未达刑事责任年龄、依法不负刑责的精神病人，三种都应及时告知公检

课程位置：16:00。
:::
