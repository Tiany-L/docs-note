# 刑诉法流程图

## 知识点速记

> 来源：2027 公专 P22 课程整理。以下保留课程表述，尚待确认的内容列在本页“待核对事项”，未作现行法规核验。

| 考点 | 记忆点 |
| --- | --- |
| 刑法与刑诉法的分工 | 刑法是<strong>实体法</strong>，解决构成要件与定罪；刑诉法是<strong>程序法</strong>，解决公检法三家的办案流程；公安专业科目只考刑诉法里与公安相关的那部分 |
| 三机关各自的程序规定 | 公安部出《公安机关办理刑事案件程序规定》，检察院出<strong>高检规则</strong>，法院出<strong>刑诉解释</strong>；与刑诉相关的解释共约 38 部，通用制度三家各自规定、内容相近但条文不一 |
| 公检法的分工与检察院定位 | 公安侦查、检察院审查起诉、法院审判，一家干一家的活；检察院是宪法规定的<strong>唯一法律监督机关</strong>，能决定案件是否移送法院 |
| 公安的两大职权 | 刑事案件中公安只有两项权力：侦查权与<strong>刑罚执行权</strong>；侦查权目的是调查取证，含讯问嫌疑人、询问证人被害人、勘验检查、搜查扣押查封、查询冻结、辨认鉴定、通缉 |
| 公安执行的四种刑罚 | 剩余刑期三个月以下有期徒刑、拘役、剥夺政治权利、驱逐出境；此处考特殊不考常态，四项之外都不是公安执行 |
| 剩余刑期三个月以下 | 判决执行以前先行羁押的，<strong>羁押一日折抵刑期一日</strong>；折抵后剩余刑期三个月以下的，由公安在看守所代为执行，不再办出所转监手续；判前未被羁押（如取保候审）的无从折抵，剩再短也送监狱 |
| 刑事强制措施五种 | 由轻到重：拘传、取保候审、监视居住、拘留、逮捕；<strong>逮捕</strong>最严厉，故须检察院把关；目的是保障诉讼顺利进行，不是处罚 |
| 受案到立案的调查核实 | 受案只是接受案件；受案到立案之间为<strong>调查核实</strong>阶段，原称初查，现行规定已废初查一词，题目中出现初查一般也按调查核实对待 |
| 查找嫌疑人的期限 | 立案后查找犯罪嫌疑人的时间法律<strong>无期限限制</strong>；无监控的农村案件只能靠调查走访 |
| 刑拘的期限档次 | 原则上 <strong>3 日</strong>；案情重大复杂可延长 1 至 4 日，按最长算 3＋4＝7 日；流窜、多次、结伙作案可延长至 30 日 |
| 报捕与审查批捕 | 公安向<strong>检察院</strong>提请批准逮捕；检察院应在 7 日内审查完毕，决定批捕或不批捕；这 7 日嫌疑人仍是刑拘状态，留在看守所 |
| 刑拘最长37天 | 30 日（多次、流窜、结伙作案）＋检察院审查批捕 7 日＝<strong>37 日</strong>；起算点是宣布刑拘之日，终点是批捕 |
| 刑拘的场所与通知 | 刑事拘留送<strong>看守所</strong>执行，治安拘留才在拘留所；刑拘后 24 小时内通知家属 |
| 侦查羁押期限 | 逮捕后的侦查羁押一般为 2 个月；按 2＋1＋2＋2＋X 逐次延长，直到犯罪事实查清为止 |
| 侦查终结与起诉意见书 | 侦查终结后移送<strong>检察院</strong>审查起诉；随案移送的是起诉意见书，侦查卷由公安机关自己留存 |
| 审查起诉与起诉书 | 检察院审查公安移送的证据，认为齐全后向<strong>法院</strong>提起公诉；检察院给法院的文书是起诉书，与起诉意见书相差「意见」二字 |
| 三阶段的不同称谓 | 提起公诉前称犯罪嫌疑人；提起公诉后至宣判前称<strong>被告人</strong>；宣判后称罪犯 |
| 侦查阶段辩护人资格 | 侦查阶段<strong>有且只有律师</strong>能担任辩护人；自第一次讯问或采取强制措施之日起介入；此时不能阅卷、不能核实证据 |
| 后两阶段的辩护人 | 审查起诉阶段与审判阶段，律师和非律师身份都可担任辩护人；这两个阶段律师<strong>可以阅卷、可以核实证据</strong> |
| 不批捕后的复议释放 | 公安对检察院不批捕的决定不服，可以要求<strong>复议</strong>；但必须立即释放被拘留人，不得以复议为由继续关人 |
| 不批捕后的措施变更 | 放人同时可变更强制措施：符合取保的取保、符合监居的监居；取保候审是<strong>人保或金保</strong>；既无人保又无保证金，变更为监视居住 |
| 不批捕的三种情形 | 情节轻微、不致发生社会危险性；事实不清证据不足需继续补充侦查；<strong>无犯罪事实</strong> |
| 两处补充侦查的差别 | 批捕阶段的补充侦查<strong>无时间、无次数限制</strong>，补完再报捕；审查起诉阶段的补充侦查应在一个月内完毕，以两次为限 |
| 审查起诉缺证据两条路 | 检察院可退回公安机关补充侦查，也可<strong>自行侦查</strong>；侦查权不是公安独享 |
| 全程羁押在看守所 | 从宣布刑拘到宣判，嫌疑人一直在<strong>看守所</strong>；法院、检察院都没有自己的羁押场所，故仍由公安看守 |
| 认罪认罚从宽的判断 | 坦白可以从宽，<strong>抗拒不能从严</strong>；看最后的态度，最后认即认罪认罚、从宽，先认后翻供则不适用；应当听取被害人及诉讼代理人意见，但仅属礼貌，不影响认定 |
| 行政拘留与刑事拘留 | 依据分别为治安管理处罚法与刑诉法；场所为拘留所与<strong>看守所</strong>；行政拘留最长 15 日、合并执行最长 20 日，刑事拘留最长 37 日；性质为处罚与强制措施 |
| 公检法关系与上下级 | 分工负责、互相配合、互相制约，我国<strong>无三权分立</strong>；公安、检察院上下级是领导与被领导，法院上下级是监督与被监督；公安对治安保卫组织是指导与被指导 |
| 不追究刑责六种情形 | 情节显著轻微、危害不大、不认为是犯罪（三者是<strong>且</strong>的关系，不是或）；已过追诉时效；经特赦令免除刑罚；告诉才处理没有告诉或撤回告诉；犯罪嫌疑人死亡 |
| 六情形的分阶段处理 | 立案阶段<strong>不立案</strong>；侦查阶段撤销案件；审查起诉阶段不起诉；审判阶段终止审理，确认无罪的宣告无罪 |
| 程序规定撤案的口径 | 程序规定在五种情形外另加<strong>无犯罪事实</strong>；如实供述、有重大立功或涉及国家重大利益需撤案的，层报公安部，由公安部商请最高检核准后撤案，撤案同时通报同级检察院 |
| 正当防卫等不受限制 | 正当防卫、紧急避险、意外事件、职务行为本身不是犯罪，不适用不追究刑事责任的规定；该类情形是「压根不是坏人」，与「是坏人但有条件不追究」不同 |

## 课程口诀

::: tip
**口诀（不追究刑事责任的情形）：「显时特告死」**

显＝情节显著轻微、危害不大、不认为是犯罪；时＝已过追诉时效；特＝经特赦令免除刑罚；告＝告诉才处理没有告诉或撤回告诉；死＝犯罪嫌疑人死亡

课程位置：105:30。
:::

::: tip
**口诀（不追究刑事责任的情形）：「显著清过时效特赦告诉和死掉」**

同一条的加长版，与「显时特告死」逐字对应，爱记哪个用哪个

课程位置：105:30。
:::

::: tip
**口诀（侦查阶段律师的权利）：「律师不可查阅据」**

查阅据＝阅卷、核实证据，侦查阶段这两项都不能；到审查起诉、审判阶段才放开

课程位置：065:00。
:::
